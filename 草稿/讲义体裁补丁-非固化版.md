# 讲义体裁补丁（非固化版）

> 用途：同一份 `courseware-to-obsidian` 技能换一个模型执行时，规则能等效、判断不能等效。
> 这一节补的是规则管不到的那部分，**不设字数、不设框数**，只描述取向与自查。
> 用法：整段放在技能的最前面（「核心目标」之后），先于所有格式规则出现。

---

## 可复制正文

```
# 补充：这份技能真正要交付的东西

下面的格式与结构规则你照旧执行。但那些规则只能保证你不写错，保证不了读者读完不用再听课。
这一节讲后者。它没法被勾选，只能靠你自己判断——所以请把它读成"动笔时的取向"，而不是又一份清单。

## 一、你交付的不是"整理结果"，是一次"讲过去"

整理问的是：材料里有什么，我有没有漏。
讲课问的是：读者此刻卡在哪里，我下一步把他带到哪。

这两个问题的答案会产出完全不同的东西。前者产出的叫资料卡——信息齐全、便于检索、经得起核对；
后者产出的才叫讲义。资料卡是讲义的必要条件，不是充分条件。

每写完一段，用一句话回答自己：**这一段让读者多会了什么？**
如果答案是"知道了有这么一个定义"，那不是讲课，那是索引。

## 二、你的默认体裁不是讲义，要主动抵抗

面对教材和课件，你的自然反应是：抽取知识点 → 一条一块 → 加标题 → 保证全覆盖。
这个产物是资料卡。它有一个可辨认的外观：每一段都被某种框、某种列表、某种标注包着，
读者眼睛找不到可以连续读下去的平地。

讲的动作只有一种特征：**读者先产生了一个疑问，然后被你的下一段回答。**
没有疑问、也没有回答、只有陈述——那就不是讲义，无论格式多整齐。

## 三、不要先搭骨架再填格子

你的默认生成顺序是先列 H2/H3，再往每个格子里填内容。这个顺序天然产出等长的小节，
因为格子在动笔前就已经一样大了。

换一个顺序：先在脑子里把这一节的难点排个序——哪一处学生一定会卡，哪一处一句话就过去了——
再决定每一处写多长。骨架是写完之后留下的痕迹，不是写之前搭好的脚手架。

## 四、三个你最容易走偏的方向

1. **把"完整"当"讲清楚"。** 你会倾向于把每个条件、每个反例、每道习题都收进来，然后觉得自己尽职了。
   但完整是对材料的交代，讲清楚是对读者的交代。前者做满、后者为零，读者仍然什么都没学会。
2. **把"严谨"当"设防"。** 不确定的地方标一次就够；标满全篇，讲义就变成了审稿意见。
   诚实的样子是——"我判断这里是 A，理由是……；B 这一点我没有把握"——说清楚一次，
   而不是每段末尾补一句"不能据此断言"。
3. **把"层次"当"目录"。** 内容的层次感来自"先讲这个，因为后面要用；这里先按住，第 X 节回收"，
   不来自多一级标题。目录树不是思路树。

## 五、三个必须动笔前就回答的问题

- **这一节的真难点在哪？** 难点要展开到"合上书能自己复现"的程度；不难的地方一句话带过是尽责，不是偷懒。
- **这个概念是被给出来的，还是被逼出来的？** 如果读者读完只知道定义、不知道为什么非得这么定义，
  那这一节最缺的不是解释，而是"不这么定义会坏在哪"。
- **这个"为什么"我答完了没有？** 把它写成小标题很容易，把它走完很难。
  凡是"为什么……？"后面两三句就收尾的，多半是在装饰标题。

## 六、三个自查（不数字化，但一眼能看出破绽）

- 通读一篇，找一段**不被任何框、任何列表、任何标注包围的连续文字**。找不到 → 你在罗列，不在讲。
- 看各小节的长度。如果像栅栏一样齐 → 你没有判断过哪里难，你只是把注意力平均分了。
- 找"先试了个笨办法 → 发现它坏了 → 于是换路"这样的段落。整篇没有 → 你的概念全是天上掉下来的。

## 七、允许与不允许

允许：
- 允许某一段只值三句话，只要它真的只值三句话。
- 允许写"这一点我也没有把握，按通行讲法应当是……"，写一次、写清楚。
- 允许不补某个拓展，如果它和主线无关。
- 允许在两处之间犹豫，然后选一条，并说明为什么选它。

不允许：
- 不允许把判断权交回去（"教材如此规定""按书中所述"）。教材是你的依据，不是你的上级。
- 不允许用格式消化判断。框多一些、层深一些、表格整齐一些，都替代不了"这里到底该讲多深"。
- 不允许把"覆盖到了"当成"讲到了"。

## 八、写完之后，换个身份读一遍

假设明天有人只拿这份笔记去考试，不听这门课。他会卡在哪一句？把那句找出来，改写它。
这一条比任何字数指标都准，也是你唯一需要的终检。
```

## 为什么这样写

旧的写法是给配额（"≥600 行""callout 25–45 个"）。配额有个副作用：
模型会把**达标的动作**和**该做的判断**解耦——数字到了就停，不管那 600 行是推导还是罗列。
这一版换成描述性的取向 + 可自我识别的破绽，让它对"我写出来的东西像不像课"负责，
而不是对"我有没有凑够指标"负责。

配额不是没用，但要降级：**只当体检指标，用来定位跑偏，不作为写作目标**。
体检数字偏小的时候，要问的是"我漏了哪一类内容"，不是"我再补多少字"。

## 塞回技能的三个动作

1. **把这一节放在最前**。取向必须先于规则出现——规则读在前面，模型就进入了"遵守模式"，
   后面再说"要有讲课感"它已经听不进去了。
2. **每条反面清单后面补三行正样本**。技能里 ❌ 的条目很多，模型会把"避免这些"理解成
   "退到最保守的体裁"。每一条后面贴一个三五行的"应该长什么样"，比再加十条禁令有效。
3. **删掉或改写"不给每节设长度配额"这类只否定、不指路的句子**。模型不知道替代行为是什么时，
   默认行为就是均匀覆盖。要补上那句"按信息增量定"的**替代动作**：先排序难点，再分配篇幅。
