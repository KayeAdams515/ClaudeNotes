# C4.1 无监督学习与 K-means 算法

> [!abstract] 本讲任务
> 到上一章为止，我们做的每一件事都有一个共同前提：**数据里带着标准答案 $y$**。房价、肿瘤良恶、邮件是不是垃圾——总有人先把答案标好，我们再去逼近它。
>
> 这一讲把这个前提抽掉，训练集里只剩下 $x$。没有 $y$ 还能学什么？“把数据分成几堆”这件事怎么写成算法？数据本来就没有明显的“堆”时，这件事还有没有意义？

---

## 1. 把 $y$ 拿掉

先回忆监督学习的样子。训练集是

$$\{(x^{(1)},y^{(1)}),(x^{(2)},y^{(2)}),\ldots,(x^{(m)},y^{(m)})\}$$

画在图上，点有两种形状，比如红叉和蓝圈——**形状就是 $y$**。算法的任务很明确：找一条线把红叉和蓝圈分开。对错有标准，因为每个点头上都写着自己该在哪边。

现在只改一处：训练集变成

$$\{x^{(1)},x^{(2)},\ldots,x^{(m)}\}$$

没有 $y$ 了。画在图上，所有点都是**一模一样的黑点**，你不再知道谁和谁一伙。

满屏一样的黑点，还能“学”出什么？——**你仍然看得出哪些点挨在一起。** 同样一张图，谁都能一眼看出点分成了左下和右上两团。人眼看得出来，说明数据本身带着结构；把这种结构自动找出来的算法，就叫**聚类算法 clustering algorithm**。

![[C4.1-板书-无监督学习的训练集.png]]

这就是监督学习和无监督学习的根本区别：监督学习的数据是 $(x,y)$，任务是逼近一个已知的目标；无监督学习的数据只有 $x$，没有目标可以逼近，任务是**把数据自身的结构找出来**。聚类是无监督学习里最常见的一类任务，这一章讲的 K-means 是最常用的聚类算法。

聚类有很多实际用处：

- **市场细分**：把客户分成几群，给每一群设计不同的产品和价格；
- **社交网络分析**：找出互相联系紧密的小圈子；
- **组织计算集群**：经常协同工作的机器放进同一个机架或机房，减少网络延迟；
- **天文数据分析**：从观测数据里发现星系、星团。

这几个例子有个共同点：**谁也没法事先给出标准答案**。“这个客户属于第 3 类”对不对？没法说——因为“第 3 类”本身就是算法要造出来的东西。

---

## 2. 看 K-means 怎么跑

先不写公式，看一遍 K-means 在一组二维数据上是怎么运行的。

![[C4-Kmeans迭代九帧.png]]

**第 1 帧**，一堆没有标签的点，肉眼看是左下、右上两团。

**第 2 帧**，算法随机放下两个“×”，一红一蓝。它们叫**聚类中心 cluster centroid**——注意是这两个 ×，不是数据点。

**第 3 帧，分配**：每个点看看自己离哪个 × 更近，就把自己染成那个 × 的颜色。这一步 × 完全不动。

**第 4、5 帧，移动**：红 × 问自己，“所有红点的平均位置在哪？”然后搬过去；蓝 × 同理。这一步点的颜色完全不变，只有 × 在动。

**第 6 到 9 帧**：分配、移动、分配、移动……两个 × 越走越靠近各自那团点的正中心，点的颜色也越分越干净。到最后，再迭代下去颜色不再变、× 也不再动——**收敛了**。

所以 K-means 就是两件事轮流做：**点认中心**（每个点归到最近的中心），**中心认点**（每个中心搬到自己那群点的平均位置）。名字里的 “means” 就是第二步的平均，“K” 是要分成几堆。

---

## 3. 把它写成算法

### 3.1 输入

K-means 要两样输入：

- $K$，要分成几个簇。这是你自己定的，算法不替你决定。怎么选是 [[C4.2 K-means 的优化目标、随机初始化与选 K]] 的话题。
- 训练集 $\{x^{(1)},\ldots,x^{(m)}\}$，其中 $x^{(i)}\in\mathbb{R}^n$。

注意这里**不再加 $x_0=1$**。线性回归、逻辑回归里人为加一个恒为 1 的 $x_0$，是为了把截距 $\theta_0$ 塞进内积 $\theta^Tx$ 里。K-means 里没有 $\theta$、没有内积、没有截距，只有**距离**；硬加一个 $x_0=1$，只是给每个点加上一个完全相同的坐标，对任何两点的距离都毫无影响。所以 $x^{(i)}\in\mathbb{R}^n$，而不是 $\mathbb{R}^{n+1}$。

![[C4.1-板书-Kmeans的输入.png]]

### 3.2 算法

$$
\begin{aligned}
&\text{随机初始化 }K\text{ 个聚类中心 } \mu_1,\mu_2,\ldots,\mu_K\in\mathbb{R}^n\\[4pt]
&\text{重复}\ \{\\
&\qquad\text{for } i=1 \text{ to } m:\quad c^{(i)}:=\text{离 } x^{(i)} \text{ 最近的聚类中心的编号（1 到 }K\text{）}\\[4pt]
&\qquad\text{for } k=1 \text{ to } K:\quad \mu_k:=\text{被分到第 }k\text{ 簇的所有点的平均}\\
&\}
\end{aligned}
$$

这两个循环各有名字，后面一直要用：第一个叫**分配步 cluster assignment step**，第二个叫**移动中心步 move centroid step**。

两个记号要分清：

| 记号 | 含义 | 取值 |
|---|---|---|
| $c^{(i)}$ | 第 $i$ 个样本被分到了第几簇 | $\{1,\ldots,K\}$ 中的整数 |
| $\mu_k$ | 第 $k$ 个聚类中心的位置 | $\mathbb{R}^n$ 中的向量 |

$c^{(i)}$ 的上标数的是**样本**，一共 $m$ 个，它的值是一个簇编号；$\mu_k$ 的下标数的是**簇**，一共 $K$ 个，它的值是一个位置。打个比方：$c^{(i)}$ 是“第 $i$ 个人报的组号”，$\mu_k$ 是“第 $k$ 组的集合地点”。

**分配步**里“最近”用公式写就是

$$c^{(i)}:=\arg\min_{k}\ \lVert x^{(i)}-\mu_k\rVert^2$$

即让 $x^{(i)}$ 到 $\mu_k$ 的距离平方最小的那个 $k$。用平方而不用距离本身，是因为两者的最小值点相同（平方是单调的），平方还省了一次开方，并且和下一讲的代价函数正好对上。

**移动中心步**写成公式是

$$\mu_k:=\frac{1}{|S_k|}\sum_{i\in S_k}x^{(i)},\qquad S_k=\{\,i\mid c^{(i)}=k\,\}$$

举个例子：如果 $x^{(1)},x^{(5)},x^{(6)},x^{(10)}$ 这四个点被分到了第 2 簇，即 $c^{(1)}=c^{(5)}=c^{(6)}=c^{(10)}=2$，那么移动步就把第 2 个中心放到

$$\mu_2=\frac14\left[x^{(1)}+x^{(5)}+x^{(6)}+x^{(10)}\right]\in\mathbb{R}^n$$

![[C4.1-板书-两步循环与手算例.png]]

**如果某个簇一个点都没分到怎么办？** 这时平均值的分母是 0，算不了。常见的处理是直接删掉这个簇，$K$ 变成 $K-1$；如果一定要恰好 $K$ 个簇，就重新随机放一个中心，比如放到离现有中心最远的那个数据点上。$K$ 取得偏大时这种情况并不少见。（拓展）

## 4. 手算一遍

光看动画不够，自己算一遍才踏实。7 个二维点：

$$(1,1),\ (1.5,2),\ (3,4),\ (5,7),\ (3.5,5),\ (4.5,5),\ (3.5,4.5)$$

$K=2$，从数据点里挑两个当初始中心：$\mu_1=(1,1)$，$\mu_2=(5,7)$。

### 第 1 轮

**分配**：算每个点到两个中心的距离平方，取小的。

| 点 | 到 $\mu_1=(1,1)$ | 到 $\mu_2=(5,7)$ | 归属 |
|---|---|---|---|
| $(1,1)$ | 0 | 52 | 1 |
| $(1.5,2)$ | 1.25 | 37.25 | 1 |
| $(3,4)$ | 13 | 13 | 1（平局，取小编号） |
| $(5,7)$ | 52 | 0 | 2 |
| $(3.5,5)$ | 22.25 | 6.25 | 2 |
| $(4.5,5)$ | 28.25 | 4.25 | 2 |
| $(3.5,4.5)$ | 18.5 | 8.5 | 2 |

**移动**：

$$\mu_1=\frac{(1,1)+(1.5,2)+(3,4)}{3}\approx(1.833,\,2.333),\qquad\mu_2=\frac{(5,7)+(3.5,5)+(4.5,5)+(3.5,4.5)}{4}=(4.125,\,5.375)$$

### 第 2 轮

**分配**：$(3,4)$ 到新 $\mu_1$ 的距离平方是 $1.167^2+1.667^2\approx4.14$，到新 $\mu_2$ 是 $1.125^2+1.375^2\approx3.16$——**它改投第 2 簇了**。其余点不变。

**移动**：

$$\mu_1=\frac{(1,1)+(1.5,2)}{2}=(1.25,\,1.5),\qquad\mu_2=\frac{(3,4)+(5,7)+(3.5,5)+(4.5,5)+(3.5,4.5)}{5}=(3.9,\,5.1)$$

### 第 3 轮

再分配一次，归属一个都没变。**收敛。**

![[C4-Kmeans手算例三次迭代.png]]

回头看：三轮、每轮两步，全是**算距离**和**求平均**，没有梯度、没有学习率、没有求导——K-means 的全部数学就这两样。还要注意 $(3,4)$ 第 1 轮在第 1 簇，第 2 轮就跑了：中心一动，归属就可能翻盘，这正是要“重复”的原因。

## 5. 数据本来就没有“堆”怎么办

前面所有例子里，数据都明显分成几团，K-means 只是把人眼看得见的东西自动化了。可如果数据是**连成一片**的呢？

比如一群人的身高体重。从矮小到高大是连续过渡的，散点图上是一条从左下到右上的带子，中间根本没有空隙。这时候 K-means 分出来的“簇”还有意义吗？

有。换个问法就明白了：**不要问“数据里是否存在 3 个簇”，要问“把数据切成 3 份对我有没有用”。**

设想一个 T 恤厂商。他不可能给每个人量身定做，只能做有限几个尺码。S、M、L 三个尺码的身高体重该定在哪？用 K-means 取 $K=3$：三个中心 $\mu_1,\mu_2,\mu_3$ 就是 S、M、L 三个尺码的“标准身材”，$c^{(i)}$ 就是“这个人该买哪一号”。散点图上本来没有分界，但 K-means 仍然给出了一个**让每个人和他那一号的标准身材差得尽量小**的分档方案。

![[C4.1-板书-非分离簇与T恤分档.png]]

在这种场合，K-means 不是在“发现”结构，而是在“设计”一个最省事的分档。类似的例子还有：鞋码分档；把一张上千万种颜色的图片压成 16 色（每个像素的 RGB 是一个三维点，16 个中心就是调色板——拓展）。这些问题的共同点是：**$K$ 由现实约束决定，不是从数据里读出来的。**

## 6. 小结与遗留问题

从“把 $y$ 拿掉”出发，我们换了一个问题（不再逼近已知答案，而是找数据自身的结构），给出了一个算法（随机初始化 $K$ 个中心，分配和移动轮流做到不再变化），还拓宽了它的用途（即使数据没有天然的簇，它仍是一个有用的分档工具）。

但有三个问题还没回答：

1. “重复到不再变化”——**凭什么保证一定会停？** 会不会两个中心来回横跳，永远不收敛？
2. 初始化是随机的。**换一个随机起点，结果可能完全不同**，哪个才算数？
3. $K$ 是自己给的，**怎么给才对？**

这三个问题有一把共同的钥匙：给 K-means 写出一个代价函数。

> [!important] 这一讲的三句话
> 1. **无监督学习的训练集只有 $\{x^{(1)},\ldots,x^{(m)}\}$，没有 $y$**；聚类的任务是把数据自身的成团结构找出来，应用包括市场细分、社交网络分析、计算集群组织、天文数据分析。
> 2. **K-means = 分配步 + 移动中心步，轮流做到收敛**：分配步把每个 $x^{(i)}$ 归给最近的中心，$c^{(i)}:=\arg\min_k\lVert x^{(i)}-\mu_k\rVert^2$（中心不动）；移动步把每个中心搬到自己那群点的平均位置（归属不动）。输入是 $K$ 和训练集，不再使用 $x_0=1$，$x^{(i)}\in\mathbb{R}^n$。
> 3. **数据没有天然分界时 K-means 依然有用**：T 恤 S/M/L 的例子里，它不是在发现簇，而是在设计一个让每个人与所属尺码差距尽量小的分档方案，$K$ 由现实约束决定。

### 速查表

| 名称 | 内容 |
|---|---|
| 无监督训练集 | $\{x^{(1)},\ldots,x^{(m)}\}$，$x^{(i)}\in\mathbb{R}^n$，不加 $x_0=1$ |
| 输入 | $K$（簇数，自己给）+ 训练集 |
| 聚类中心 | $\mu_1,\ldots,\mu_K\in\mathbb{R}^n$ |
| 归属 | $c^{(i)}\in\{1,\ldots,K\}$ |
| 分配步 | $c^{(i)}:=\arg\min\limits_{k}\lVert x^{(i)}-\mu_k\rVert^2$ |
| 移动中心步 | $\mu_k:=\dfrac{1}{\lvert S_k\rvert}\sum\limits_{i\in S_k}x^{(i)}$，$S_k=\{i\mid c^{(i)}=k\}$ |
| 例 | $c^{(1)}=c^{(5)}=c^{(6)}=c^{(10)}=2$ ⟹ $\mu_2=\frac14[x^{(1)}+x^{(5)}+x^{(6)}+x^{(10)}]$ |
| 空簇（拓展） | 删掉该簇，或重新随机放一个中心 |
| 手算例 | 7 个点、$K=2$、初始 $(1,1)$ 与 $(5,7)$：第 2 轮得 $\mu_1=(1.25,1.5)$、$\mu_2=(3.9,5.1)$，第 3 轮收敛 |

> [!abstract] 下一讲预告
> 下一讲给 K-means 写出它的代价函数
> $$J(c^{(1)},\ldots,c^{(m)},\mu_1,\ldots,\mu_K)=\frac1m\sum_{i=1}^m\lVert x^{(i)}-\mu_{c^{(i)}}\rVert^2$$
> 并且会看到一个漂亮的事实：**分配步和移动步各自都在最小化这同一个 $J$**，只是针对不同的变量。有了它，“会不会停”“哪次随机才算数”“$K$ 取几”三个问题就都有了答案。
