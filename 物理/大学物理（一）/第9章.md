# 第九章 质心与线动量 [Chapter 9 Center of Mass and Linear Momentum]

## 9-1 质心 [The Center of Mass]

- 分析物体的运动时，如果引入**质心 [center of mass]** 的概念，问题会得到大大**简化 [simplified]**。⚾
    
- 棒球棒底部的运动轨迹并不简单，但是棒球棒的**质心 [center of mass]** 遵循一个**简单的抛物线轨迹 [simple parabolic path]**。棒球棒的其他部分都绕着**质心 [center of mass]** 运动。
    
    ![[Pasted image 20260403093923.png]]
    
- **一维中的质心 [Center of mass in one dimension]**：物体的**质心 [center of mass]** 是一个特殊的点，它的运动方式就像物体的所有质量都集中在该点，且所有外力都施加在该点上一样。
    
- 对于两个粒子，质心的**位置 [position]** 公式为：
    
    $$x_{com} = \frac{m_1x_1 + m_2x_2}{m_1 + m_2} = \frac{m_1x_1 + m_2x_2}{M}$$
    
- （其中 $M$ 为总质量）
    
- 对于 $n$ 个粒子，公式推广为：
    
    $$x_{com} = \frac{m_1x_1 + m_2x_2 + m_3x_3 + \dots + m_nx_n}{M}$$
    
- 简写为求和公式：
    
    $$x_{com} = \frac{1}{M}\sum_{i=1}^n m_ix_i$$
    
    ![[Pasted image 20260403093947.png]]
    

**例题 1**：三个粒子的质量分别为 $m_1 = 1.2 kg$，$m_2 = 2.5 kg$ 和 $m_3 = 3.4 kg$，它们构成一个边长 $a = 140 cm$ 的等边三角形。这个系统的质心在哪里？

- **解答**：根据坐标系（$m_1$ 在原点，$m_2$ 在 x 轴正半轴），第三个粒子的坐标为 $x_3 = (140cm)\cos 60^{\circ} = 70 cm$，$y_3 = (140cm)\sin 60^{\circ} = 121 cm$。
    
    $$x_{com} = \frac{m_1x_1+m_2x_2+m_3x_3}{m_1+m_2+m_3} = 83 cm$$
    
    $$y_{com} = \frac{m_1y_1+m_2y_2+m_3y_3}{m_1+m_2+m_3} = 58 cm$$
    
    ![[Pasted image 20260403094005.png]]

## 9-2 粒子系统的牛顿第二定律 [Newton's Second Law for a System of Particles]

- **质心的加速度 [Acceleration of the center of mass]**：质心的运动就像一个质量等于系统总质量的粒子。我们可以为质心指定**位置 [position]**、**速度 [velocity]** 和**加速度 [acceleration]**。
    
- 作用在系统上的所有**外力 [external forces]** 的净力满足：
    
    $$\vec{F}_{net} = M\vec{a}_{com}$$
    
- （其中 $M$ 为系统总质量，$\vec{a}_{com}$ 为质心加速度）
    

### 台球碰撞 [Billiard balls]

- 两个碰撞的台球的质心**速度 [velocity]** 不会改变。🎱
    
- 由于 $\vec{F}_{net} = M\vec{a}_{com}$，且水平面上 $\vec{F}_{net} = 0$，因此 $\vec{a}_{com} = 0$。
    
- 因为在水平面上没有**外力 [external forces]** 作用在台球上，它们质心的加速度为零。它们质心的**速度保持不变 [velocity of their center of mass does not change]**。
    
    ![[Pasted image 20260403094123.png]]
    

### 爆炸的抛射物 [Exploding projectile]

- 爆炸的抛射物碎片的**质心 [center of mass]** 遵循的**抛物线轨迹 [parabolic trajectory]**，与抛射物如果没有爆炸时所遵循的轨迹完全相同。💥
    
- 重力是唯一作用在抛射物上的外力。爆炸的力是内力。质心具有**自由落体加速度 [free fall acceleration]**。
    
    $$\vec{F}_{net} = M\vec{a}_{com}$$
    
    $$\vec{F}_{net} = M\vec{g} \quad \therefore \vec{a}_{com} = \vec{g}$$
    
    ![[Pasted image 20260403101630.png]]
    

### 公式推导 [Derivation]

- 对于一个由 $n$ 个粒子组成的系统：$M\vec{r}_{com} = m_1\vec{r}_1 + m_2\vec{r}_2 + \dots + m_n\vec{r}_n$
    
- 对时间求导得到速度：$M\vec{v}_{com} = m_1\vec{v}_1 + m_2\vec{v}_2 + \dots + m_n\vec{v}_n$
    
- 再次对时间求导得到加速度：$M\vec{a}_{com} = m_1\vec{a}_1 + m_2\vec{a}_2 + \dots + m_n\vec{a}_n$
    
- 根据单个粒子的牛顿第二定律：$M\vec{a}_{com} = \vec{F}_1 + \vec{F}_2 + \dots + \vec{F}_n$
    
- 根据牛顿第三定律，粒子相互施加的内力形成作用力与反作用力对，相互抵消。最终剩下作用在系统上的所有**外力 [external forces]** 的净力：
    
    $$M\vec{a}_{com} = \vec{F}_{net}$$

## 9-3 线动量 [Linear Momentum]

- **单个粒子 [Single particle]**：粒子的**线动量 [Linear momentum]** 是一个矢量。
    
    $$\vec{p} = m\vec{v}$$
    
- （其中 $m$ 为质量，$v$ 为速度）
    
- 我们可以将牛顿第二定律表示为：
    
    $$\vec{F}_{net} = \frac{d\vec{p}}{dt}$$
    
- 推导过程：$\vec{F}_{net} = m\vec{a} = m\frac{d\vec{v}}{dt} = \frac{d(m\vec{v})}{dt} = \frac{d\vec{p}}{dt}$
    
- 作用在粒子上的净力等于粒子动量随时间的变化率。如果没有外力，线动量就不会改变。
    

---

## 9-4 粒子系统的线动量 [The Linear Momentum of a System of Particles]

- **粒子系统 [System of particles]**：由 $n$ 个粒子组成的系统的线动量等于各个粒子线动量之和。
    
    $$\vec{P} = \vec{p}_1 + \vec{p}_2 + \dots + \vec{p}_n$$
    
- 粒子系统的**线动量 [linear momentum]** 等于系统**总质量 $M$** 与**质心速度 [velocity of the center of mass]** 的乘积：
    
    $$\vec{P} = M\vec{v}_{com}$$
    
- （推导过程：$M\vec{v}_{com} = m_1\vec{v}_1 + m_2\vec{v}_2 + \dots + m_n\vec{v}_n = \vec{p}_1 + \vec{p}_2 + \dots + \vec{p}_n = \vec{P}$）
- 该公式可以用于**求解粒子系统的质心**的速度:$$v_{com} = \frac{\vec P}{M}$$
    
- **牛顿第二定律扩展**：作用在系统上的所有**外力 [external forces]** 的净力为 $\vec{F}_{net} = M\vec{a}_{com}$。
    
    $$\vec{F}_{net} = \frac{d\vec{P}}{dt}$$
    作用在粒子上的净力是粒子动量变化的时间率。
    因此，给定动量时间图像，斜率等于净力。
- （推导：$\vec{F}_{net} = M\vec{a}_{com} = M\frac{d}{dt}(\vec{v}_{com}) = \frac{d}{dt}(M\vec{v}_{com}) = \frac{d\vec{P}}{dt}$）
    
- 如果没有净**外力 [external force]** 作用在系统上，系统的**线动量 [linear momentum]** 就**不能改变 [cannot change]**。

## 9-5 碰撞与冲量 [Collision and Impulse]

### 单次碰撞 [Single collision]

- 考虑一次**碰撞 [collision]**，一个运动的类粒子物体（抛射物）与另一个类粒子物体（目标）相撞。
    
- 碰撞通常很短暂，球在碰撞过程中经历一个不断变化的力。$\vec{F} = \frac{d\vec{p}}{dt}$
    
- 在时间间隔 $dt$ 内，球的**线动量 [linear momentum]** 的变化是 $d\vec{p} = \vec{F}dt$。
    
- 由于碰撞导致的球的动量净变化为：
    
    $$\Delta\vec{p} = \int_{t_i}^{t_f} \vec{F} dt$$
    
    ![[Pasted image 20260408141504.png|340]]
    

### 冲量 [Impulse]

- 球的**动量 [momentum]** 因碰撞而产生的**变化 [change]** 等于碰撞的**冲量 [impulse]** $\vec{J}$：
    
    $$\Delta\vec{p} = \int_{t_i}^{t_f} \vec{F} dt = \vec{J}$$
    
- 对于 x 分量，$\Delta p_x = J_x$。即 $p_{f,x} - p_{i,x} = \int_{t_i}^{t_f} F_x dt$。沿 x 轴的冲量分量 $J_x$ 是**力-时间曲线 [force-versus-time curve]** 与 t 轴之间的面积。
    
- 在许多情况下，力的变化是未知的。如果知道 $\Delta p_x$ 和碰撞持续时间 $\Delta t$，我们可以计算作用在目标上的**平均力 [average force]**：
    
    $$F_{avg} = \frac{p_{f,x} - p_{i,x}}{\Delta t}$$
    
    ![[Pasted image 20260408141956.png|237]]

### 冲量与牛顿第三定律 [Impulse and Newton's third law]

- 根据**牛顿第三定律 [Newton's third law]**，作用在球棒上的冲量与作用在球上的冲量大小相等，但**方向相反 [opposite direction]**。
    
    ![[Pasted image 20260408142413.png]]
    

### 连续碰撞 [Series of collisions]

- 当一个固定物体经历一系列相同的重复碰撞时，作用在它上面的平均力是多少？
    
- 在 $\Delta t$ 时间内作用在所有**抛射物 [projectiles]** 上的**冲量 [impulse]** 为 $n\Delta\vec{p}$（$n$ 为粒子数，$\Delta\vec{p}$ 为单个粒子的冲量）。
    
- 在 $\Delta t$ 时间内作用在**目标 [target]** 上的**冲量 [impulse]** 为 $\vec{J} = -n\Delta\vec{p}$。
    
- 作用在目标上的**平均力 [average force]** 为：
    
    $$F_{avg} = \frac{J}{\Delta t} = -\frac{n \Delta p}{\Delta t} = -\frac{n m \Delta v}{\Delta t} = -\frac{\Delta m}{\Delta t} \Delta v$$
    
- 这里 $\frac{\Delta m}{\Delta t}$ 是**质量 [mass]** 与目标碰撞的**速率 [rate]**。
    
- 如果抛射物在撞击时停止：$\Delta v = v_f - v_i = 0 - v = -v$。
    
- 如果抛射物直接从目标向后反弹且速度大小不变：$\Delta v = v_f - v_i = -v - v = -2v$。

#### 关卡
一个敞篷小车在**无摩擦的轨道**上行驶，此时天正在下雨。随着小车的行驶，雨水落入车内，小车的**速度**会如何变化？（假设雨水是垂直落入车内的）

- **A) Speeds up** (加速)
    
- **B) Maintains constant speed** (保持匀速)
    
- **C) Slows down** (减速)
    
- **D) Stops immediately** (立即停止)
    
##### 🔍 核心解析：动量守恒视角

要解开这道题，我们需要观察系统在**水平方向**上的动量表现。

###### 1. 系统定义与受力分析

- **系统：** 小车 + 掉进车里的雨水。
    
- **水平方向：** 题目明确说了轨道是 **frictionless（无摩擦）** 的。雨水是 **vertically（垂直）** 落下的，这意味着雨水在进入车厢前，在水平方向上没有初速度，也没有给系统施加水平方向的外力。
    
- **结论：** 系统在水平方向上满足**动量守恒（Conservation of Momentum）**。
    

##### 2. 数学推导

设小车初始质量为 $M$，速度为 $v$。一段时间后，落入车内的雨水质量为 $m$。

根据动量守恒公式：

$$P_{initial} = P_{final}$$

$$M \cdot v = (M + m) \cdot v'$$

由于雨水落入后，系统的总质量变大了（$M + m > M$），为了保持等式平衡，最终速度 $v'$ 必须满足：

$$v' = \frac{M}{M+m} \cdot v < v$$

##### 3. 物理直觉：完全非弹性碰撞

你可以把这个过程想象成：无数个质量极小、水平速度为 $0$ 的“雨水小球”，不断地与正在行驶的小车发生**完全非弹性碰撞**并粘在一起。

为了让这些静止的雨水获得水平方向的速度，小车必须“分出”一部分自己的动量给雨水，代价就是自己变慢。
##### ✅ 正确答案

**C) Slows down (减速)**

## 9-6 线动量守恒 [Conservation of Linear Momentum]

- **无净外力 [No net external force]** 时：$\vec{F}_{net} = \frac{d\vec{P}}{dt} = 0 \quad \therefore \vec{P} = \text{常数 [constant]}$。即 $\vec{P}_i = \vec{P}_f$。
    
- **线动量守恒定律 [Law of conservation of linear momentum]**：如果**没有净外力 [no net external force]** 作用在一个闭合的粒子系统上，那么该系统的总**线动量 [linear momentum]** 就**不能改变 [cannot change]**。🔒
    
- 孤立系统 [Isolated system] = 没有外部净力。
    
- 闭合系统 [Closed system] = 没有粒子进入或离开系统。
    
- **沿坐标轴的线动量守恒 [Conservation of linear momentum along an axis]**：如果作用在闭合系统上的**净外力的某个分量 [component of the net external force]** 沿某一轴为**零 [zero]**，那么系统沿该轴的**线动量分量 [component of the linear momentum]** 就**不能改变 [cannot change]**。
    
    $$\vec{F}_{net, x} = \frac{dP_x}{dt} = 0 \quad \therefore P_x = \text{常数 [constant]}$$
    

**例题 2**：一枚火箭在太空中弹射出一个模块。火箭和模块的总质量 = $M$。模块的质量 = $0.2M$。相对于太阳的初始速度 $v = 2100 km/h$。弹射后，**火箭的移动速度比模块快 $500 km/h$**。火箭相对于太阳的速度是多少？

- **解答**：由于没有净外力作用在系统上，系统的总线动量守恒。
    
    $$\vec{P}_{xi} = \vec{P}_{xf} = \vec{P}_{1xf} + \vec{P}_{2xf}$$
    
    $$MV = (0.8M)v_{RS} + (0.2M)v_{MS}$$
    
- 已知 $V = 2100 km/h$，相对速度关系为 $\vec{v}_{MS} = \vec{v}_{MR} + \vec{v}_{RS}$，且 $v_{MR} = -500km/h$。代入得到：
    
    $$V = (0.8)v_{RS} + (0.2)(v_{MR} + v_{RS})$$
    
    $$2100 = (0.8)v_{RS} + (0.2)(-500 + v_{RS})$$
    
- 解得火箭相对于太阳的速度 $v_{RS} = 2200 km/h$。

## 9-7 碰撞中的动量与动能 [Momentum and Kinetic Energy in Collisions]

- **弹性与非弹性碰撞 [Elastic and inelastic collisions]**：
    

|**碰撞类型**|**总线动量 [Total Linear momentum]**|**总动能 [Total kinetic energy]**|
|---|---|---|
|**弹性碰撞 [Elastic collision]**|守恒 [conserved]|守恒 [conserved]|
|**非弹性碰撞 [Inelastic collision]**|守恒 [conserved]|不守恒 [Not conserved]|

- 在现实生活中，部分动能总是会转移为其他形式的能量，如**热能 [thermal energy]** 或**声能 [energy of sound]**。
    
- 如果**能量损失很小 [loss of energy is small]**，我们可以近似将碰撞视为弹性的。
    
- 如果物体粘在一起，则发生**最大损失 [greatest loss]**。在这种情况下，碰撞被称为**完全非弹性碰撞 [completely inelastic collision]**。

## 9-8 一维非弹性碰撞 [Inelastic Collisions in One Dimension]

- **动量守恒 [Conservation of momentum]**：两个碰撞的粒子形成一个孤立和闭合的系统。总**线动量 [linear momentum]** 是守恒的。
    
    $$\vec{P}_{1i} + \vec{P}_{2i} = \vec{P}_{1f} + \vec{P}_{2f}$$
    
    $$m_1\vec{v}_{1i} + m_2\vec{v}_{2i} = m_1\vec{v}_{1f} + m_2\vec{v}_{2f}$$
    
- **完全非弹性碰撞 [Completely inelastic collision]**：碰撞后粘在一起。
    
    $$\vec{P}_{1i} + \vec{P}_{2i} = \vec{P}_f$$
    
    $$m_1\vec{v}_{1i} + m_2\vec{v}_{2i} = (m_1 + m_2)\vec{v}$$
    
    $$\vec{v} = \frac{\vec{P}_{1i} + \vec{P}_{2i}}{m_1 + m_2}$$
    
- 在一个闭合、孤立的系统中，**质心的速度不能因为碰撞而改变 [velocity of the center of mass cannot be changed]**。
    
    $$\vec{P} = M\vec{V}_{com} = (m_1 + m_2)\vec{V}_{com}$$
    
    $$\vec{V}_{com} = \frac{\vec{P}_{1i} + \vec{P}_{2i}}{m_1 + m_2}$$

## 9-9 一维弹性碰撞 [Elastic Collisions in One Dimension]

- 日常的碰撞都是非弹性的，但我们可以将其中一些近似为弹性的。在**弹性碰撞 [elastic collisions]** 中，系统的总**动能 [kinetic energy]** **不会改变 [does not change]**。
    
- 在正碰中，粒子在一维方向上运动。
    

### 静止目标 [Stationary target] ($v_{2i} = 0$)

- 守恒方程组：
    
    $$\begin{cases} m_1v_{1i} = m_1v_{1f} + m_2v_{2f} \quad \text{(总线动量守恒)} \\ \frac{1}{2}m_1v_{1i}^2 = \frac{1}{2}m_1v_{1f}^2 + \frac{1}{2}m_2v_{2f}^2 \quad \text{(总动能守恒)} \end{cases}$$
    
- 解得碰撞后的速度：
    
    $$v_{1f} = \frac{m_1 - m_2}{m_1 + m_2}v_{1i}$$$$v_{2f} = \frac{2m_1}{m_1 + m_2}v_{1i}$$
    
    ![[Pasted image 20260408145240.png|372]]
    
- **运动方向分析 [Direction of motion]**（针对初始静止目标）：
    
    - $v_{2f} > 0$ （目标总是向前运动）
        
    - 如果 $m_1 = m_2$（**质量相等 [Equal masses]**），则 $v_{1f} = 0$（抛射物停止）。
        
    - 如果 $m_1 > m_2$（**大质量抛射物 [Massive projectile]**），则 $v_{1f} > 0$（抛射物继续向前）。
        
    - 如果 $m_1 < m_2$（**大质量目标 [Massive target]**），则 $v_{1f} < 0$（抛射物反弹）。
        
        ![[Pasted image 20260408145204.png|275]]
        

### 运动目标 [Moving target]

- 如果目标也是运动的，通过联立动量和动能守恒方程，得到更普遍的速度公式：
    
    $$v_{1f} = \frac{m_1 - m_2}{m_1 + m_2}v_{1i} + \frac{2m_2}{m_1 + m_2}v_{2i}$$
    
    $$v_{2f} = \frac{2m_1}{m_1 + m_2}v_{1i} + \frac{m_2 - m_1}{m_1 + m_2}v_{2i}$$
    
- 如果我们交换下标 1 和 2，我们会得到相同的一组方程。

## 9-10 二维碰撞 [Collisions in Two Dimensions]

### 掠射碰撞 [Glancing collision]

- 总**线动量守恒 [linear momentum is conserved]**：$\vec{P}_{1i} + \vec{P}_{2i} = \vec{P}_{1f} + \vec{P}_{2f}$
    
- **分解到坐标轴**上：
    
    - **沿 x 轴 [Along the x axis]**：
        
        $$m_1v_{1i} = m_1v_{1f}\cos\theta_1 + m_2v_{2f}\cos\theta_2$$
        
    - **沿 y 轴 [Along the y axis]**：
        
        $$0 = -m_1v_{1f}\sin\theta_1 + m_2v_{2f}\sin\theta_2$$
        
- 如果碰撞是弹性的，那么总动能也是守恒的：
    
    $$K_{1i} + K_{2i} = K_{1f} + K_{2f}$$
    
    $$\frac{1}{2}m_1v_{1i}^2 = \frac{1}{2}m_1v_{1f}^2 + \frac{1}{2}m_2v_{2f}^2$$
