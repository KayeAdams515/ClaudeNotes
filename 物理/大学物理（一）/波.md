# 第 16 章 Waves - I

## 16-1 Types of Waves (波的类型)
在波中 (wave)，能量和信息可以从一个点移动到另一个点，但没有物质对象随之移动。波主要有三种类型：**机械波** (Mechanical Wave)、**电磁波** (Electromagnetic Wave)、**物质波** (Matter Wave)。

**机械波 (Mechanical Waves)**：这些常见波的例子包括水波、声波、拉伸弦上的波和地震波。它们受牛顿定律支配，并且只存在于物质介质中，例如水、空气、弦等。没有介质就没有机械波。

[图片：一位妇女按响闹钟的示意图，声波以红色波纹形式传播]

**电磁波 (Electromagnetic Waves)**：例子包括可见光、紫外线、无线电和电视波、微波、X 射线和雷达波。这些波不需要物质介质，全部在真空中以相同的速度 $c=299,792,458 \text{ m/s}$ 传播。

[图片：G.P. Thomson 的实验示意图，展示入射束穿过靶材并在相纸上形成圆环]
**物质波 (Matter Waves)**：这些波与电子、质子和其他基本粒子，甚至原子和分子相关联。由于我们通常认为这些物质构成了“物质”，因此这种波被称为物质波。

## 16-3 Wavelength and Frequency (波长和频率)
### 波长和周期
**正弦波 (Sinusoidal wave)**
[图片：正弦波形示意图]
**在特定时间 (快照，At certain time)**
[图片：纵轴为 y，横轴为位置 x，显示波长 $\lambda$ 的波形]
**波长 (Wavelength) $\lambda$** 是波的形状重复的距离。

**在特定位置 (At certain position)**
[图片：纵轴为 y，横轴为时间 t，显示周期 $T$ 的波形]
**周期 (Period) $T$** 是介质中某个元素完成一次振荡所需的时间。

### 正弦波的数学表示 (Mathematical representation of a sinusoidal wave)
[图片：带有位移、振幅、波峰、波谷标注的正弦波 $y(x, t)$ 示意图]
**位移 (Displacement) $y(x, t)$** = **振幅 (Amplitude) $y_m$** $\sin\left(2\pi \frac{x}{\text{波长 (Wavelength) } \lambda} \pm 2\pi \frac{t}{\text{周期 (Period) } T} + \text{相位常数 (Phase constant) } \phi\right)$
公式为：
$$y(x, t) = y_m \sin\left( 2\pi \frac{x}{\lambda} \pm 2\pi \frac{t}{T} + \phi \right)$$
其中 $\phi$ 读作 phi。相位以弧度 (radians) 为单位。

### Changing the position by one wavelength (改变一个波长的位置)
在特定时间，相隔一个波长的两个位置具有相同的位移。
公式推导（步骤展示）：
$$y(x_1, t) = y_m \sin\left( 2\pi \frac{x_1}{\lambda} \pm 2\pi \frac{t}{T} + \phi \right)$$
$$y(x_2, t) = y_m \sin\left( 2\pi \frac{x_2}{\lambda} \pm 2\pi \frac{t}{T} + \phi \right)$$
$$= y_m \sin\left( 2\pi \frac{x_1 + \lambda}{\lambda} \pm 2\pi \frac{t}{T} + \phi \right)$$
$$= y_m \sin\left( 2\pi \frac{x_1}{\lambda} + 2\pi \pm 2\pi \frac{t}{T} + \phi \right)$$
$$= y(x_1, t)$$
[图片：特定时间下的波形图，展示相距一个波长 $\lambda$ 的两点 $x_1$ 与 $x_2$ 的位移一致]

### Changing time be one period (改变一个周期的时间)
在特定位置，相隔一个周期的两个时间具有相同的位移。
公式推导（步骤展示）：
$$y(x, t_1) = y_m \sin\left( 2\pi \frac{x}{\lambda} \pm 2\pi \frac{t_1}{T} + \phi \right)$$
$$y(x, t_2) = y_m \sin\left( 2\pi \frac{x}{\lambda} \pm 2\pi \frac{t_2}{T} + \phi \right)$$
$$= y_m \sin\left( 2\pi \frac{x}{\lambda} \pm 2\pi \frac{t_1 + T}{T} + \phi \right)$$
$$= y_m \sin\left( 2\pi \frac{x}{\lambda} \pm 2\pi \frac{t_1}{T} + 2\pi + \phi \right)$$
$$= y(x, t_1)$$
[图片：特定位置的振荡图，展示相隔一个周期 $T$ 的两点 $t_1$ 与 $t_2$ 的位移一致]

## Angular wave number and angular frequency (角波数与角频率)
**正弦波的等效表示**
公式：
$$y(x, t) = y_m \sin(kx \pm \omega t + \phi)$$
其中：
**角波数 (Angular wave number) $k = \frac{2\pi}{\lambda}$**
SI 单位：$\text{rad/m}$ (弧度/米)
含义：$2\pi$ 米内的波长数量。

**角频率 (Angular frequency) $\omega = \frac{2\pi}{T}$**
SI 单位：$\text{rad/s}$ (弧度/秒)
含义：$2\pi$ 秒内的周期数。

**频率 (Frequency) $f = \frac{1}{T}$**
SI 单位：$\text{Hz}$ (赫兹)
含义：一秒内的周期数。
关系：$\omega = \frac{2\pi}{T} = 2\pi f$
$\omega$ 读作 omega。

## 16-4 The Speed of a Traveling Wave (行波的速度)
### Shifting a function along the x axis (沿 x 轴平移函数)
如果 $|\Delta x| = vt$，函数 $f(x - |\Delta x|)$ 的形状沿 x 轴以恒定速度 $v$ 向右移动。
[图片：波函数 $f(x)$ 向右平移 $|\Delta x|$ 到 $f(x - |\Delta x|)$ 的示意图]
**$f(x - vt)$ 以恒定速度 $v$ 向右移动。**

如果 $|\Delta x| = vt$，函数 $f(x + |\Delta x|)$ 的形状沿 x 轴以恒定速度 $v$ 向左移动。
[图片：波函数 $f(x)$ 向左平移 $|\Delta x|$ 到 $f(x + |\Delta x|)$ 的示意图]
**$f(x + vt)$ 以恒定速度 $v$ 向左移动。**

如果你**不能**将一个函数写成 $f(x - vt)$ 或 $f(x + vt)$ 的形式，那么该函数不代表行波。
例如：$\sqrt{3(x - 2t)}$ 沿 x 轴以恒定速度传播；$\sqrt{3(x^2 - 2t)}$ 不沿 x 轴以恒定速度传播。

## 16-5 The Speed of a Traveling Wave (行波的速度)
### Moving to the right (向右移动)
如果波向右传播，公式为：
$$y(x, t) = y_m \sin(-kx + \omega t + \phi)$$
可以改写为：
$$y(x, t) = y_m \sin\left[-k\left(x - \frac{\omega}{k}t\right) + \phi\right]$$
因为它具有 $f(x - vt)$ 的形式，所以波**向右**移动，速度为 $v = \frac{\omega}{k}$。
[图片：红色余弦波向右移动的示意图]
波速公式：
$$v = \frac{\omega}{k}$$

### Moving to the left (向左移动)
如果波向左传播，公式为：
$$y(x, t) = y_m \sin(kx + \omega t + \phi)$$
改写为：
$$y(x, t) = y_m \sin\left[k\left(x + \frac{\omega}{k}t\right) + \phi\right]$$
因为它具有 $f(x + vt)$ 的形式，所以波**向左**移动，速度为 $v = \frac{\omega}{k}$。
[图片：红色余弦波向左移动的示意图]
波速公式：
$$v = \frac{\omega}{k}$$

## Examples (例题)
### Example 1 (例题 1)
波由 $y(x, t) = 0.00327\sin(72.1x - 2.72t)$ 描述。所有常数均为 SI 单位。求 (a) 振幅，(b) 波长，(c) 周期，(d) 频率，(e) 波速，(f) 在 $x = 22.5 \text{cm}$ 和 $t = 18.9 \text{s}$ 处的位移，(g) 横向速度 (transverse velocity)，以及 (h) 横向加速度 (transverse acceleration)。

**解答 (Solution):**
(a) **振幅 (Amplitude) $y_m = 0.00327 \text{ m}$。**
(b) **波长 (Wavelength) $k = 72.1 \text{ rad/m} \Rightarrow \lambda = \frac{2\pi}{k} = 8.71 \text{cm}$。**
(c) **周期 (Period) $\omega = 2.72 \text{ rad/s} \Rightarrow T = \frac{2\pi}{\omega} = 2.31 \text{s}$。**
(d) **频率 (Frequency) $f = \frac{1}{T} = 0.433 \text{ Hz}$。**
(e) **波速 (Speed) $v = \frac{\omega}{k} = \frac{2.72 \text{ rad/s}}{72.1 \text{ rad/m}} = 0.0377 \text{ m/s}$。**
(f) **位移 (Displacement) $y(x, t) = 0.00327 \sin[72.1(0.225) - 2.72(18.9)] = 1.92 \text{ mm}$。**
(g) **横波速度 (Trans-velocity) $u(x, t) = \frac{\partial y}{\partial t} = 0.00327\sin(72.1x - 2.72t) = 7.20 \text{ mm/s}$。**
(h) **横向加速度 (Trans-acceleration) $a(x, t) = \frac{\partial u}{\partial t} = 0.00327(-2.72)\cos(72.1x - 2.72t) = -14.2 \text{ mm/s}^2$。**

波沿 $\text{Ox}$ 方向传播，$t=0 \text{ s}$ 时的波形为**曲线 I**，$0.5 \text{ s}$ 后波形变为**曲线 II**。设周期大于 $1 \text{ s}$。求 (a) 介质在位置 $\text{P}$ 处的振动方程（函数），以及 (b) 波的方程。

## 16-5 Wave Speed on a Stretched String (拉伸弦上的波速)
### Wave speed does not depend on the frequency (波速不取决于频率)
[图片：示意图，上方是较低频率的波，下方是较高频率的波。两者的传播速度均为 $v_0$]
弦调整其波长，使得速度 $v = \lambda f$ 保持恒定。

### Wave speed depends on the tension in the string (波速取决于弦中的张力)
[图片：上方张力为 $\tau_0$，速度为 $v_0$；下方张力为 $4\tau_0$，速度为 $2v_0$]
将弦中的张力 (tension) 增加**四倍**，波速 (speed) 会增加到**两倍**。$\tau$ 读作 tau。

---

## Wave speed depends on the linear mass density of the string (波速取决于弦的线质量密度)
[图片：上方线质量密度为 $\mu_0$，速度为 $v_0$；下方线质量密度为 $4\mu_0$，速度为 $v_0/2$]
将弦的**线质量密度** (linear mass density) 增加四倍，其波速会减半。

### Formula - speed of a wave (公式 - 波速)
[图片：公式图解，包含弦张力、波速、频率、波长]
$$v = \sqrt{\frac{\tau}{\mu}} = \lambda f$$
**$v$**: 波速 (Speed of the wave)
**$\tau$**: 弦中的张力 (Tension in the string)
**$\mu$**: 弦的线质量密度 (Linear mass density of the string)
**$\lambda$**: 波长 (Wavelength)
**$f$**: 频率 (Frequency)

拉伸弦上的波速取决于弦的**张力和线质量密度**，而不取决于波的**频率**。

### 波速公式的量纲分析 (Dimensional analysis of speed of wave formula)
$$v = \sqrt{\frac{\tau}{\mu}}$$
$$\frac{\text{m}}{\text{s}} \leftarrow \sqrt{\frac{\text{N}}{\text{kg/m}}} = \sqrt{\frac{\text{kg m/s}^2}{\text{kg/m}}} = \sqrt{\frac{\text{m}^2}{\text{s}^2}} = \frac{\text{m}}{\text{s}}$$

### 推导 (Derivation)
[图片：弦段受力分析图，半圆，张力 $\vec{\tau}$ 在两端，加速度指向中心]
总力 $\vec{F}_r$ 是弦段两端张力 $\vec{\tau}$ 之和。该段加速度为 $v^2/R$ (向心加速度)。
因为元素很小，$\theta$ 很小，我们可以使用小角度近似：$\sin \theta \approx 0$。
总径向力大小为：$F_r = 2 \tau \sin \theta \approx 2 \tau \theta$
元素的质量为 $m = \mu \Delta s$，其中 $\mu$ 是单位长度的质量。
$\Delta s = R \cdot 2\theta$，因此 $m = \mu \Delta s = 2 \mu R \theta$
对该元素应用牛顿第二定律：
$$F_r = \frac{mv^2}{R} \rightarrow 2 \tau \theta = \frac{2 \mu R \theta v^2}{R}$$
$$\tau = \mu v^2$$
解出 $v$ 得到：
$$v = \sqrt{\frac{\tau}{\mu}}$$

## 16-6 Energy and Power of a Traveling String Wave (行波弦波的能量与功率)
### Kinetic and elastic potential energies (动能和弹性势能)
[图片：示意图，上方为弦无波状态，下方为弦上有波状态，标出微元的速度 $u$]
弦上的微元 (string element) 具有**动能** (kinetic energy)，因为它正在以速度 $u$ 横向运动：
$dK = \frac{1}{2} dm \, u^2$
弦上的微元还具有**弹性势能** (elastic potential energy)，因为它被波拉伸了。
$u = \frac{\partial y}{\partial t} = -\omega y_m \cos(kx - \omega t)$
将 $dm = \mu dx$ 代入，我们得到：
$dK = \frac{1}{2}(\mu dx)(-\omega y_m)^2 \cos^2(kx - \omega t)$
动能传递的平均速率：
$$\left(\frac{dK}{dt}\right)_{avg} = \frac{1}{2} \mu v \omega^2 y_m^2 [\cos^2(kx - \omega t)]_{avg} = \frac{1}{4} \mu v \omega^2 y_m^2$$
由于平均动能和平均势能相等。
平均功率 (Average power) 为：
$$P_{avg} = 2 \left( \frac{dK}{dt} \right)_{avg} = \frac{1}{2} \mu v \omega^2 y_m^2$$

### Maximum and minimum energies (最大和最小能量)
[图片：无波时的弦，以及波在弦上不同位置的示意图]
在**最大位移处** (Maximum displacement)：
**动能**为零，零横向速度。
**弹性势能**为零，没有额外拉伸。

在**零位移处** (Zero displacement)：
**动能**最大，横向速度最大。
**弹性势能**最大，拉伸最大。

### Average power transmitted by a sinusoidal string wave (正弦弦波传递的平均功率)
[图片：位移（红色波）、动能（蓝色波，始终为正）和弹性势能（绿/蓝色波）在时间/位置上的关系图]
**能量传输 (Energy transmitted)**：平均功率 = 一个周期内传输的能量 / 一个周期
$$P_{avg} = \frac{\text{Energy transmitted in one period}}{\text{one period}}$$

### Formula - Average power transmitted by a sinusoidal string wave (公式 - 正弦弦波传递的平均功率)
$$P_{avg} = \frac{1}{2} \mu v \omega^2 y_m^2$$
**$P_{avg}$**: 波传递的平均功率 (Average power transmitted by the wave)
**$\mu$**: 线质量密度 (Linear mass density)
**$v$**: 波速 (Speed of the wave)
**$\omega$**: 角频率 (Angular frequency)
**$y_m$**: 振幅 (Amplitude)

传递的平均功率中，一半是**动能**，另一半是**弹性势能**。
$$(P_{avg})_{kinetic} = (P_{avg})_{elastic} = \frac{1}{4} \mu v \omega^2 y_m^2$$
任何机械波传递的平均功率都与其**振幅的平方**和**频率的平方**成正比。

### Example 3 (例题 3)
正弦波在弦上：
频率 $f = 120 \text{ Hz}$
振幅 $y_m = 8.5 \text{ mm}$
线质量密度 $\mu = 525 \text{ g/m}$
张力 $\tau = 45 \text{ N}$
波输送能量的平均速率是多少？

**解答 (Solution):**
$$P_{avg} = \frac{1}{2} \mu v \omega^2 y_m^2$$
我们需要求 $v$ 和 $\omega$。
$\omega = 2\pi f = 2\pi(120 \text{Hz}) = 754 \text{ rad/s}$
$$v = \sqrt{\frac{\tau}{\mu}} = \sqrt{\frac{45\text{N}}{0.525 \text{kg/m}}} = 9.26 \text{ m/s}$$
$$P_{avg} = \frac{1}{2} (0.525 \text{kg/m})(9.26 \text{m/s})(754 \text{rad/s})^2 (0.0085 \text{m})^2$$
$$= 100 \text{W}$$

## 16-7 The Wave Equation (波动方程)
**将牛顿第二定律应用于弦元素：**
[图片：弦元素受力分析图，展示张力 $F_1, F_2$ 及其分量]
$F_{2y} - F_{1y} = dm \, a_y$
$F_{1y} = F_{1x} S_1 \approx \tau S_1$ （$\tau = F_1$，$S_1$ 为斜率）
$F_{2y} = F_{2x} S_2 \approx \tau S_2$ （$\tau = F_2$）
$\tau S_2 - \tau S_1 = (\mu dx) \frac{d^2 y}{dt^2}$
$dS = \frac{d(dy/dx)}{dx} dx = \frac{\mu d^2 y}{\tau dt^2} dx$
$$\frac{\partial^2 y}{\partial x^2} = \frac{\mu}{\tau} \frac{\partial^2 y}{\partial t^2}$$
因为波速 $v = \sqrt{\tau / \mu}$。
**波方程 (Wave Equation)：**
$$\frac{\partial^2 y}{\partial x^2} = \frac{1}{v^2} \frac{\partial^2 y}{\partial t^2}$$

## 16-8 The Principle of Superposition for Waves (波的叠加原理)
[图片：两列波相互穿过而无碰撞的示意图]
**叠加原理 (The principle of superposition for waves):**
**合成波的位移** = **波 1 的位移** + **波 2 的位移**
$$y'(x, t) = y_1(x, t) + y_2(x, t)$$
波 1 穿过波 2，就像波 2 不存在一样。

## 16-9 Interference of Waves (波的干涉)
**两波沿相同方向运动 (Two waves moving in the same direction)**
[图片：波 1 和波 2 沿相同方向运动干涉产生合成波的示意图]
当两个或多个波同时在同一介质中运动时，会发生波的干涉 (Interference)。
两个同向运动的波在同一弦上干涉产生合成波。

### Formula - interference of two sinusoidal waves (公式 - 两个正弦波的干涉)
两个具有相同振幅和频率、沿相同方向运动的波：
$y'(x, t) = y_1(x, t) + y_2(x, t)$
$y'(x, t) = y_m \sin(kx - \omega t) + y_m \sin(kx - \omega t + \phi)$
使用三角恒等式 $\sin \alpha + \sin \beta = 2 \cos \frac{1}{2}(\alpha - \beta) \sin \frac{1}{2}(\alpha + \beta)$
$$y'(x, t) = \left[ 2y_m \cos \frac{1}{2}\phi \right] \sin\left( kx - \omega t + \frac{1}{2}\phi \right)$$
**合成波**具有与 $y_1(x, t)$ 和 $y_2(x, t)$ 相同的波长和频率。
$\phi$ 是波 1 和波 2 之间的**相位差** (phase difference)。

---

## In phase and out of phase (同相和反相)
$y_1(x, t) = y_m \sin(kx - \omega t)$
$y_2(x, t) = y_m \sin(kx - \omega t + \phi)$
两波间的相位差 = 波 2 的相位 - 波 1 的相位
$= (kx - \omega t + \phi) - (kx - \omega t) = \phi$

如果相位差 $\phi = 0$ 或 $2\pi$ 的整数倍，我们说波 1 和波 2 **同相** (in phase)。
如果相位差 $\phi = \pi$ 或 $\pi$ 的奇数倍，我们说波 1 和波 2 **反相** (out of phase)。
对于一般的相位差 $\phi$，我们说波 1 和波 2 是“不同相的”。

### Constructive interference (相长干涉)
**合成波**：
$$y'(x, t) = 2y_m \cos \frac{1}{2}\phi \sin\left(kx - \omega t + \frac{1}{2}\phi\right)$$
**特殊情况：**
相位差 $\phi = 0$ 或 $2\pi$ 的整数倍（波 1 和波 2 同相）。
此时发生**相长干涉**。
[图片：波 1 与波 2 波形完全重合/对齐，相加后产生振幅为 $2y_m$ 的合成波]
波 1 和波 2 干涉**相长**。
$y'(x, t) = 2y_m \sin(kx - \omega t + \frac{1}{2}\phi)$
**最大振幅** (Maximum amplitude) = $2y_m$。

### Destructive interference (相消干涉)
**合成波**：
$$y'(x, t) = 2y_m \cos \frac{1}{2}\phi \sin\left(kx - \omega t + \frac{1}{2}\phi\right)$$
**特殊情况：**
相位差 $\phi = \pi$ 或 $\pi$ 的奇数倍（波 1 和波 2 反相）。
此时发生**相消干涉**。
[图片：波 1 与波 2 波峰波谷完全错开（反相），相加后振幅为零的合成波]
波 1 和波 2 干涉**相消**。
$y'(x, t) = 0$

### Radian to wavelength (弧度与波长的转换)
以波长表示的相位差：
[图片：波 1 和波 2 之间的相位差 $\phi$ 示意图（$0.6\lambda$）]
$y_1(x, t) = y_m \sin(kx - \omega t)$
相位差 = $3.8 \text{ rad}$。移动的距离 = ?
$y_2(x, t) = y_m \sin(kx - \omega t - 3.8)$
因为 $k = \frac{2\pi}{\lambda}$，
$y_2(x, t) = y_m \sin[k(x - 0.6\lambda) - \omega t]$
$$\text{距离} = 3.8 \text{ rad} \left( \frac{\lambda}{2\pi \text{ rad}} \right) = 0.60 \lambda$$
我们可以说：
两波相差 $3.8 \text{ rad}$。
或者，两波相差 $0.60$ 个波长。

## Example 4 (例题 4)
两个振幅相同、沿相同方向移动的波互相干涉。每个波的振幅为 $y_m = 9.8 \text{ mm}$。它们之间的相位差为 $100^\circ$。
(a) 合成波的振幅是多少？发生什么类型的干涉？
(b) 需要多大的相位差（用弧度表示）和波长差，才能产生 $4.9 \text{ mm}$ 的合成波振幅？

**解答 (Solution):**
(a)
$$y'_m = |2y_m \cos \frac{1}{2}\phi| = 2(9.8 \text{mm}) \cos(100^\circ / 2) = 13 \text{mm}$$
这种干涉是**中等**的（intermediate），因为 $y'_m$ 介于 0 和 $2y_m = 19.6 \text{mm}$ 之间。

(b)
要达到合成振幅 $4.9 \text{ mm}$：
$4.9 = 2(9.8 \text{mm}) \cos(\frac{1}{2}\phi)$
$\phi = 2 \cos^{-1} \left( \frac{4.9 \text{mm}}{2(9.8 \text{mm})} \right)$
$= 2 \cos^{-1}(0.25) = \pm 2.6 \text{ rad}$
相位差（弧度）：
$$\phi = \frac{\text{波长}}{2\pi \text{ rad}} = \frac{(\pm 2.6 \text{ rad})}{2\pi \text{ rad}} \text{波长} = \pm 0.42 \text{ wavelength}$$

## 16-10 Phasors (相量)
波可以用相量 (phasor) 来向量化表示，相量的大小等于波的振幅，并绕原点以恒定角速度 $\omega$ 旋转。
[图片：相量相加示意图，在复平面/坐标系中，向量 $y_1$ 与 $y_2$ 相加得到 $y'$]
$y_1(x, t) = y_{1m} \sin(kx - \omega t + \phi_1)$
$y_2(x, t) = y_{2m} \sin(kx - \omega t + \phi_2)$
$y'(x, t) = y_1(x, t) + y_2(x, t)$
$y'_{mv} = y_{1mv} + y_{2mv} = y_1 + y_2$
$y'_{mh} = y_{1mh} + y_{2mh} = x_1 + x_2$
合成振幅：
$$y'_m = \sqrt{y'^2_{mv} + y'^2_{mh}}$$
相位：
$$\beta = \tan^{-1} \frac{y'_{mv}}{y'_{mh}}$$
合成波公式：
$$y'(x, t) = y'_m \sin(kx - \omega t + \beta)$$
即使波有不同的振幅，我们也可以使用**相量**来合并它们。

## 16-11 Standing Waves and Resonance (驻波与共振)
### At Resonance (共振时)
[图片：振动器发出右行波和左行波在固定端反射，形成驻波的示意图]
**右行波 (Right-going waves) + 左行波 (Left-going waves) = 合成波 (Resultant wave)**
对于振子特定的频率，合成波的振幅会非常大。这些频率被称为**共振频率** (resonant frequencies)。在共振时，右行波和左行波**同相**。

### Not at resonance (非共振时)
[图片：右行波和左行波不匹配，合成波振幅很小的示意图]
如果右行波和左行波不同相，在这种情况弦不发生共振（合成波振幅很小）。

## Mathematical Description of Standing Wave (驻波的数学描述)
两列具有相同波长和振幅的正弦波在拉伸弦上沿相反方向传播。
$y_1(x, t) = y_m \sin(kx - \omega t)$
$y_2(x, t) = y_m \sin(kx + \omega t)$
叠加原理给出了合成波：
$$y'(x, t) = y_1(x, t) + y_2(x, t) = y_m \sin(kx - \omega t) + y_m \sin(kx + \omega t)$$
$$y'(x, t) = [2y_m \sin kx] \cos \omega t$$
此等式中的 **$2y_m \sin kx$** 为在位置 $x$ 处的**振幅**（随位置变化的振幅）。
$kx = n\pi, n = 0, \pm 1, \dots \Rightarrow \sin(kx) = 0, y(x, t) = 0$
因此 $x = n\frac{\lambda}{2}$。**波节** (Nodes) 相距 $\lambda/2$ 且分隔两个波节。
$kx = \left( n + \frac{1}{2} \right) \pi, n = 0, \pm 1, \dots \Rightarrow |\sin(kx)| = 1$
因此 $x = \left( n + \frac{1}{2} \right) \frac{\lambda}{2}$。**波腹** (Antinodes) 相距 $\lambda/2$。

## Reflections at a Boundary (在边界处的反射)
**入射波** (incident wave) 和**反射波** (reflected wave) 可以结合形成驻波模式。
(a) 弦固定 (String is fixed)
[图片：绳子固定在墙上，一列波遇到墙反射回来，边界处为波节]
必须是**波节** (Node)，因为弦在该点固定。
对于固定端：相位改变 $\pi$。

(b) 弦自由滑动 (String is free to slide)
[图片：波遇到自由端，边界处为波腹]
必须是**波腹** (Antinode)，因为弦在该点无摩擦地上下移动。
对于自由端：没有相位改变。

### Example 5 (例题 5)
波 $y = A\cos 2\pi(t/T - x/\lambda)$ 向右传播，它可以在表面反射，反射点 B 距离原点 $5\lambda$，并且在 B 处存在**半波损失** (half wave loss)。求 (a) 反射波的函数，(b) 驻波的函数，(c) O 和 B 之间波节与波腹的位置。

**解答 (Solution):**
(a) 在位置 B 处的振动方程：
$$y_{B \text{in}} = A \cos 2\pi(t/T - l/\lambda)$$ ✔
由于在半波损失位置 B，反射波振动方程重写为：
$$y_{B \text{re}} = A \cos[ 2\pi(t/T - l/\lambda) - \pi ]$$ ✔
设 P 点为沿反射路径的一点，其坐标为 $x$。因此其相位滞后于 B 的相位 $(l-x) \cdot 2\pi / \lambda$，因此反射波函数可以表示为：
$$y_{\text{re}} = A \cos[ 2\pi(t/T - l/\lambda) - \pi - (l-x) \cdot 2\pi / \lambda ]$$ ✔
将 $l = 5\lambda$ 代入方程中，我们得到：
$$y_{\text{re}} = -A \cos 2\pi(t/T + x/\lambda)$$ ✔

(b) 驻波函数：
$y_{\text{in}} = A \cos 2\pi(t/T - x/\lambda)$
$y_{\text{re}} = -A \cos 2\pi(t/T + x/\lambda)$
$y = y_{\text{in}} + y_{\text{re}} = 2A \sin(2\pi x / \lambda) \cdot \sin(2\pi t / T)$ ✔

(c) O 和 B 之间的波节和波腹位置：
令 $\sin(2\pi x / \lambda) = 0$，我们得到波节的位置：
$x = k\lambda/2 \quad k=0, 1, 2, \dots, 10$
$x = 0, \lambda/2, \lambda, 3\lambda/2, 4\lambda/2, 5\lambda/2, 3\lambda, 7\lambda/2, 4\lambda, 9\lambda/2, 5\lambda$ ✔
令 $|\sin(2\pi x / \lambda)| = 1$，我们得到波腹的位置：
$x = (2k + 1)\lambda/4 \quad k=0, 1, 2, \dots, 10$
$x = \lambda/4, 3\lambda/4, 5\lambda/4, 7\lambda/4, 9\lambda/4, 11\lambda/4, 13\lambda/4, 15\lambda/4, 17\lambda/4, 19\lambda/4$ ✔

## 16-11 Standing Waves and Resonance (驻波与共振)
### Harmonics (谐波)
[图片：基波、二次谐波、三次谐波、四次谐波的波形图]
$n$: **谐波数** (Harmonic number)
$\lambda_n$: **共振波长** (Resonant wavelength)
$f_n$: **共振频率** (Resonant frequency)
公式：
$$\lambda_n = \frac{2L}{n}, \quad f_n = n \frac{v}{2L}$$

### Resonant frequencies (共振频率)
[图片：振子与固定端之间的驻波，往返距离为 $2L$]
两个连续的右行波之间的距离为 $2L$。
为了干涉相长 (constructive interference)，两波的相位差是 $n \cdot 2\pi \text{ rad}$
即 $n\lambda = n \lambda$，对于 $n = 1, 2, \dots$
共振发生在：
$2L = n\lambda$
根据 $\lambda = \frac{v}{f}$，
$$f = \frac{v}{\lambda} \Rightarrow f_n = n \frac{v}{2L}$$
其中 $n = 1, 2, \dots$

### Example 6 (例题 6)
[图片：长度为 L=1.2m 的弦，一端为振动器（振幅很小可视为节点），另一端为支撑物]
$L = 1.2 \text{ m}, \quad \mu = 1.6 \text{ g/m}$
振子频率 $f = 120 \text{ Hz}$。

(a) 使得弦在其第四次谐波 (fourth harmonic) 处共振的块体质量是多少？
$$v = \sqrt{\frac{\tau}{\mu}} = \sqrt{\frac{mg}{\mu}}$$
根据 $n=4$ 的情况：
$\sqrt{\frac{mg}{\mu}} = \frac{2Lf}{n}$
$$m = \left( \frac{2Lf}{n} \right)^2 \frac{\mu}{g} = \left( \frac{2(1.2\text{m})(120\text{Hz})}{4} \right)^2 \frac{0.0016 \text{kg/m}}{(9.8 \text{m/s}^2)} = 0.85 \text{kg}$$

(b) 如果块体质量 $m = 10 \text{ kg}$，设置的是什么驻波模式？
$$n = \frac{2Lf}{\sqrt{mg/\mu}} = \frac{2Lf}{\sqrt{\frac{\mu}{mg}}} = 3.7$$
$n$ 必须是整数。$n=3.7$ 是不可能的，因此振子无法在弦上建立驻波。
