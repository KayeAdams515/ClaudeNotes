# C10.1 支持向量机的目标与大间隔

> [!abstract] 本讲任务
> 两条分界线都把训练样本分对了，一条紧贴着样本，另一条在两类中间留下了更宽的空隙。你会选哪条？支持向量机把“分对之外，还要留余地”写进了优化目标。
>
> 我们从熟悉的逻辑回归出发，换一种损失函数，解释参数 $C$，再看大间隔为什么遇到离群点时也需要妥协。

> [!info] 怎么读这份讲义
> 先回顾 [[C2.5 逻辑回归]] 与 [[C2.7 过拟合与正则化]]。本篇沿用 $y\in\{0,1\}$；需要写统一间隔形式时，会另定义 $t=2y-1\in\{-1,+1\}$。目前无本学期对应转写稿，“拓展”标识标准理论的进一步展开。p6 留空的预测规则在 p7 有完整手写，不属于知识缺失。

## 1. 从逻辑回归的分数开始

你在做二分类，二维平面上两类样本可以被直线分开。但其中一条线几乎擦着一个样本通过，只要输入有一点测量误差，就可能把它推到另一侧。另一条线离两边最近的样本都更远，看起来更稳妥。

我们先别急着给“远”下定义，回到逻辑回归。令

$$z=\theta^Tx=\theta_0+\sum_{j=1}^n\theta_jx_j,\qquad h_\theta(x)=g(z)=\frac1{1+e^{-z}},\quad x_0=1.$$

$z$ 是分类分数，sigmoid 把它转成概率。对正例 $y=1$，我们希望 $h_\theta(x)$ 接近 1，这要求 $z$ 显著大于 0；对负例 $y=0$，希望 $h_\theta(x)$ 接近 0，这要求 $z$ 显著小于 0。

![[C10.1-板书-逻辑回归的分数解释.png]]

这里已经出现了区别：**预测为正只要求 $z\ge0$，但有把握地预测正确往往要求 $z$ 离 0 更远。** 不过 $z$ 还不是几何距离，因为放大整组 $\theta$ 就会把分数放大，这个问题下一讲会专门解决。

## 2. 换一种损失：分数达到要求以后，不再继续奖励

### 2.1 把对数损失改写成 $z$ 的函数

单个样本的逻辑回归损失为

$$-y\log g(z)-(1-y)\log(1-g(z)).$$

若 $y=1$，只剩

$$\ell_1(z)=-\log g(z)=\log(1+e^{-z});$$

若 $y=0$，只剩

$$\ell_0(z)=-\log(1-g(z))=\log(1+e^z).$$

因此，正例的损失随着 $z$ 增大不断下降，负例的损失随着 $z$ 减小不断下降。两者都在有限分数下大于 0。

### 2.2 朴素想法：够好了以后能不能就记零损失

支持向量机 **Support Vector Machine，SVM** 可以从一种分段直线替代来理解：正例达到 $z\ge1$ 就记零损失，负例达到 $z\le-1$ 就记零损失，没有达到要求时按缺口惩罚。

$$\operatorname{cost}_1(z)=\max(0,1-z)=\begin{cases}1-z,&z<1,\\0,&z\ge1,\end{cases}$$

$$\operatorname{cost}_0(z)=\max(0,1+z)=\begin{cases}0,&z\le-1,\\1+z,&z>-1.\end{cases}$$

这就是**合页损失 Hinge Loss** 的两种标签写法。单位斜率是这里采用的标准归一化；把整项损失乘上正数，可以吸收到后面的 $C$ 中。

![[C10.1-板书-对数损失到合页损失.png]]

![[C10-对数损失与合页损失.png]]

补画的两个面板横轴都是 $z$，纵轴都是损失；左面板真实标签为 1，右面板为 0。不要把右图的零损失区读成 $z\le1$，正确分界是 **$-1$**。

> [!question] 停一下，先自己想想
> 一个正例的分数是 $z=0.5$。它分错了吗？它的 SVM 损失是 0 吗？

它没有分错，因为分数已经大于 0；但损失是 $1-0.5=0.5$，因为它仍没有达到正例应有的 $z\ge1$。所以 **SVM 不仅惩罚错分类，也惩罚“分对了但余地不够”**。

> [!example] 正例的五个分数
> 当 $z=-2,0,0.5,1,2$ 时，$\operatorname{cost}_1(z)$ 依次为 $3,1,0.5,0,0$。跨过分类阈值 0 还不够，到达间隔阈值 1 才停止惩罚。

## 3. 优化目标中的 $C$ 从哪里来

### 3.1 先区分两次变化

正则化逻辑回归的目标可以记成

$$\frac1m\left[A_{log}(\theta)+\lambda B(\theta)\right],\qquad B(\theta)=\frac12\sum_{j=1}^n\theta_j^2,$$

其中 $A_{log}$ 是全部样本的对数损失之和。**把对数损失换成合页损失，是改变了学习算法，不是等价变形。** 换完以后，记

$$A_{hinge}(\theta)=\sum_{i=1}^m\left[y^{(i)}\operatorname{cost}_1(\theta^Tx^{(i)})+(1-y^{(i)})\operatorname{cost}_0(\theta^Tx^{(i)})\right].$$

现在才作等价的缩放：当 $\lambda>0$ 时，将 $\frac1m(A_{hinge}+\lambda B)$ 乘以正数 $m/\lambda$，最优参数的位置不变，得到

$$\boxed{\min_\theta\;C A_{hinge}(\theta)+\frac12\sum_{j=1}^n\theta_j^2,\qquad C=\frac1\lambda.}$$

![[C10.1-板书-目标改写与C的由来.png]]

为什么正数缩放不改变最小点？若 $F(a)\le F(b)$，乘 $k>0$ 后仍有 $kF(a)\le kF(b)$。例如 $(u-5)^2+1$ 与 $10(u-5)^2+10$ 都在 $u=5$ 最小，最小值分别是 1 与 10；变了的是目标数值，不是参数位置。

> [!warning] $C=1/\lambda$ 有归一化前提
> 上式对应本课 $\frac1m\sum\ell+\frac\lambda{2m}\lVert\theta\rVert^2$ 的写法。若另一资料用 $\frac1m\sum\ell+\frac\lambda2\lVert w\rVert^2$，换成 $C\sum\ell+\frac12\lVert w\rVert^2$ 后应为 $C=1/(m\lambda)$。比较参数前先看完整目标，不要只比较字母。

### 3.2 $C$ 是“违规损失”相对有多贵

$C$ 大时，合页损失很昂贵，模型更努力满足每个样本的间隔要求；这对应较弱的相对正则化。$C$ 小时，参数大小受到更强的相对约束，模型可以为更简单的边界容忍更多间隔违规。

参数 $\theta_0$ 仍然不在平方惩罚中，这与前面的回归正则化一致。训练时求目标最小值；预测时则只看分数符号：

$$\boxed{h_\theta(x)=\begin{cases}1,&\theta^Tx\ge0,\\0,&\theta^Tx<0.\end{cases}}$$

![[C10.1-板书-SVM预测规则.png]]

> [!important] SVM 的输出含义
> 本课的 $h_\theta(x)$ 是类别 0 或 1，原始分数 $\theta^Tx$ 不是正类概率。逻辑回归的 sigmoid 概率解释不能直接搬过来。

## 4. 大间隔直觉：为什么“把样本分开”还不够

### 4.1 零损失要求更严格

对于正例，零损失要求 $\theta^Tx^{(i)}\ge1$；对于负例，零损失要求 $\theta^Tx^{(i)}\le-1$。仅仅符号正确不一定够。

![[C10.1-板书-零损失的间隔要求.png]]

> [!warning] p9 的一处手写漏号
> 负例损失图旁的蓝字写成了 $z\le1$，但曲线拐点与同页正式条件都在 $-1$。正确零损失区为 $z\le-1$。

如果数据**线性可分 Linearly Separable**，存在一个直线或高维超平面把全部样本分开。此时把 $C$ 取得足够大，可以理解为优先让所有训练合页损失为 0，再在满足条件的参数中寻找平方范数最小者：

$$\min_\theta\frac12\sum_{j=1}^n\theta_j^2\quad\text{s.t.}\quad\begin{cases}\theta^Tx^{(i)}\ge1,&y^{(i)}=1,\\\theta^Tx^{(i)}\le-1,&y^{(i)}=0.\end{cases}$$

“s.t.” 表示 subject to，即“满足以下约束”。示例 $C=100000$ 仅用于表达“损失很贵”的直觉，不是保证所有数据都零损失的通用阈值。

![[C10.1-板书-大C与约束优化.png]]

### 4.2 更宽的走廊从哪里来

在平面上画出所有分对数据的直线，你会发现有些线偏向某一类、离最近的样本很近，有些线则在两类之间留下更宽的通道。SVM 的上述目标选出的是**大间隔分类器 Large Margin Classifier**。

![[C10.1-板书-最大间隔分界线.png]]

现在先记住对应关系：在 $\pm1$ 的分数约束下，减小非偏置参数的范数会扩大几何间隔。为什么不是把参数缩成 0 就能无限扩大间隔？因为缩得过小会违反这些约束。下一讲用投影把这件事完整算出来。

## 5. 一个离群点就能让“全部分对”变得不划算

假设大部分正负样本明显分成两堆，却有一个负例落到正例附近。为了把这个孤立样本也分对，一条原本合理的分界线可能被迫剧烈倾斜，使大量其他样本离边界更近。

$C$ 非常大时，模型更不愿承担这个点的损失，因此可能牺牲整体间隔去照顾它。$C$ 适中时，可以接受该点违反间隔甚至被错分，换取更合理的整体边界。

![[C10.1-板书-离群点与C的取舍.png]]

所以“支持向量机总会把每个训练样本分对”是不正确的。有限 $C$ 的目标本来就在作取舍；即使线性可分，也可能因 $C$ 较小而接受训练错误。不可分数据更不可能强行满足全部硬约束。

### 5.1 把“允许违规”写清楚（拓展）

令 $t_i=2y^{(i)}-1$，正例为 $+1$，负例为 $-1$，并写 $z_i=w^Tx^{(i)}+b$。两种损失可合并为 $\max(0,1-t_iz_i)$。

引入**松弛变量 Slack Variable** $\xi_i\ge0$，表示第 $i$ 个样本距离间隔要求还差多少：

$$\min_{w,b,\xi}\frac12\lVert w\rVert^2+C\sum_i\xi_i,\qquad t_i(w^Tx^{(i)}+b)\ge1-\xi_i,\quad\xi_i\ge0.$$

对于固定的 $w,b$，最省钱的选择正好是 $\xi_i=\max(0,1-t_iz_i)$，因此它与合页损失目标等价。这就是**软间隔 Soft Margin**；完全不允许违规的版本叫硬间隔 Hard Margin。

$0<\xi_i<1$ 时通常仍分对，但处在间隔内部；$\xi_i>1$ 时分数已经在错误一侧；$\xi_i=1$ 位于决策边界，类别取决于边界上的约定。

## 6. 小结

> [!important] 这一讲的三句话
> 1. SVM 的合页损失要求正例分数至少为 1、负例至多为 −1，因此分对不一定零损失。
> 2. 目标 $C\sum\ell+\frac12\lVert w\rVert^2$ 在间隔违规与参数大小之间取舍；$C$ 越大，违规越贵。
> 3. 线性可分且足够重视零违规时得到大间隔直觉；有离群点或不可分数据时，软间隔允许必要的妥协。
