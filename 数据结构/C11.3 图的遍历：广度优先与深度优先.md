# C11.3 图的遍历：广度优先与深度优先

> [!abstract] 这一讲的任务
> 树有根，所以"遍历"有个天然的起点和方向：从根往下走。图没有根，也没有"往下"——从一个顶点出发，它可能通向任何地方，而且**可能绕回自己走过的路**。
> 这一讲给两种走法：**广度优先** 用队列，一层层往外铺；**深度优先** 用栈（或递归），一条路走到黑再回头。两种都只比"看一遍顶点和边"多一点点开销：$\Theta(|V|+|E|)$。后面几乎所有图算法都建立在它们之上——连通分量、无权最短路、二分图判定、拓扑排序、生成树，都是它们的变体。

## 走之前必须先解决"绕圈"

先看一个具体的问题。下面这张图有 9 个顶点、12 条边：

![[C11-遍历-九顶点示例图.png]]

邻接关系按字母序列出来是：

| 顶点 | 邻居 |
| --- | --- |
| $A$ | $B,C,E$ |
| $B$ | $A,C,D$ |
| $C$ | $A,B,D,E,F$ |
| $D$ | $B,C$ |
| $E$ | $A,C,G,H$ |
| $F$ | $C$ |
| $G$ | $E,I$ |
| $H$ | $E,I$ |
| $I$ | $G,H$ |

图里有环：$A\to B\to C\to A$ 就是一个。如果只是"能走就走"，从 $A$ 出发会走进 $A\to B\to C\to A\to B\to\cdots$，**永远出不来**。

所以遍历的第一条规则不是"怎么走"，而是：

> [!important] 访问标记 Visited
> 每个顶点带一个标记，**第一次到达时置位**，之后再遇到就跳过。
> 有了它，"绕着环转"就变成了"走到已访问的点就停下"，遍历必然在有限步内结束。

标记需要多少空间？$\Theta(|V|)$ 个布尔量，也就是每个顶点一位。材料给了两种实现：

- **散列表**：顶点是对象（不是 $0\sim n-1$ 的整数）时用它，按地址查；
- **位数组**：如果顶点能编号，$|V|/8$ 个字节就够——一百万个顶点只要 125 KB。

## 两种走法的骨架

遍历也叫**搜索** search：找的不是某个特定顶点，而是"从起点能到达的全部顶点"。材料把两种策略的差别压缩成一句话：

- **广度优先** BFS：用**队列**——先到先展开，像水波一圈圈往外推；
- **深度优先** DFS：用**栈**——后到先展开，像走迷宫时一路摸着墙走到底。

（递归的 DFS 用的是**调用栈**，不是显式栈；两者等价，但占的内存位置不同。）

复杂度上有一条必须记住的界：

$$T_{\text{遍历}}=\Theta\bigl(|V|+|E|\bigr).$$

- **下界**：每个顶点至少要访问一次、每条边至少要检查一次（否则无法确认"都到过了"），所以不能比这更少；
- **上界**：用邻接表时，每个顶点入队/出队一次、每条边被两端各看一次，正好是这个量级；
- 连通图可以把 $|V|$ 省掉（$|E|\ge|V|-1$），变成 $\Theta(|E|)$；
- **用邻接矩阵时** 是 $\Theta(|V|^2)$——因为列一遍邻居要扫一整行。

## 广度优先：队列

> [!important] 广度优先遍历 BFS
> 1. 任选一个顶点，标记为已访问，**入队**；
> 2. 当队列非空：
>    - 弹出队首顶点 $v$；
>    - 对 $v$ 的每个邻居 $w$：若 $w$ 未访问，**标记并入队**；
> 3. 队列空时结束。若所有顶点都被访问，图连通；否则从任一未访问顶点重新开始，就得到下一个连通分量。

第 2 步里"标记"和"入队"必须**同时发生**——只入队不标记，同一个顶点会被重复入队好几次。

```cpp
void Graph::breadth_first_traversal(Vertex *first) const {
    std::unordered_map<Vertex *, int> hash;   // 访问标记
    hash.insert(first);
    std::queue<Vertex *> queue;
    queue.push(first);

    while (!queue.empty()) {
        Vertex *v = queue.front();
        queue.pop();
        // 在这里对 v 做该做的事（打印、记录距离……）

        for (Vertex *w : v->adjacent_vertices()) {
            if (!hash.member(w)) {            // 没访问过
                hash.insert(w);
                queue.push(w);
            }
        }
    }
}
```

队列里最多装多少个顶点？每个顶点最多入队一次，所以 $O(|V|)$。这也是 BFS 的内存瓶颈所在：图很宽（比如一个中心顶点连着十万个叶子）时，队列会很长。

### 走一遍示例图

![[C11-遍历-BFS十步演示.png]]

> [!note] 图解：九顶点示例图的 BFS 十步演进
> 起点 `A` 入队后，每轮弹出队首并将未访问邻居按序入队（`A` → `B,C,E` → `D` → `F` → `G,H` → `I`），队列为空时遍历结束，访问序列严格按到起点距离分层展开。

从 $A$ 开始，按邻居表里的字母顺序展开：

| 步骤 | 弹出 | 新入队 | 队列（队首在左） | 已访问序列 |
| --- | --- | --- | --- | --- |
| 0 | — | $A$ | $A$ | $A$ |
| 1 | $A$ | $B,C,E$ | $B,C,E$ | $A,B,C,E$ |
| 2 | $B$ | $D$ | $C,E,D$ | $A,B,C,E,D$ |
| 3 | $C$ | $F$ | $E,D,F$ | $A,B,C,E,D,F$ |
| 4 | $E$ | $G,H$ | $D,F,G,H$ | $A,B,C,E,D,F,G,H$ |
| 5 | $D$ | — | $F,G,H$ | 同上 |
| 6 | $F$ | — | $G,H$ | 同上 |
| 7 | $G$ | $I$ | $H,I$ | $A,B,C,E,D,F,G,H,I$ |
| 8 | $H$ | — | $I$ | 同上 |
| 9 | $I$ | — | 空 | 结束 |

最后一行排序：$A,B,C,E,D,F,G,H,I$。

注意第 3 步：$C$ 的邻居有五个（$A,B,D,E,F$），其中 $A,B,D,E$ 全都访问过了，**只有 $F$ 是新的**。这就是"绕圈"被标记挡住的地方——而且挡得干净利落，不需要额外判断。

## 深度优先：栈

> [!important] 深度优先遍历 DFS
> 1. 任选一个顶点，标记为已访问；
> 2. 从它出发：
>    - 若有**未访问** 的邻居，走进去（标记它，继续从它出发）；
>    - 若没有未访问的邻居，**退回** 上一个还有未访问邻居的顶点；
> 3. 一直退到没有任何顶点还有未访问邻居为止。

两种实现。**递归版** 把"退回"交给调用栈：

```cpp
void Graph::depth_first_traversal(Vertex *first) const {
    std::unordered_map<Vertex *, int> hash;
    hash.insert(first);
    first->depth_first_traversal(hash);
}

void Vertex::depth_first_traversal(std::unordered_map<Vertex *, int> &hash) const {
    // 在这里对本顶点做该做的事
    for (Vertex *v : adjacent_vertices()) {
        if (!hash.member(v)) {
            hash.insert(v);
            v->depth_first_traversal(hash);
        }
    }
}
```

**迭代版** 把"退回"交给显式栈：

```cpp
void Graph::depth_first_traversal(Vertex *first) const {
    std::unordered_map<Vertex *, int> hash;
    hash.insert(first);
    std::stack<Vertex *> stack;
    stack.push(first);

    while (!stack.empty()) {
        Vertex *v = stack.top();
        stack.pop();
        for (Vertex *w : v->adjacent_vertices()) {
            if (!hash.member(w)) {
                hash.insert(w);
                stack.push(w);
            }
        }
    }
}
```

> [!warning] 迭代版和递归版的访问顺序可能不同
> 上面的迭代版是"弹出一个顶点、把它所有未访问的邻居一口气压栈"。栈是后进先出，所以**最后一个被压进去的邻居会最先被取出**——顺序与递归版（按邻居表顺序深入）**相反**。
> 两者都是合法的 DFS，但**输出的序列不一样**。考试写"DFS 序列"时，必须先确认是递归还是迭代、邻居按什么次序访问。

### 走一遍示例图（递归版）

![[C11-遍历-DFS九步演示.png]]

> [!note] 图解：九顶点示例图的 DFS 九步演进
> 从 `A` 出发一路沿未访问邻居深入（`A → B → C → D`），遇死路回溯至最近仍有未访问邻居的顶点（`B → E → F → H → G → I`），直至所有可达顶点访问完毕。

![[Pasted image 20261126142404.png]]

| 步骤 | 当前 | 动作 | 已访问序列 |
| --- | --- | --- | --- |
| 1 | $A$ | 访问 $A$，邻居 $B$ 未访问，深入 | $A$ |
| 2 | $B$ | 访问 $B$，邻居 $C$（$A$ 已访问），深入 | $A,B$ |
| 3 | $C$ | 访问 $C$，邻居 $D$（$A,B$ 已访问），深入 | $A,B,C$ |
| 4 | $D$ | 访问 $D$，邻居 $B,C$ 都访问过——**无路可走，退回 $C$** | $A,B,C,D$ |
| 5 | $C$ | 继续看邻居：$E$ 未访问，深入 | $A,B,C,D,E$ |
| 6 | $E$ | 邻居 $A,C$ 已访问，$G$ 未访问，深入 | $A,B,C,D,E,G$ |
| 7 | $G$ | 邻居 $E$ 已访问，$I$ 未访问，深入 | $A,B,C,D,E,G,I$ |
| 8 | $I$ | 邻居 $G$ 已访问，$H$ 未访问，深入 | $A,B,C,D,E,G,I,H$ |
| 9 | $H$ | 邻居 $E,I$ 都访问过，退回 $I\to G\to E\to C$ | 同上 |
| 10 | $C$ | 还有 $F$ 未访问，深入 | $A,B,C,D,E,G,I,H,F$ |
| 11 | $F$ | 只有邻居 $C$，已访问；退回 $C$，$C$ 的邻居看完；再退回 $A$，全图结束 | 同上 |

序列：$A,B,C,D,E,G,I,H,F$。

两条序列并排看：

| | 顺序 |
| --- | --- |
| 广度优先 | $A,B,C,E,D,F,G,H,I$ |
| 深度优先 | $A,B,C,D,E,G,I,H,F$ |

都以 $A$ 开头，之后很快分道扬镳：BFS 把 $A$ 的三个邻居（$B,C,E$）一次全铺开，DFS 则沿着 $B\to C\to D$ 一路钻到底。**同一张图、同一个起点，两种遍历给出的顺序可以差得很远**——这也是为什么"遍历顺序"从来不是图的性质，而是"算法 + 起点 + 邻居次序"三者的产物。

## 遍历能干什么

材料列了五类问题，它们都是"把遍历稍作改动"：

| 问题 | 怎么改 |
| --- | --- |
| 判断连通性、找出连通分量 | 一次遍历能到的顶点就是一个分量；对未访问顶点重新起一次就是下一个分量 |
| 从一个顶点到其余所有顶点的路径长度 | BFS 天然按层推进：入队时记录"层号"，就是无权图的**最短路** |
| 判断二分图 | 遍历时给顶点染两色，若某条边的两端同色则不是二分图 |
| 最大流 | 残量网络上的 BFS（Edmonds–Karp）找增广路 |
| Cheney 算法的垃圾回收 | 从根集合出发的可达性遍历，把"活对象"复制走 |

前两条最常用，值得多说一句：

> [!note] 无权图里 BFS 就是最短路算法
> BFS 的队列保证了"**按距离从近到远**"出队：所有距离为 $d$ 的顶点出完，才会轮到距离 $d+1$ 的。所以第一次访问某个顶点时的层号，就是它到起点的最短边数。
> 这也是 Dijkstra 的雏形：把"队列"换成"按距离取最小的优先队列"，就得到带权图的最短路（C11.6）。

## 速查

| 项目 | BFS | DFS |
| --- | --- | --- |
| 容器 | 队列 queue | 栈 stack（递归则用调用栈） |
| 展开方式 | 先到先展开，逐层 | 后到先展开，一路到底 |
| 已访问标记 | $\Theta(\lvert V\rvert)$ | 同左 |
| 时间 | $\Theta(\lvert V\rvert+\lvert E\rvert)$ | 同左 |
| 邻接矩阵时 | $\Theta(\lvert V\rvert^2)$ | 同左 |
| 额外内存 | 队列 $O(\lvert V\rvert)$ | 栈深 $O(\lvert V\rvert)$（最坏） |
| 典型用途 | 无权最短路、连通分量、二分图 | 连通分量、拓扑排序、判环、回溯 |

| 判据 | 结论 |
| --- | --- |
| 遍历后仍有未访问顶点 | 图不连通；每个未访问点起一次 = 一个连通分量 |
| 一条边两端同时已访问 | 可能存在环（无向图里每条边都会遇到一次"另一端已访问"） |
| BFS 第一次访问的层号 | 到起点的最短边数（无权图） |

## 下一讲

遍历解决了"能不能到"，但没解决"怎么连最省"。

设想要给一栋楼里的每个房间布线、或者给若干城市铺光缆：所有点都要连上，且总长度最短。这就是**最小生成树**——一个连通图的所有生成树里权值最小的那棵。下一讲先把它定义清楚（生成树、生成森林、权值），再看两个算法怎么"贪心"地把它长出来：Prim 从一个点往外长，Kruskal 从最便宜的边往里挑。
