## 2. 最重要的一条：重心在「课堂上真正讲的话」

课件只是**提词板**。转写稿里老师展开的、举例的、反复强调的、临时改口的、算错又纠正的，
**才是这篇讲义的主体**。要求：

- 转写稿里讲到的，**全部录入**，不得只写课件上那一行结论。
- 转写稿是 ASR 转的：英文单词常被拼成怪样（`bes` = Bayes，`simple` = sample，`君子`/`晶子` = 均值，
  `拍`/`pi` = $\pi$，`s八` = $\bar{x}$，`缪`/`mu` = $\mu$）。**按上下文校正成正确的术语与符号，不要照抄乱码。**
- 老师讲错的数字，**用 python 复算**，在正文里写对，并说明"原话这里说成 X，实际是 Y"。
- **不许编造"老师说过什么"**。转写稿没讲的推导，可以补，但按第 5 节的方式标明是标准讲法的补充。
- 老师的个人经历、行业见闻（风投、股市、招生、赌场、药企……）只要承载了统计道理，就保留并压缩成
  **能讲清机理的那几句**；纯闲聊、纯吐槽不写。

### 3.3 叙述层禁用词（脚本会查）

**正文里不许出现「课件」「幻灯片」。** 主语是知识本身，不是文件。
- ❌「课件 p.37 给了均值公式」→ ✅「均值的定义是」／「（p.37）」
- ❌「课件没提，属于补充」→ ✅「这一条不在主干里」
- ✅ 页码可以留：`（p.37）` 是定位，不是出处声明。
- 例外：**点名原始材料的缺陷**时用「原稿 / 原印」：`原稿把 $s^2$ 印成 $\sigma^2$，实际应为 $s^2$`。
- 「课件」只允许出现在 frontmatter `source`、篇末勘误表、配图清单里。

其他禁用：「老师说 / 老师讲 / 老师给」（改写成断言，或用"课堂上的说法是"之外的直接讲法）；
「课堂板书 / 手写标注 / 箭头指向 / 圈了出来」这类画面描述。

## 4. 讲义体怎么推进（这是质量分水岭）

每一个新概念，按这条链条走，**不许跳步**：

**提出问题 → 让读者先猜 → 给出朴素尝试 → 撞墙 → 引出概念 → 正式定义 → 手算验证 → 回头看我们做了什么**

- **「撞墙」是重点**：朴素做法为什么不行，要讲透。看懂失败比记住结论更重要。
- 每讲完一块回头总结：「停一下，我们刚才干了什么」。
- 每篇至少 1–2 处 `> [!question] 停一下，先自己想想`，答案在后面叙述里给。

### 4.1 新概念准入（硬性，脚本查不出来，交付前自己过一遍）

任何术语／算法名／专有符号，**第一次出现之前**必须先有一句人话：

1. 它解决什么问题？（先说坎，再说名字）
2. 它是什么？用「先……再……」讲动作，**不许**「XX 是一种方法」这种同义反复。
3. 为什么叫这个名字？逐字拆（**抽样分布** = 抽样的 + 分布；**中心极限定理** = 中心 + 极限；**经验法则** = 靠经验的比例；**z 分数** = 标准化后的分数）。
4. 依赖哪个前置工具？依赖读者可能忘了的（求和号 ∑、平方和、开方、副对角线），三五行先补上。
5. 第一次提到它时，是不是已经在用了？是就补过渡。

**检查点**：篇名里的名词、mermaid 路线图里的名词、小结里出现但从没定义过的名词——这三处最容易漏。

### 4.2 详细程度按「信息增量」，不按篇幅

- **该展开**：被压成一行结论的地方；跳过一步就断链的地方；「显然/可以证明/同理」；一切「为什么」；
  读者会停下来问「等一下为什么」的地方；课上真实发生过的细节（口头补充、临时例子、当场算错的数）。
- **该收敛**：同一件事说第二遍；没有信息量的强调（「非常重要」「值得注意的是」）；
  先修课已学过的内容（一句带过）；与主干无关的旁支（走【拓展】）；用形容词代替机理。

### 4.3 必须补充的东西

公式来源、省略的推导、设计动机（为什么用这个统计量、换成别的会怎样）、前置知识补课、
图表读法（坐标轴/单位/关键点/两图坐标系差异）、易错点、随堂测（原题抄录 + **逐项解析** + 标出正确选项）、
前后联系（后面哪章会用到）、专业关联（vault 使用者是 AI / 大数据方向，接到 ML、DSP、PyTorch 上）。

## 6. 图怎么做

先问：**这张图要承担什么？**

| 图的角色 | 做法 |
|---|---|
| 让人看出规律、对比、结构、走向（分布形状、抽样分布的收窄、箱线图结构、置信区间覆盖、控制图的判异模式、回归残差形态……） | **自绘**（matplotlib / mermaid）。统一坐标、只留必要的线、标出关键点 |
| 它本身是"某个东西长什么样"，用坐标和文字重述一定失真（课件里给定的真实数据集图表、软件输出、复杂多子图、印刷版表格） | **裁原件** |
| 纯数据对照、多方案逐项比较 | **用表格**，不用图 |

- **图不能是唯一的知识载体**：结论由正文讲出来，图放在讲完之后做印证。
- 图要自足：轴是什么、单位、标出的点代表什么、几条线分别是谁——图上或紧邻文字交代清楚。
- **自绘图用中文标签**（本机 matplotlib 可用，见下），字号 ≥11，`dpi=150`。
- 裁切：`python3 <scripts>/pdf_tools.py images <pdf> --page N` 拿坐标，
  再 `crop --page N --rect x0,y0,x1,y1 --scale 2.5`；裁完检查有没有带进页码/页脚/邻页内容。
- 每张图做完**必须 `read_image` 回看**（中文变方框、图例遮数据、坐标被截断都要修）。
- 规模控制：**一篇 2–4 张图为宜**，只为"需要读者在空间里想象"的地方配图。装饰图不配。

matplotlib 模板（复制即用）：
