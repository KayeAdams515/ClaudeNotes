# 第 13 章 · 第 2 讲　神经网络的表示与前向传播

> [!abstract] 这一讲要解决什么
> 上一讲把墙算清楚了：$3{,}126{,}250$ 个二次项，手工特征在图像上走不通，出路是让特征自己长出来。这一讲把模型立起来——**一个神经元抽象成一个逻辑单元，一堆单元并排放成层，层叠成网络**。
> 然后它做一件看起来很小、其实是关键的事：**用一组手写的整数权重，让网络算出"同或 XNOR"**。这个例子证明网络能表达单个单元表达不了的东西；而"能不能自己学会这些权重"要到下一章才回答。

## 从一个神经元到一个网络

这一节的分节页只有一行：**Model representation I**。要建立的是"网络长什么样"和"怎么把它写下来"。

### 神经元：七处标注，三个有用

先看一个真实的神经元。图上标了七处，要一个个读：

| 部件 | 位置 | 作用 |
|---|---|---|
| **树突 Dendrite** | 胞体周围密集分叉的短枝 | 接收信号 |
| **胞体 Cell body** | 中间那团，里面有**细胞核 Nucleus** | 汇总收到的信号，决定要不要放电 |
| **轴突 Axon** | 一根长而粗的延伸 | 把输出送出去 |
| **髓鞘 Myelin sheath** | 轴突外面一段段的包裹 | 绝缘、加速传导 |
| **郎飞结 Node of Ranvier** | 髓鞘之间的间隙 | 信号在这里中继、再生 |
| **施万细胞 Schwann cell** | 形成外周神经髓鞘的细胞 | 就是包出髓鞘的那种细胞 |
| **轴突末梢 Axon terminal** | 轴突末端的分叉 | 通过突触把信号递给下一个神经元 |

这张图唯一要记的是两个词：**Dendrite** 就是 *input wires*，**Axon** 就是 *output wires*；夹在中间的胞体（含细胞核）负责汇总。**这两句话就是全部建模信息。**

![[C13.2-板书-神经元解剖.png]]

为什么只需要这三个？因为把"信号"换成"数"、把"强弱"换成"权重"，神经元做的运算就是一句话：

> [!important] 神经元的抽象
> **一堆输入线各自带一个权重，胞体把加权后的信号加起来，加总超过某个水平就放电。**
>
> 输入线 = 树突，输出线 = 轴突，加权求和 + 阈值 = 胞体。髓鞘、郎飞结、施万细胞是"这根线为什么传得快"的问题，对建模没有影响。

把尺度再往上拉一层：信号从**眼睛**进来，经过**一个神经元**，再传给下一个神经元，最后到**肌肉**。它要说明的事很简单，但很关键：

**神经元不是孤立的零件，它们首尾相接地串成链。** 一个神经元的输出线，接的是下一个神经元的输入线。**这句话就是"网络"的全部结构含义**——后面所有的层、连接、前向传播，都是把这句话写清楚。

### 神经元模型：逻辑单元

把上节的三个部件换成符号，得到这一讲的第一个公式：

> [!important] 神经元模型：逻辑单元 Logistic unit
> $$h_\theta(x)=g\Bigl(\theta_0+\sum_{j=1}^{n}\theta_jx_j\Bigr)=g\bigl(\theta^Tx\bigr),\qquad g(z)=\frac{1}{1+e^{-z}} .$$
> 输入向量带一个恒为 1 的分量：$x=\bigl[x_0,x_1,x_2,x_3\bigr]^T$，$x_0=1$；权重向量 $\theta=\bigl[\theta_0,\theta_1,\theta_2,\theta_3\bigr]^T$。

逐项说清楚，因为这几个词后面每一节都会用到：

- $x_0=1$ 叫**偏置单元 bias unit**（图上在它外面圈了一圈，写上 *"bias unit"*，旁边标 $x_0=1$）。它为什么存在，见下面一小段。
- $\theta_j$ 叫**权重 weights**，也叫**参数 parameters**——图上 $\theta$ 旁边画了个箭头，写着 *"weights"*，再往下写 *"parameters"*，两个词指同一个东西。
- $g$ 叫**激活函数 activation function**，这里取的是 **sigmoid（logistic）函数** $\;g(z)=\dfrac{1}{1+e^{-z}}$。图上把它的解析式手写在了下面：$g(z)=\frac{1}{1+e^{-z}}$。
- 输出 $h_\theta(x)$ 旁边的箭头写着 *"output"*，取值在 $(0,1)$ 之间。

**第一眼看上去会泄气：这不就是逻辑回归吗？** 是的，一模一样。神经网络的第一个零件，就是 [[C2.5 逻辑回归]] 里推过、用过、调过的那个模型。

这不是巧合，也不是偷懒。它说明：**网络的新东西不在单元上，而在连接方式上。** 一个单元能做的事，逻辑回归都能做。真正的变化在下一小节——把很多个单元并排放进**层**里。

**为什么偏置要单独拎出来当"单元"？** 因为记账方便。$\theta_0$ 是个独立的偏置，它不乘任何输入。如果允许"有一个输入不乘任何东西、直接进求和"，那每一层的输入向量长度就不统一，写矩阵乘法时还得单独处理一列。把 $x_0$ 固定成 1，$\theta_0x_0$ 就等于 $\theta_0$，**偏置就变成了一个普通的权重**，整层的运算可以写成一次矩阵乘法。

> [!warning] 一个必须记住的约定
> 偏置单元的激活值**永远是 1**，它不参与学习；可学的是它对应的那个权重。
>
> 下一小节就会看到 $a^{(2)}_0=1$、$a^{(3)}_0=1$ 这些式子——它们全是**补上的**，不是算出来的。

### 三层网络

把三个逻辑单元并排放，让它们吃同一批输入 $x_1,x_2,x_3$，再把它们的输出接到第四个单元上，就得到这张图：

![[C13-三层网络的记号.png]]

这就是神经网络的原型。图上有四个名字，一个都不能少：

| 名字 | 是什么 | 在图上的位置 |
|---|---|---|
| **输入层 Input layer** | 原始特征 $x_1,\dots,x_n$。**它不是单元**，是数据本身 | 左边三个圈 |
| **隐藏层 Hidden layer** | 并排的那一批单元 | 中间三个圈 |
| **输出层 Output layer** | 做最后裁决的那个单元 | 右边那个圈 |
| **偏置单元 Bias unit** | 每个非输出层各补一个恒为 1 的单元 | $x_0$ 和 $a^{(2)}_0$ |

**"隐藏"这两个字要单独解释，它是这套东西最容易被误解的地方。** 训练数据里只有 $(x,y)$——输入长什么样、答案是什么。**中间那三个数该是多少，没有任何人告诉你。** 它们不在数据集里，是模型自己算出来的，所以叫隐藏层。

还有两个词在这里正式登场：

- **层内不连**：同一层的三个单元之间没有连线。它们互不通信，各看各的同一批输入。
- **全连接 fully connected**：上一层的**每一个**单元，都连到下一层的**每一个**单元。图上那些交叉的线就是它——从 $x_0,x_1,x_2,x_3$ 出发，四条线各连到三个隐藏单元，一共 $4\times3=12$ 条；从 $a^{(2)}_0,\dots,a^{(2)}_3$ 出发，四条线连到输出，一共 4 条。

### 记号与维度规则

接下来要频繁写"第几层的第几个单元"，所以先把记号钉死。整层的运算就是四个式子；两条定义在前，维度规则在后。

> [!important] 两个记号
> - $a^{(j)}_i$ = 第 $j$ 层第 $i$ 个单元的**激活值 "activation"**。"激活"就是"这个单元算出来的那个数"——上一层传来的信号经过 $g$ 得到它。
> - $\Theta^{(j)}$ = 控制**从第 $j$ 层映射到第 $j+1$ 层**的**权重矩阵 matrix of weights**。
>
> 注意 $\Theta$ 是大写、带层号上标的**矩阵**，不是第 2 章那个小写向量 $\theta$。一层里有很多条连线，每条线一个权重，合起来自然是个矩阵。

于是三层网络的运算一项一项写出来就是（$x_0=1$、$a^{(2)}_0=1$ 都是偏置）：

$$
\begin{aligned}
a^{(2)}_1&=g\bigl(\Theta^{(1)}_{10}x_0+\Theta^{(1)}_{11}x_1+\Theta^{(1)}_{12}x_2+\Theta^{(1)}_{13}x_3\bigr),\\
a^{(2)}_2&=g\bigl(\Theta^{(1)}_{20}x_0+\Theta^{(1)}_{21}x_1+\Theta^{(1)}_{22}x_2+\Theta^{(1)}_{23}x_3\bigr),\\
a^{(2)}_3&=g\bigl(\Theta^{(1)}_{30}x_0+\Theta^{(1)}_{31}x_1+\Theta^{(1)}_{32}x_2+\Theta^{(1)}_{33}x_3\bigr),\\
h_\Theta(x)&=a^{(3)}_1=g\bigl(\Theta^{(2)}_{10}a^{(2)}_0+\Theta^{(2)}_{11}a^{(2)}_1+\Theta^{(2)}_{12}a^{(2)}_2+\Theta^{(2)}_{13}a^{(2)}_3\bigr).
\end{aligned}
$$

**这四个式子要多看两眼**，里面藏着两件事：

1. **下标读法**：$\Theta^{(1)}_{12}$ 是"从第 1 层的**第 2 个**输入，连到第 1 层的**第 1 个**隐藏单元"的权重。**第一个下标是目标单元，第二个是来源单元。**（图上那个圈起来的 $\Theta^{(1)}$ 旁边标了 $3\times4$，就是这个意思。）
2. **隐藏层里也有偏置**：$a^{(2)}_0=1$ 出现在最后一个式子里。它不是算出来的，是**规定成 1 的**——和输入层的 $x_0=1$ 完全一样的道理。

**维度规则**。设第 $j$ 层有 $s_j$ 个单元（**不含偏置**），第 $j+1$ 层有 $s_{j+1}$ 个单元：

> [!important] 维度规则（唯一必须背下来的一条）
> $$\Theta^{(j)}\in\mathbf{R}^{s_{j+1}\times(s_j+1)} .$$
>
> 读法：**行数 = 下一层的单元数**（每个目标单元一行），**列数 = 上一层的单元数 + 1**（多出来的那一列是偏置的权重）。

图上线把这条规则写在最下面，右边手写了 $s_{j+1}\times(s_j+1)$ 强化了一遍；那个 $3\times4$ 的标注就是 $\Theta^{(1)}$ 的具体形状。

回到这个三层网络（$s_1=3,s_2=3,s_3=1$）：

- $\Theta^{(1)}\in\mathbf{R}^{3\times4}$ —— 3 个隐藏单元，每个接 3 个输入 + 1 个偏置；
- $\Theta^{(2)}\in\mathbf{R}^{1\times4}$ —— 1 个输出单元，接 3 个隐藏单元 + 1 个偏置。

一共 $12+4=16$ 个可学参数。

**再练一个**：如果网络是 3 个输入、5 个隐藏、5 个隐藏、4 个输出（$L=4$），共有多少参数？

三个矩阵分别是 $5\times(3+1)=20$、$5\times(5+1)=30$、$4\times(5+1)=24$，合计

$$20+30+24=74 .$$

> [!warning] 最常见的两个记账错误
> 1. **忘掉 $+1$**。以为 $\Theta^{(1)}$ 是 $3\times3$，实际是 $3\times4$——少算的就是偏置那一列。
> 2. **把 $s_j$ 算进偏置**。$s_j$ 是**不含偏置**的单元数；若把偏置也算进去，列数会变成 $s_j+2$，全错。
>
> 检验办法：把形状对一遍——$(s_{j+1})\times(s_j+1)$ 乘 $(s_j+1)\times1$，得到 $(s_{j+1})\times1$，维度必须能消掉。

## 向量化的前向传播

分节页：**Model representation II**。上一节把式子写清了，这一节把它们**压成两行矩阵运算**，并解释隐藏层到底在干什么。

### 一层的运算只有两行

上一节那四个式子能算，但**千万别那么写代码**。每层写 $s_{j+1}$ 条独立式子，网络一大就是几百行重复代码，而且跑得极慢——数值库的优势全在矩阵运算上，循环是把优势扔掉。

记 $a^{(1)}=x$（输入层就是原始特征），那么前向传播 forward propagation 的完整链路是：

> [!important] 前向传播的完整链路
> $$
> \begin{aligned}
> &a^{(1)}=x,\\
> &z^{(2)}=\Theta^{(1)}a^{(1)},\qquad a^{(2)}=g\bigl(z^{(2)}\bigr),\qquad \textbf{再补 } a^{(2)}_0=1,\\
> &z^{(3)}=\Theta^{(2)}a^{(2)},\qquad h_\Theta(x)=a^{(3)}=g\bigl(z^{(3)}\bigr).
> \end{aligned}
> $$
>
> 三步一个循环：**先乘出 $z$，再激活成 $a$，再补偏置。** 层数再多也只是把这个循环重复。

![[C13.2-板书-向量化前向传播.png]]

$g$ 是**逐元素**作用在向量上的——每个分量各自过一遍 sigmoid。这里有一个很容易漏的细节：$a^{(2)}$ 算出来之后，**要给它补上一个偏置单元** $a^{(2)}_0=1$，才能送进下一层。图上那句 "Add $a^{(2)}_0=1$" 单独写了一行，就是因为这一步漏掉不会有任何报错，只会让结果悄悄变错。

> [!note] 一个符号习惯
> $z^{(j)}$ 是专门为向量化引入的记号：它是**激活之前**的加权和。给中间量一个名字的理由，下一章就会兑现——算梯度时要用 $g'(z^{(j)})$，那时会庆幸它有个名字。

### 网络在学自己的特征

这一节是整讲的落点。图上 **Layer 1 的三个单元是淡的**（不是画错了，是刻意淡掉的），左边用箭头标了 $x_1x_2$、$x_1x_2x_3$ 这些"手工特征"的打叉位置，右边把 $h_\Theta(x)$ 的算式完整写了出来：

$$h_\Theta(x)=g\bigl(\Theta^{(2)}_{10}a^{(2)}_0+\Theta^{(2)}_{11}a^{(2)}_1+\Theta^{(2)}_{12}a^{(2)}_2+\Theta^{(2)}_{13}a^{(2)}_3\bigr).$$

把它按层切开看：

- **最后一层**（$\Theta^{(2)}$ 那部分）拿到的是 $a^{(2)}_1,a^{(2)}_2,a^{(2)}_3$ 三个数，然后做一次逻辑回归。**它做的事和 [[C2.5 逻辑回归]] 完全一样，没有新东西。**
- **前面几层**做的事完全不同：它们把原始输入 $x_1,x_2,x_3$ 变成 $a^{(2)}_1,a^{(2)}_2,a^{(2)}_3$。

所以：

> [!important] 隐藏层 = 自动学出来的特征
> 传统做法是：人先想好特征（"这里加个 $x_1x_2$"、"那里加个 $x_1^2x_2$"），再喂给分类器。
>
> 神经网络的做法是：**把特征本身也变成可学的参数。** 网络自己决定 $a^{(2)}$ 这三个数该是什么——它不需要人指定"二次项"或"三次项"，只要求这三个数能让最后的分类做得好。
>
> 这就是上一讲那堵墙的正面突破：**不是找更强的特征模板，而是让特征从数据里长出来。**

图上左侧那些被淡掉、被打叉的 $x_1x_2$、$x_1x_2x_3$，说的正是这件事：**它们不再是必须的，因为 $a^{(2)}$ 可以自己长成任何形状。**

（拓展）**在图像上，这些"特征"往往会有直观含义。** 现代卷积网络的中间层被大量可视化过，呈现出一种从具体到抽象的顺序：最早几层学出**边缘**（某个方向的亮暗突变），往上一层把边缘拼成**局部形状**（角、弧、条纹），再往上拼成**物体的部件**（轮子、眼睛、把手），最后才在输出层判断"是不是车"。这个层级不是人设计的，是训练出来的。

（这里要诚实说明：这一讲只讲到"网络学习自己的特征"这个想法；"像素→边缘→部件→物体"这个层级是后来在卷积网络上观察到的，属于标准讲法的补充，不在这一讲的推导线里。）

### 其他网络结构

隐藏层可以不止一层。换一个四层网络看：3 个输入、3 个隐藏、2 个隐藏、1 个输出，每一层的名字照旧——*"input"*、两个 *"hidden layer"*、*"output"*。

**层数、每层单元数都可以变，但规则一条都没变**：全连接、每层补偏置、$\Theta^{(j)}$ 的形状是 $s_{j+1}\times(s_j+1)$、前向传播照"乘、激活、补偏置"循环。

## 一个单元就是一个逻辑门

分节页：**Examples and intuitions I**。从这里开始不再推公式，而是**手算**：给定一组权重，网络算出什么。

这一节要建立的手感是：**一个逻辑单元，在权重大到让 sigmoid 饱和时，就是一个硬阈值。**

### 先立靶子：XOR 与 XNOR

取 $x_1,x_2\in\{0,1\}$，定义

$$y=x_1\ \text{XOR}\ x_2 .$$

名字要拆开：**XOR = eXclusive OR，异或**——"恰有一个为 1"。它的否定 **XNOR = NOT XOR，同或**——"两个一样"：

$$x_1\ \text{XNOR}\ x_2=\text{NOT}\,(x_1\ \text{XOR}\ x_2).$$

两个名字只差一个"非"字，记住这一条就够了。

把四个输入放到平面上，靶子就清楚了：$y=1$ 的点是 $(0,1)$ 和 $(1,0)$，$y=0$ 的点是 $(0,0)$ 和 $(1,1)$。

**这个排布决定了后面的全部难点**：要把两个 $y=1$ 的点跟另外两个分开，边界得是两块分离的区域。**一条直线做不到。** 这就是后面要证明的那个"单层不够"。

### 与门 AND

先造最小的那种门。取权重

$$\Theta^{(1)}_{10}=-30,\qquad \Theta^{(1)}_{11}=20,\qquad \Theta^{(1)}_{12}=20,$$

也就是

$$h_\Theta(x)=g\bigl(-30+20x_1+20x_2\bigr).$$

把四种输入代进去：

| $x_1$ | $x_2$ | $-30+20x_1+20x_2$ | $h_\Theta(x)$ |
|---|---|---|---|
| 0 | 0 | $-30$ | $g(-30)\approx0$ |
| 0 | 1 | $-10$ | $g(-10)\approx0$ |
| 1 | 0 | $-10$ | $g(-10)\approx0$ |
| 1 | 1 | $10$ | $g(10)\approx1$ |

**只有两个输入都为 1 时才输出 1。这就是 AND。**

这里必须回答一个问题：**为什么是 $-30$、$20$ 这些数，而不是 $-3$、$2$？**

![[C13.2-板书-与门的阈值.png]]

两个数就能说清这件事：$g(4.6)=0.99$、$g(-4.6)=0.01$。**$|z|$ 一旦超过 4.6，sigmoid 就基本饱和**——它退化成一只开关。

所以权重要取得"足够大"，让每一种输入组合落下的 $z$ 都远离 0：这样 $g$ 的输出才是干净的 0 或 1，而不是 0.52、0.47 这种模棱两可的值。**取整十的数是让手算干净，不是数学上的要求。**

### 或门 OR

换一组权重：

$$h_\Theta(x)=g\bigl(-10+20x_1+20x_2\bigr).$$

| $x_1$ | $x_2$ | $-10+20x_1+20x_2$ | $h_\Theta(x)$ |
|---|---|---|---|
| 0 | 0 | $-10$ | $g(-10)\approx0$ |
| 0 | 1 | $10$ | $g(10)\approx1$ |
| 1 | 0 | $10$ | $g(10)\approx1$ |
| 1 | 1 | $30$ | $g(30)\approx1$ |

**只要有一个为 1 就输出 1。这就是 OR。** 和 AND 的差别只在偏置：$-10$ 比 $-30$ 松，一个输入就够把它推过零。

## 把门拼成同或

分节页：**Examples and intuitions II**。上一节一次造一个门，这一节把它们当积木拼起来。

### 非门与"两个都不是"

上一节还留了一个门没用上：**非门 NOT**。

$$h_\Theta(x)=g\bigl(10-20x_1\bigr),\qquad
\begin{array}{c|c}
x_1 & h_\Theta(x)\\ \hline
0 & g(10)\approx1\\
1 & g(-10)\approx0
\end{array}$$

**输入为 0 时输出 1，输入为 1 时输出 0。** 注意偏置是 $+10$、权重是 $-20$——**符号和 AND 刚好相反**：一个负权重的输入，本身就是"否"。

它真正的用处，是跟 AND 组合起来：

$$\bigl(\text{NOT}\,x_1\bigr)\ \text{AND}\ \bigl(\text{NOT}\,x_2\bigr)$$

这个式子的含义很明确：它成立当且仅当 $x_1=x_2=0$。把它展开成权重，取 $(10,\,-20,\,-20)$：

$$h_\Theta(x)=g\bigl(10-20x_1-20x_2\bigr).$$

- $x_1=x_2=0$：$10$，输出 1 ✔
- $x_1=1,x_2=0$：$-10$，输出 0 ✔
- $x_1=0,x_2=1$：$-10$，输出 0 ✔
- $x_1=x_2=1$：$-30$，输出 0 ✔

**这就是"两个都不是 1"。** 它和 AND 是同一个结构，只是把两个权重翻成负数、偏置留正——**"没有输入"这件事，靠正偏置来兜。**

### 三层拼装与逐行验算

现在把三块积木拼起来。目标是把同或写成

$$x_1\ \text{XNOR}\ x_2=(x_1\ \text{AND}\ x_2)\ \text{OR}\ \bigl((\text{NOT}\,x_1)\ \text{AND}\ (\text{NOT}\,x_2)\bigr),$$

读作**"两个都是 1"或者"两个都是 0"**：两个极端各做一个 AND，最后用 OR 并起来。

于是要三个单元，各管一件事：

| 单元 | 负责 | 权重（偏置, $x_1$, $x_2$） | 表达式 |
|---|---|---|---|
| $a^{(2)}_1$ | $x_1$ AND $x_2$ | $(-30,\ 20,\ 20)$ | $g(-30+20x_1+20x_2)$ |
| $a^{(2)}_2$ | $(\text{NOT}\,x_1)$ AND $(\text{NOT}\,x_2)$ | $(10,\ -20,\ -20)$ | $g(10-20x_1-20x_2)$ |
| 输出 | $a^{(2)}_1$ OR $a^{(2)}_2$ | $(-10,\ 20,\ 20)$ | $g(-10+20a^{(2)}_1+20a^{(2)}_2)$ |

**注意第三行：它的输入不是 $x$，而是 $a^{(2)}$。** 这一层做的事和前两个单元一模一样（加权求和、过 sigmoid），只是它看的东西换了。这句话是理解"层"的关键。

四个输入全算一遍：

| $x_1$ | $x_2$ | $a^{(2)}_1$（AND） | $a^{(2)}_2$（都非） | $-10+20a^{(2)}_1+20a^{(2)}_2$ | $h_\Theta(x)$ | 应为 XNOR |
|---|---|---|---|---|---|---|
| 0 | 0 | $\approx0$ | $\approx1$ | $10$ | $\approx1$ | **1** ✔ |
| 0 | 1 | $\approx0$ | $\approx0$ | $-10$ | $\approx0$ | 0 ✔ |
| 1 | 0 | $\approx0$ | $\approx0$ | $-10$ | $\approx0$ | 0 ✔ |
| 1 | 1 | $\approx1$ | $\approx0$ | $10$ | $\approx1$ | **1** ✔ |

四行全对。**六个单元（3 输入 + 2 隐藏 + 1 输出）、九个权重，算出了同或。**

![[C13.2-板书-XNOR的拼装.png]]

图上把整条通路都画了出来：三个门各自的权重（AND、两个都非、OR 各一组），两个隐藏单元 $a^{(2)}_1$、$a^{(2)}_2$，第三层把它们"或"起来；图下方的真值表就是上面这四行。

### 隐藏层在换坐标

到这里必须回答：**这种拼装，单层做不到吗？**

做不到，理由是几何上的。

![[C13-XNOR的坐标变换.png]]

左图是输入空间：正例在 $(0,0)$ 和 $(1,1)$，负例在 $(0,1)$ 和 $(1,0)$。画一条 $x_1+x_2=0.5$ 当候选——它把 $(0,0)$ 单独划出来，却把 $(1,1)$ 和两个负例关在同一边。**换任何一条直线，都会错一对。**

右图是隐藏层坐标：把四个输入按 $a^{(2)}$ 那两个式子算出来，落到平面上的位置是

| $x=(x_1,x_2)$ | $(a^{(2)}_1,a^{(2)}_2)$ | 应该输出 |
|---|---|---|
| $(0,0)$ | $\approx(0,1)$ | 1 |
| $(0,1)$ | $\approx(0,0)$ | 0 |
| $(1,0)$ | $\approx(0,0)$ | 0 |
| $(1,1)$ | $\approx(1,0)$ | 1 |

**两个负例被堆到了原点，两个正例分开了。** 而"输出 1"的条件是 $-10+20a^{(2)}_1+20a^{(2)}_2>0$，也就是 $a^{(2)}_1+a^{(2)}_2>0.5$——**一条斜线**。原来切不开的排布，被隐藏层重新摆过一次之后，**一条直线就切开了**。

> [!important] 隐藏层的全部秘密
> 它不"增加复杂度"这种含糊的说法，而是**换了一套坐标，让原来非线性可分的问题在新坐标里线性可分**。
>
> 之后所有的深度网络都在重复这一件事：一层换一次坐标，越往上换得越接近"能一刀切开"。

接着，把这件事画成普遍情形：一个四层的网络，每一层的名字都标在下面——*"input"*、两个 *"hidden layer"*、*"output"*。**每一层都是一次坐标变换，前向传播就是把这一串变换依次做下去。** 这是示意图，它的层数和单元数与上面 XNOR 那个网络不同，别把两者当成同一个模型。

> [!question] 那多堆几层是不是总能解决
> 表达能力上是的——更深的网络能表示更复杂的边界。但这**不等于**更深一定训练得更好：参数更多、更容易过拟合（[[C2.7 过拟合与正则化]]）、优化更难。
>
> 更要紧的是：这一讲所有的权重都是**手写的整数**。真实的训练里我们并不知道这些数，得让梯度下降把它们找出来——那是下一章的事。**所以这一讲证明的是"网络有能力表达 XNOR"，不是"网络能学会 XNOR"。** 这两件事差得很远。

### 一个真实的例子：手写数字

理论讲完，看一个当年的真实成果：LeNet 5 做手写数字识别。输入是一张手写数字图（图里这张是"9"），系统输出的答案是 9；左边那一列展示的是内部不同单元对同一个输入给出的不同候选判断。

![[C13-LeNet5-手写数字.png]]

这个系统的意义在于：**没有人手工告诉它"去哪里找笔画"，它自己从像素里学出了能区分 0–9 的特征。** 这正是「网络在学自己的特征」讲的那件事，第一次在真实任务上成立。

## 多分类：K 个输出单元

分节页：**Multi-class classification**。

### 四个输出单元与独热标签

前面所有网络的输出都是一个数，回答一个是非问题。要回答"四类里是哪一类"，最直接的做法是把输出层做成 **4 个单元**，每类一个：

$$\text{pedestrian}\quad\text{car}\quad\text{motorcycle}\quad\text{truck}$$
$$h_\Theta(x)\in\mathbf{R}^{4}$$

每个输出单元各自回答"是不是这一类"，四个问题依次是 *pedestrian? car? motorcycle? truck?*。而 $h_\Theta(x)\in\mathbf{R}^4$ 这句话的意思是——**输出不再是 1 个数，是 4 个数。**

训练时标签不能是一个数 $1,2,3,4$，而必须是一个**向量**，只有对应类别那一位是 1：

| 类别 | 期望的 $h_\Theta(x)$ |
|---|---|
| 行人 pedestrian | $[1,0,0,0]^T$ |
| 汽车 car | $[0,1,0,0]^T$ |
| 摩托车 motorcycle | $[0,0,1,0]^T$ |
| 卡车 truck | $[0,0,0,1]^T$ |

> [!important] 训练集的形式
> 每个样本是 $(x^{(i)},y^{(i)})$，其中 $y^{(i)}$ **本身是一个四维向量**，取上面四者之一。标签可以写成 $y^{(i)}\in\{1,2,3,4\}$，训练目标是 $h_\Theta(x^{(i)})\approx y^{(i)}$——**让输出的那个四维向量逼近标签的那个四维向量。**
>
> 这叫**独热编码 one-hot encoding**。要注意它和第 2 章 One-vs-all 的差别：One-vs-all 是训练 $K$ 个**互相独立**的二分类器，每个只关心自己那一类；这里的 $K$ 个输出单元是**在同一个网络里联合训练**的，共享同一个隐藏层，所以特征是共享的（[[C2.6 高级优化算法与多分类]]）。参数更少，通常也更好。

## 速查

| 名称 | 内容 |
|---|---|
| 逻辑单元 | $h_\theta(x)=g(\theta^Tx)$，$g(z)=\dfrac{1}{1+e^{-z}}$；**＝一次逻辑回归** |
| 三个同义词 | 单元 unit ＝ 神经元 neuron ＝ 节点 node |
| 术语 | $\theta_j$：权重 weights ＝ 参数 parameters；$g$：激活函数 activation function |
| 偏置单元 | $x_0=1$（每个非输出层各补一个，激活值恒为 1，不参与学习） |
| 记号 | $a^{(j)}_i$：第 $j$ 层第 $i$ 个单元的激活值；$\Theta^{(j)}$：第 $j$ 层到 $j+1$ 层的权重矩阵 |
| 下标读法 | $\Theta^{(j)}_{ik}$：**目标**是第 $i$ 个、**来源**是第 $k$ 个 |
| 维度规则 | $\Theta^{(j)}\in\mathbf{R}^{s_{j+1}\times(s_j+1)}$；$s_j$ **不含偏置**，列数要 $+1$ |
| 参数计数 | 三层（3-3-1）：$3\times4+1\times4=16$；四层（3-5-5-4）：$5\times4+5\times6+4\times6=74$ |
| 前向传播 | $z^{(j+1)}=\Theta^{(j)}a^{(j)}$ → $a^{(j+1)}=g(z^{(j+1)})$ → **补 $a^{(j+1)}_0=1$**；$a^{(1)}=x$，$h_\Theta(x)=a^{(L)}$ |
| sigmoid 饱和 | $g(\pm4.6)=0.99/0.01$；权重取 $\pm10,\pm20,\pm30$ 时单元退化成硬阈值 |
| AND | $g(-30+20x_1+20x_2)$ |
| OR | $g(-10+20x_1+20x_2)$ |
| NOT | $g(10-20x_1)$ |
| 都非 | $g(10-20x_1-20x_2)$，仅在 $x_1=x_2=0$ 时为 1 |
| XNOR | $g(-10+20a^{(2)}_1+20a^{(2)}_2)$，其中 $a^{(2)}_1$ 为 AND、$a^{(2)}_2$ 为"都非" |
| 为什么要多一层 | 隐藏层换坐标：负例被堆到原点，$a^{(2)}_1+a^{(2)}_2>0.5$ 一条直线即可切开 |
| 多分类 | 输出层放 $K$ 个单元，$h_\Theta(x)\in\mathbf{R}^K$；标签用独热向量；同一网络联合训练 |

## 下一讲

这一讲结束时，网络能算出同或——**但所有的权重都是我们手写进去的。**

这就是下一章要拆掉的东西。真实的训练里，没有人会告诉你"$\Theta^{(1)}_{11}$ 该是 20"；网络要从数据里把这 16 个数找出来。要找，就得先有一个"错得多离谱"的度量——**代价函数**；再要一个"每个权重该往哪边改"的算法——**反向传播**。

下一章从代价函数开始，把它写成对 $K$ 个输出单元求和的形式（多分类那一节刚埋了伏笔），然后用链式法则把误差一层层往回传。那里会出现一个这一讲已经准备好的记号：**$z^{(j)}$**——因为它正是求导时反复出现的那个量。
