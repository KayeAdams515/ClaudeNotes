## p76
- 页标题：`4.6.0 Overview`
- 中文正文要点：
  - 「In practical applications, there are many non-sine periodical signal (voltage or current)」
    ——实际应用中存在大量非正弦周期信号（电压或电流）。
  - 周期性定义式写在正中央：$f(t)=f(t+kT)\quad(k=1,2,3,\dots)$
  - 下方并排三张波形图，各自带中英文标签：
    - `(a) square wave`（方波）
    - `(b) sawtooth wave（锯齿波）`
    - `(c) Half wave rectification waveform（半波整流波形）`
- 公式：$f(t)=f(t+kT),\ k=1,2,3,\dots$（周期函数定义，$T$ 为周期）
- 图/表：
  - **(a) 方波**：纵轴 $f(t)$ 箭头向上，横轴 $t$ 箭头向右，原点标 `0`，横轴标 `T`。
    波形为**先高后低**：在 $0<t<T/2$ 为高电平，$T/2<t<T$ 为低电平，高电平高度 ≈ 1 格、低电平为 0（单极性方波，不是 ± 双向）。
    低频方波画了约 2.5 个周期。
  - **(b) 锯齿波**：纵轴 $f(t)$、横轴 $t$，原点 `0`，横轴标 `T`。
    波形为**线性上升的锯齿**：每个周期从 0 线性升到峰值，在 $t=T$ 处**垂直跌回 0**；周期起点对齐 `T` 刻度。
    画了约 3 个锯齿。
  - **(c) 半波整流波形**：纵轴 $f(t)$、横轴 $t$，原点 `0`（标在 y 轴左侧）。
    **只有上半个正弦包**交替出现：$0\sim T/2$ 有一个完整上凸半波，$T/2\sim T$ 为 0 直线，然后重复。
    画了约 2.5 个半波。
  - **复现性**：三张图都能用 matplotlib 精确复现（方波 `square`、锯齿 `sawtooth`、半波 `np.clip(sin,0,None)`），
    而且比原图清楚。**复现 >> 裁切**；若一定要裁，三图并排裁成一整条即可。
- 数值：横轴刻度 `0`、`T`（只有符号，无具体数字）；$k=1,2,3,\dots$。
- 疑点：
  - (a) 与 (b) 的波形是**单极性**（0 到正），而 p84/p87 正式展开时方波用的是 ±$U_m$ 双向、锯齿波用的是 0→$U_m$。
    **同一份课件里同一名称的波形画法不一致**，读图时要按各页自己的定义走。
  - (a) 方波的「T」刻度打在低电平段中间，不是打在跳变沿上——坐标刻度标注不严谨。

## p77
- 页标题：`4.6.0 Overview`
- 中文正文要点（逐句转述，红色词为课件红色高亮）：
  - 「The causes of non-sine periodic signals in the circuit include:」电路中产生非正弦周期信号的原因包括：
    1. ★ `Non-sine periodic source supply excites linear circuit to generate Non-sine periodic signal;`
       **非正弦周期电源激励线性电路，产生非正弦周期信号**；（红色：`linear circuit`、`Non-sine`）
    2. ★ `Several sine excitations of different frequencies act on the same linear circuit;`
       **多个不同频率的正弦激励作用于同一个线性电路**；（红色整句）
    3. ★ `The sine excitation of a single frequency acts on a nonlinear circuit.`
       **单一频率的正弦激励作用于非线性电路**。（红色：`a nonlinear circuit`）
  - 「This course only discusses the first two cases.」**本课程只讨论前两种情况。**

    the first case can be equivalent to the second case.」
    事实上，当非正弦周期电源函数满足**狄氏条件**时，第一种情况可以等效为第二种情况。
  - 「According to the superposition property of linear circuit, the phasor method can be used to analyze the
    steady-state response in this case.」
    根据线性电路的叠加性质，这种情况下的稳态响应可以用**相量法**分析。
- 公式：无
- 图/表：无。三条原因用金色 ★ 符号作项目符号；红色高亮就是「线性电路 / 不同频率多个正弦激励 / 非线性电路 / 狄氏条件」这些关键词。
- 数值：无。
- 疑点：
  - 中文术语写作**「狄氏条件」**（p77），而 p78 的正式标题写**「狄里赫利条件」**，同一份课件内两种译名。
  - 本页说「前两种情况可以互相等效」，但**没给出为什么**——按教学习惯这里缺一步说明：

## p78
- 页标题：`4.6.1 Harmonic Decomposition of Non-sine Periodic Voltage and Current`（页眉黄字，本段所有内页统一用这个页眉）
- 中文正文要点：
  - 「`Dirichlet condition(狄里赫利条件)`」——**狄里赫利条件**，三条：
    1. 「The function $f(t)$ `is absolutely integrable(绝对可积)` in any period, that is, for any time $t_0$,
       the integral $\int_{t_0}^{t_0+T}|f(t)|\mathrm{d}t$ exists. (`The function value is limited`)」
       **函数 $f(t)$ 在任意一个周期内绝对可积**，即对任意 $t_0$，积分 $\int_{t_0}^{t_0+T}|f(t)|\mathrm{d}t$ 存在。
       （括号补充红色：函数值有限。）
    2. 「The function $f(t)$ has only `finite maximum and minimum` in any period;」
       **函数 $f(t)$ 在任意一个周期内只有有限个极大值和极小值**；
    3. 「The function $f(t)$ is `continuous` or has only a `finite number of discontinuous points` in any period.」
       **函数 $f(t)$ 在任意一个周期内连续，或只有有限个间断点**。
  - 「The non-sine periodic voltage and current in the actual circuit are `energy limited` signals,
    which `generally meet the Dirichlet condition`.」
    实际电路中的非正弦周期电压和电流都是**能量有限**信号，**一般都能满足狄里赫利条件**。
- 公式：$\displaystyle\int_{t_0}^{t_0+T}|f(t)|\,\mathrm{d}t$ 存在（第 1 条的绝对可积条件）
- 图/表：无。红字分布：`absolutely integrable(绝对可积)`、`The function value is limited`、
  `finite maximum and minimum`、`continuous`、`a finite number of discontinuous points`、
  `energy limited`、`generally meet the Dirichlet condition`。
- 数值：无具体数字；$t_0$、$T$ 为符号。
- 疑点：
  - 第 1 条括号里的「The function value is limited（函数值有限）」是**额外补充**，不属于狄里赫利三条件的标准表述，
    是课件为工程直观加的注解。绝对可积本身已经蕴含了「除有限点外函数值有界」。
  - 三点**只讲了充分条件，没讲收敛到什么值**。按数学结论，在连续点收敛到 $f(t)$，在间断点收敛到
    $\dfrac{f(t^-)+f(t^+)}{2}$（左右极限的算术平均）——这一点课件完全没写，是本段一个重要缺口
    （后面方波在跳变沿处「过冲」的吉布斯现象与之相关）。

## p79
- 页标题：`4.6.1 Harmonic Decomposition of Non-sine Periodic Voltage and Current`
- 中文正文要点：
  - ◆ 「`Fourier series expansion(傅里叶级数展开)` of periodic functions」周期函数的傅里叶级数展开
  - 「According to the mathematical analysis theory, if the given periodic signal (function) `satisfies the
    Dirichlet condition`, the signal can `be expanded into a convergent Fourier series （傅里叶级数）`」
    根据数学分析理论，如果给定周期信号（函数）**满足狄里赫利条件**，则该信号**可以展开成收敛的傅里叶级数**。
  - 逐项命名（这是本页的核心知识点）：
    - 「The constant term $A_0$ is called `constant component` or `DC component`, which is the average value of
      the signal in a period.」
      **常数项 $A_0$ 称为恒定分量或直流分量（DC component），它等于信号在一个周期内的平均值。**
    - 「$A_{1\mathrm{m}}\sin(\omega t+\varphi_1)$ is called `fundamental wave(基波)` or `first harmonic(一次谐波)`,
      its frequency is the same as the original signal, and $A_{1\mathrm{m}}$ is the amplitude of fundamental wave.」
      **$A_{1\mathrm{m}}\sin(\omega t+\varphi_1)$ 称为基波或一次谐波，其频率与原信号相同，$A_{1\mathrm{m}}$ 是基波振幅。**
    - 「$A_{2\mathrm{m}}\sin(2\omega t+\varphi_2)$ is called the `second harmonic (二次谐波)`, its frequency is twice
      the fundamental frequency, and $A_{2\mathrm{m}}$ is the amplitude of the second harmonic.」
      **$A_{2\mathrm{m}}\sin(2\omega t+\varphi_2)$ 称为二次谐波，其频率是基波频率的两倍，$A_{2\mathrm{m}}$ 是二次谐波振幅。**
    - 「By analogy, `the second and above harmonics` are collectively referred to as `high-order harmonics(高次谐波)`.」
      **依此类推，二次及以上谐波统称为高次谐波。**
- 公式（**傅里叶级数三角形式之一，即含 $A_0$、$A_{k\mathrm{m}}$、$\varphi_k$ 的「振幅—初相」形式**）：
  $$f(t)=A_0+A_{1\mathrm{m}}\sin(\omega t+\varphi_1)+A_{2\mathrm{m}}\sin(2\omega t+\varphi_2)+\cdots
  =A_0+\sum_{k=1}^{\infty}A_{k\mathrm{m}}\sin(k\omega t+\varphi_k)$$
- 图/表：无图。
- 数值：无具体数字；下标出现 $0,1,2,k$。
- 疑点（**重要，印刷/排版事故**）：
  - 本页正文**排版严重重叠**：`A_{1m} sin(ωt+φ1)` 这一行公式**直接压印在**「the average value of the signal in a period.」
    这句话上面，`A_{2m} sin(2ωt+φ2)` 同样压印在其下方文字上，两处都糊成一团。
    **读图时只能靠上下文与 p80 的公式补齐**，这三个公式串的真实内容为：
    $A_{1\mathrm{m}}\sin(\omega t+\varphi_1)$、$A_{2\mathrm{m}}\sin(2\omega t+\varphi_2)$。
  - p79 的 $A_{k\mathrm{m}}$ 记号带下标 $\mathrm{m}$（表示 amplitude，振幅），
    与 p82 的 $A_{km}$（同一含义）以及 p92 的 $U_{k\mathrm{m}}$、$I_{k\mathrm{m}}$ 记号一致。
  - 本页给出的是**「振幅—初相」形式**；p80 给出**「$a_k\cos+b_k\sin$」形式**，两式的系数关系在 p82 给出。三种写法必须串起来看。
  - 全段自始至终**没有给出 $A_0$ 的具体定义式**——$A_0$ 的定义式只在 p80 出现，属于跨页依赖。

## p80
- 页标题：`4.6.1 Harmonic Decomposition of Non-sine Periodic Voltage and Current`
- 中文正文要点：
  - ◆「`Fourier series expansion of periodic functions`」周期函数的傅里叶级数展开
  - 「Using trigonometric `identities(三角恒等式)`, we have」**利用三角恒等式，可得**（左列文字，其余版面为公式推导）
  - 「Where:」**其中：**（引出系数积分式）
- 公式（**这是傅里叶级数两种写法的连接枢纽，必须逐个写全**）：
  - 起点（p79 的形式）：
    $$f(t)=A_0+\sum_{k=1}^{\infty}A_{k\mathrm{m}}\sin(k\omega t+\varphi_k)$$
  - 第 1 步，展开 $\sin(k\omega t+\varphi_k)$：
    $$=A_0+\sum_{k=1}^{\infty}\bigl(A_{k\mathrm{m}}\sin\varphi_k\cos k\omega t+A_{k\mathrm{m}}\cos\varphi_k\sin k\omega t\bigr)$$
  - 第 2 步，拆成两个和：
    $$=A_0+\sum_{k=1}^{\infty}(A_{k\mathrm{m}}\sin\varphi_k)\cos k\omega t+\sum_{k=1}^{\infty}(A_{k\mathrm{m}}\cos\varphi_k)\sin k\omega t$$
  - 第 3 步，写成 $a_k,b_k$ 形式：
    $$=A_0+\sum_{k=1}^{\infty}\bigl(a_k\cos k\omega t+b_k\sin k\omega t\bigr)$$
  - 「Where:」系数定义（含 $t$ 积分与 $\omega t$ 积分两种等价写法，课件两种都给了）：
    $$A_0=\frac{1}{T}\int_{0}^{T}f(t)\,\mathrm{d}t=\frac{1}{2\pi}\int_{0}^{2\pi}f(t)\,\mathrm{d}(\omega t)$$
    $$a_k=\frac{2}{T}\int_{0}^{T}f(t)\cos(k\omega t)\,\mathrm{d}t=\frac{1}{\pi}\int_{0}^{2\pi}f(t)\cos(k\omega t)\,\mathrm{d}(\omega t)$$
    $$b_k=\frac{2}{T}\int_{0}^{T}f(t)\sin(k\omega t)\,\mathrm{d}t=\frac{1}{\pi}\int_{0}^{2\pi}f(t)\sin(k\omega t)\,\mathrm{d}(\omega t)$$
- 图/表：无图，整页是三步推导 + 系数定义式。右列三行公式上下对齐，左侧留白放「Using trigonometric identities」与「Where:」。
- 数值：无具体数字。
- 疑点：
  - **$A_0$ 的定义式里少了 $\dfrac{1}{2}$ 吗？没有。** 注意 $A_0$ 是**直流分量本身**（周期平均值），
    而三角形式的常数项习惯上写作 $\dfrac{a_0}{2}$；本课件统一用 $A_0$ 直接表示平均值，因此
    $A_0=\frac1T\int_0^T f\,\mathrm{d}t$ **正确**，但读的时候不要与「$\frac{a_0}{2}$」的写法混起来。
    ⚠️ 复算提示：这条是记号约定问题，不是数值问题——用 sympy 验算 $A_0=\frac1T\int_0^T f\,\mathrm{d}t$
    得到的正是周期平均值，与 p79 的说法「the average value of the signal in a period」一致 ✔。
  - 第 3 步里 $A_0$ 与 $\sum$ 之间**没有说明 $k$ 从 1 起还是从 0 起**，本页写的是 $k=1$（无歧义）。
  - 课件**没有写出 $A_{k\mathrm{m}}$、$\varphi_k$ 与 $a_k$、$b_k$ 的关系式**——这一关系在 p82 才给出（跨页）。
  - 本页**完全没有出现「系数关系」的逆用**（即由 $a_k,b_k$ 求 $A_{k\mathrm{m}},\varphi_k$），只在 p82 出现，跨页依赖。

## p84
- 页标题：`Square wave voltage (方波)`
- 中文正文要点：整页为公式推导，无中文段落。三个英文小标题：
  - 「■Square wave voltage (方波)」
  - 「✓ `DC component:`」**直流分量**
  - 「✓ `Harmonic component:`」**谐波分量**
- 公式（**方波完整级数表达式 + 直流分量 + 各次谐波系数**）：
  - 级数表达式（图上方，先给结果）：
    $$u(t)=\sum_{n=1}^{\infty}\frac{4U_{\mathrm{m}}}{(2n-1)\pi}\sin\!\left[(2n-1)\frac{2\pi}{T}t\right]$$
  - 直流分量：
    $$U_0=\frac{1}{T}\int_{0}^{T}u(t)\,\mathrm{d}t=0$$
  - 谐波分量（$a_n$，**注意课件把两个半周期的积分并写在一起，上限都印成了 $T/2$，第二项上限显然应为 $T$**）：
    $$a_n=\frac{2}{T}\int_{0}^{T/2}U_{\mathrm{m}}\cos\!\left(\frac{2n\pi}{T}t\right)\mathrm{d}t
    +\frac{2}{T}\int_{0}^{T/2}(-U_{\mathrm{m}})\cos\!\left(\frac{2n\pi}{T}t\right)\mathrm{d}t=0$$
    （右侧印刷的上限为 $T/2$，按方波定义第二段应积到 $T$；因被积函数在整周期上正负相消，结果 $a_n=0$ 不受影响。）
  - 谐波分量（$b_n$，**这一条的上限印对了**）：
    $$b_n=\frac{2}{T}\int_{0}^{T/2}U_{\mathrm{m}}\sin\!\left(\frac{2n\pi}{T}t\right)\mathrm{d}t
    +\frac{2}{T}\int_{T/2}^{T}(-U_{\mathrm{m}})\sin\!\left(\frac{2n\pi}{T}t\right)\mathrm{d}t
    =\frac{2U_{\mathrm{m}}}{n\pi}\left[1-(-1)^{n}\right],\qquad n=1,2,\cdots$$
- 图/表：
  - **右上：方波波形图**。纵轴 `u`（向上箭头），横轴 `t`（向右箭头）。
    纵轴正向标 $U_{\mathrm{m}}$、负向标 $-U_{\mathrm{m}}$；横轴标 `T`、`2T`，原点标 `0`。
    波形为**双极性方波**：在 $0\sim T/2$ 为 $+U_{\mathrm{m}}$，$T/2\sim T$ 为 $-U_{\mathrm{m}}$，之后重复。
    **绘制为蓝色线条**，画出约 2.5 个周期。
    **注意：波形在 $t=0$ 处是从 $+U_{\mathrm{m}}$ 开始的（t=0 处为高电平）**，与 p76 的单极性方波画法不同。
  - **复现性**：非常容易用 matplotlib 复现（`np.sign(np.sin(2πt/T))` 或分段常量）。**推荐复现**；
    裁切价值低（只是一个标准方波），**值得裁的是 p85 的合成过程图**。
- 数值：
  - 系数通式 $\dfrac{4U_{\mathrm{m}}}{(2n-1)\pi}$；直流 $0$；$a_n=0$；$b_n=\dfrac{2U_{\mathrm{m}}}{n\pi}[1-(-1)^n]$。
  - $n=1,2,\cdots$；波形轴刻度 $0,\ T,\ 2T$；幅值 $\pm U_{\mathrm{m}}$；页码 `84`。
- 复算（sympy 符号积分）：
  - $b_n=\dfrac{2U_{\mathrm{m}}}{n\pi}[1-(-1)^{n}]$ → $n=1,2,3,4,5,6,7$ 得
    $\dfrac{4U_{\mathrm{m}}}{\pi},\ 0,\ \dfrac{4U_{\mathrm{m}}}{3\pi},\ 0,\ \dfrac{4U_{\mathrm{m}}}{5\pi},\ 0,\ \dfrac{4U_{\mathrm{m}}}{7\pi}$ ✔
  - 即 $b_n=\dfrac{4U_{\mathrm{m}}}{(2n-1)\pi}$（$n$ 为奇数），偶次谐波全为 0 ✔ 与级数表达式一致。
  - $U_0=0$ ✔，$a_n=0$ ✔（sympy 直接对整周期分段函数积分得 0）。
  - ✅ **结论：本页数值全部正确，无复算不符。**
- 疑点：
  - ⚠️ **印刷笔误**：$a_n$ 那一行第二个积分的**上限印成 $T/2$**（应为 $T$）。因为方波在 $t>T/2$ 才取 $-U_{\mathrm{m}}$。
    由于结果恰好为 0（正负相消），这个笔误在数值上不暴露，但**逻辑上错误**，抄写时要当心。
  - 级数表达式用 $2n-1$ 作下标（$n=1,2,\cdots$ → 频率 $1,3,5,\cdots$ 次），
    而 $a_n,b_n$ 用 $n$ 作下标（$n=1,2,\cdots$ → 频率 $1,2,3,\cdots$ 次）。
    **同一页里 $n$ 的含义换了一次**，容易搞混：级数里的 $(2n-1)$ 对应 $b$ 系数里的奇数 $n$。
  - 直流分量为 0、$a_n=0$：课件**只用积分式说明，没有点出原因是「奇函数、半波对称」**。
    实际上方波是奇函数（$a_n=0$）且半波对称（偶次谐波为 0），这两条对称性判据是本页最重要的省算技巧，课件未总结。
  - 该页**没有画频谱图**，方波的幅度谱（$\propto 1/(2n-1)$ 衰减）需要读者自己从系数式读出。

    $n=2$ → $\frac{2U_m}{15\pi}$ ✔（级数里的 $n$ 对应偶次谐波 $2n$ 次，即 $a_{2n}$，两者一致）

- 疑点：
  1. ⚠️ **印刷笔误（直流分量积分式）**：$U_0$ 定义式里被积函数印成
     $U_{\mathrm{m}}\left|\sin\dfrac{2n\pi t}{T}\right|$，**多了个 $n$**。正确应为
     $U_{\mathrm{m}}\left|\sin\dfrac{2\pi t}{T}\right|$。虽然因为分母里含 $n$ 时积分仍能算出 $2U_m/\pi$，
     但**符号定义是错的**（直流分量不应依赖 $n$）。
  2. ⚠️ **$a_n$ 式不一致的记号**：第一段积分里写的是 $\sin\frac{2\pi}{T}t$（无 $n$，正确），

     但两个积分号前的**符号与积分限写法**（上标 $T/2$ vs 下标 $T/2$）排得很紧，容易看错。
     另外第二段前面的负号来自负半周被翻到正侧（$|\sin|$ 在 $T/2\sim T$ 段等于 $-\sin$）。
  3. **$n=1$ 时公式为 $0/0$**（$\frac{-U_m[1+(-1)]}{0}$），课件**没有说明 $n=1$ 要单独处理**。

  4. 级数里用 $4n\pi/T$（即 $2n\omega$，**只有偶次谐波**），这是全波整流的特征：
     **奇次谐波全部为 0**，只含直流 + 偶次谐波。课件只用「偶函数 → 只含 cos」解释了一半，
     **没有点出「奇次谐波全为 0」这个更强的结论**。
  5. 全波整流 $u(t)$ 的定义式（$U_m|\sin|$）**没有在本页写出**，只画在图上；读者要靠图反推。p90 才写出 $u_1(t)$。

## p91
- 页标题：`Concept of spectrum function`（**独立页眉，不带 4.6.x 小节号**）
- 中文正文要点（逐条完整转述，红色词为课件红字）：
  - `(1)` 「The spectrum of a `continuous periodic signal` consists of a series of `discrete spectral lines`,
    all of which appear on the frequency (harmonic) that is `an integral multiple of the fundamental frequency(基频的整数倍)`.
    The spectrum of a periodic signal is a `discrete spectrum （离散频谱）`.」
    **连续周期信号的频谱由一系列离散谱线组成**，这些谱线都出现在**基频的整数倍**频率（谐波）上。
    **周期信号的频谱是离散频谱。**
  - `(2)` 「It can be seen from the spectrum function expression that when `the pulse(脉冲信号) repetition period
    increases`, `the fundamental frequency, the spectral lines interval (谱线之间的间隔), and the amplitude decrease`.

    **由频谱函数表达式可见：当脉冲信号的重复周期增大时，基频、谱线间隔、幅度都减小。

  - `(3)` 「When `the period is infinite`, the signal is `aperiodic(非周期)`, and the

  - `(4)` 「The spectrum function is the `representation of the signal in the frequency domain`,
    and the `Fourier analysis method` is to use the spectrum function to analyze the signal.」
    **频谱函数是信号在频域中的表示；傅里叶分析方法就是用频谱函数来分析信号。**

- 数值：无具体数字。
- 疑点：
  1. ⚠️ **第 (2) 条自相矛盾**：前半句说「周期增大 → 基频、谱线间隔、幅度**都减小**」
     （谱线间隔 = 基频，说两者同时减小是**同义重复**，不算错）；
     后半句紧接着说「**离散周期时域信号的频谱是连续的**」——**与第 (1) 条「周期信号频谱是离散频谱」直接冲突**。

## p92
- 页标题：`4.6.2 Effective value of non-sine periodic quantity`
- 中文正文要点：
  - 「■The effective value is the `root mean square (均方根)` value of periodic voltage and current」
    **有效值就是周期电压和电流的均方根（root mean square）值。**
  - 「If」**若**
  - 「Then」**则**
  - 「Where, $U_k=\dfrac{1}{\sqrt2}U_{k\mathrm{m}}$, $I_k=\dfrac{1}{\sqrt2}I_{k\mathrm{m}}$, is the effective value of
    each harmonic of voltage or current.」
    **其中 $U_k=\frac{1}{\sqrt2}U_{k\mathrm{m}}$、$I_k=\frac{1}{\sqrt2}I_{k\mathrm{m}}$ 是电压或电流各次谐波的有效值。**
    （⚠️ 原文这里有个**印刷重复**：`，is the effective value`，多个逗号，见疑点。）
  - 结论（红字，全段最重要的一句）：
    「The effective value of a `non-sine periodic signal` is equal to the `square root of the sum of the squares of
    the effective values of the DC component and each harmonic component`.」
    **非正弦周期信号的有效值，等于直流分量与各次谐波分量有效值的平方和的平方根。**
  - 右中部有红色大号 **`Why？`**（**这是课件留给课堂回答的提问，是全页唯一的口头互动痕迹**）
- 公式（**逐个写全**）：
  - 有效值定义（均方根）：
    $$U=\sqrt{\frac{1}{T}\int_{0}^{T}u^{2}(t)\,\mathrm{d}t}\qquad
    I=\sqrt{\frac{1}{T}\int_{0}^{T}i^{2}(t)\,\mathrm{d}t}$$
  - 展开式（两种信号统一用含 $U_0$、$U_{k\mathrm{m}}$、$\theta_{uk}$ 的形式）：
    $$u(t)=U_0+\sum_{k=1}^{\infty}U_{k\mathrm{m}}\sin(k\omega t+\theta_{uk})\qquad
    i(t)=I_0+\sum_{k=1}^{\infty}I_{k\mathrm{m}}\sin(k\omega t+\theta_{ik})$$
  - **有效值公式（本段核心结论）**：
    $$U=\sqrt{U_0^{2}+U_1^{2}+U_2^{2}+\cdots+U_k^{2}+\cdots}\qquad
    I=\sqrt{I_0^{2}+I_1^{2}+I_2^{2}+\cdots+I_k^{2}+\cdots}$$
  - 各次谐波有效值与振幅的关系：
    $$U_k=\frac{1}{\sqrt2}U_{k\mathrm{m}},\qquad I_k=\frac{1}{\sqrt2}I_{k\mathrm{m}}$$
- 图/表：无图。整页为定义式 + 展开式 + 结论式 + 红字 `Why？`。
- 数值：系数 $\dfrac{1}{\sqrt2}\approx0.7071$；无其它具体数字。
- 复算（**用 p81 的信号做端到端验证**）：
  - 信号 $u(t)=80+220\sqrt2\sin(2\pi50t)+100\sqrt2\sin(2\pi100t+30^\circ)
    +45\sqrt2\sin(2\pi350t-20^\circ)+30\sqrt2\sin(2\pi700t+65^\circ)$
  - 直接数值积分 $\sqrt{\frac1T\int_0^T u^2\mathrm{d}t}$（$T=0.02$ s，步长取 400 万点）
    $=260.240274$ V
  - 公式计算 $\sqrt{U_0^2+U_1^2+U_2^2+U_3^2+U_4^2}
    =\sqrt{80^2+220^2+100^2+45^2+30^2}=\sqrt{128925}=260.240274$ V
  - ✅ **两者完全一致（小数点后 6 位）**，有效值公式得到验证。无复算不符。
  - 另验证正交性：$\frac1T\int_0^T\sin^2(2\omega t)\mathrm{d}t=\frac12$ ✔（这正是 $U_k=U_{k\mathrm{m}}/\sqrt2$ 的来源）
- 疑点：
  1. ⚠️ **印刷/排版小问题**：`Where，U_k=..., I_k=...，is the effective value of each harmonic` 这句里
     主语是 $U_k,I_k$（复数），动词却用了 `is`，且逗号堆叠；属排版与语法小瑕疵。
  2. **公式里的 $\theta_{uk}$、$\theta_{ik}$ 与前面 p79/p80 的 $\varphi_k$、p93 的同一记号不统一**：
     本页用 $\theta_{uk}$（电压第 $k$ 次谐波初相），前面用 $\varphi_k$。同一份课件三套记号：
     $A_{k\mathrm{m}},\varphi_k$ → $a_k,b_k$ → $U_{k\mathrm{m}},\theta_{uk}$。
  3. **最关键的缺陷：有效值公式 $U=\sqrt{U_0^2+\sum U_k^2}$ 的推导过程完全没给**，
     只在页面上留了一个红字 `Why？`。这个 `Why？` 的答案是**三角函数的正交性**：
     展开 $u^2(t)$ 后，不同频率的交叉项（如 $2U_0U_{k\mathrm{m}}\sin(\cdot)$、$U_{k\mathrm{m}}U_{j\mathrm{m}}\sin(k\omega t)\sin(j\omega t)$，$k\ne j$）
     在一个周期上的积分**全为 0**（正交性），只剩 $U_0^2$ 与各 $U_{k\mathrm{m}}^2\sin^2$ 的项，
     而 $\frac1T\int_0^T\sin^2(k\omega t+\theta)\mathrm{d}t=\frac12$，于是每个 $U_{k\mathrm{m}}^2$ 贡献 $\frac12 U_{k\mathrm{m}}^2=U_k^2$。
     我用 sympy 验证了正交性：$\int_0^T\sin(2\omega t)\sin(3\omega t)\mathrm{d}t=0$、
     $\int_0^T\cos(2\omega t)\cos(3\omega t)\mathrm{d}t=0$、$\int_0^T\sin(2\omega t)\cos(3\omega t)\mathrm{d}t=0$ ✔
     注意：**本页的 `Why？` 与 p93 的「正交性」是同一个数学事实**，但课件把 `Why？` 放在 p92、
     把「正交性」放在 p93 讲功率时才提，**同一个知识点被拆在两页、p92 这边没有回收**。
  4. 有效值公式**对非正弦周期信号成立的前提是各次谐波频率不同（正交）**，
     如果两个分量频率相同（如两个同频正弦源），交叉项不为 0，公式失效。课件未提这个前提。

## p93
- 页标题：`4.6.3 Power of non-sine periodic AC steady state circuit`
- 中文正文要点：
  - 「■If the series expansion of voltage and current of a branch (port N) is:」
    **若某支路（端口 N）的电压和电流的级数展开为：**
  - 「The average power absorbed is」**吸收的平均功率为**
  - 「According to the `orthogonality of trigonometric functions(三角函数的正交性)`, there is」
    **根据三角函数的正交性，有** （**这是全段解答「为什么不同频率谐波不产生平均功率」的关键依据**）

    **非正弦周期交流稳态电路的平均功率，等于电路中直流分量的平均功率与各正弦谐波分量平均功率之和。**

  - 电压电流级数：
    $$u(t)=U_0+\sum_{k=1}^{\infty}U_{k\mathrm{m}}\sin(k\omega t+\theta_{uk})\qquad
    i(t)=I_0+\sum_{k=1}^{\infty}I_{k\mathrm{m}}\sin(k\omega t+\theta_{ik})$$
  - 平均功率的定义与代入展开（**这一行是「正交性消去交叉项」的出发式**）：
    $$P=\frac{1}{T}\int_{0}^{T}u(t)i(t)\,\mathrm{d}t
    =\frac{1}{T}\int_{0}^{T}\left[U_0+\sum_{k=1}^{\infty}U_{k\mathrm{m}}\sin(k\omega t+\theta_{uk})\right]
    \left[I_0+\sum_{k=1}^{\infty}I_{k\mathrm{m}}\sin(k\omega t+\theta_{ik})\right]\mathrm{d}t$$
  - **平均功率结论式（本段核心）**：
    $$P=P_0+\sum_{k=1}^{\infty}P_k=P_0+P_1+P_2+\cdots$$
  - ⚠️ **课件没有把 $P_0$ 与 $P_k$ 的展开式写出来**（这是本页最大的缺失）。按讲义标准应补：
    $$P_0=U_0I_0,\qquad P_k=\frac{1}{2}U_{k\mathrm{m}}I_{k\mathrm{m}}\cos(\theta_{uk}-\theta_{ik})=U_kI_k\cos\varphi_k$$
    其中 $\varphi_k=\theta_{uk}-\theta_{ik}$ 是第 $k$ 次谐波电压超前电流的相位差。
- 图/表：
  - **右上：单端口网络图**。一个矩形方框，内部标 `N`。
    左侧两根引出线：上端标 $i(t)$ 并有向右箭头（电流流入方框），
    端口标 $+$ / $-$ 与 $u(t)$（上正下负，**关联参考方向**：电流从 $u$ 的 `+` 端流入）。
    这是一个标准的一端口（二端网络）功率定义图。
  - **复现性**：可用 mermaid 或 python/matplotlib 画（一个方框 + 两条线 + 标注）。
    **裁切价值低**（元件极少）；建议用 mermaid 或纯文字描述代替。
- 数值：无具体数字（纯符号）。页码 `93`。
- 复算（正交性验证，sympy）：
  - $\displaystyle\int_0^T\sin(2\omega t)\sin(3\omega t)\,\mathrm{d}t=0$ ✔
  - $\displaystyle\int_0^T\cos(2\omega t)\cos(3\omega t)\,\mathrm{d}t=0$ ✔
  - $\displaystyle\int_0^T\sin(2\omega t)\cos(3\omega t)\,\mathrm{d}t=0$ ✔
  - $\displaystyle\int_0^T\sin(2\omega t)\cos(2\omega t)\,\mathrm{d}t=0$ ✔（同频率的正弦×余弦也正交）
  - $\displaystyle\frac1T\int_0^T\sin^{2}(2\omega t)\,\mathrm{d}t=\frac12$ ✔
  - ✅ **正交性结论成立**，即 $k\ne j$ 的交叉项全部积分为 0，所以
    「不同频率的谐波不产生平均功率」；同频率的 $u_k$ 与 $i_k$ 的乘积项才留下 $\frac12U_{k\mathrm{m}}I_{k\mathrm{m}}\cos(\theta_{uk}-\theta_{ik})$。
    **直流分量只与直流分量产生功率（$U_0I_0$）**，因为直流与任何正弦在一个周期上积分为 0
    （即 $\int_0^T\sin(k\omega t+\theta)\mathrm{d}t=0$）。
- 疑点：
  1. ⚠️ **$P_0$ 与 $P_k$ 的展开式缺失**：本页只写到 $P=P_0+\sum P_k$ 就停了，
     **没有给出 $P_0=U_0I_0$、$P_k=\frac12U_{k\mathrm{m}}I_{k\mathrm{m}}\cos\varphi_k$**。
     而 p94–p96 的例题直接用 $\frac12U_{k\mathrm{m}}I_{k\mathrm{m}}\cos\varphi_k$，
     **读者必须靠例题反推公式**。这是本段最关键的一处「公式缺项」。
  2. ⚠️ **相角差记号 $\varphi_k$ 未定义**：公式应写成 $\cos(\theta_{uk}-\theta_{ik})$，
     课件完全没写这个差角的记号；而 p95/p96 的例题又出现 $\cos(-90^\circ+60^\circ)$ 这种
     **用 $\theta_{uk}$ 与 $\theta_{ik}$ 拼接**的写法，读者无法判断到底是 $\theta_{uk}-\theta_{ik}$ 还是别的。
     p94 的例题用的是 $\cos\varphi_1$（把 $\varphi_1$ 当作「功率因数角」直接给出）。
     **三页三种写法，没有一处统一说明。**

  4. 端口图用的是**关联参考方向**（$i$ 从 $u$ 的 `+` 流入），所以算出来的是**吸收**的功率；

     （箭头画在端口上方，与 $+$ 端位置关系不够清楚）。

## p98
- 页标题：`4.6.4 Harmonic analysis method of non-sine periodic ac circuit`
- 中文正文要点：整页为一张**流程图**，无段落文字；框内英文标注如下（逐框转述）：
  - 左上：`Frequency f of non-sine periodic signal`（非正弦周期信号的频率 $f$）
  - 上中：`Linear passive circuit`（线性无源电路）
  - 右上：`Steady State Response of Non-sine Periodic AC Circuits`（非正弦周期交流电路的稳态响应）
  - 左中：`Harmonic decomposition`（谐波分解）
  - 中间红字大标：`Phasor analysis`（相量分析）
  - 中左起三行：`DC component`（直流分量）、`1st harmonic`（1 次谐波）……`Nth harmonic`（$N$ 次谐波），
    中间用**蓝色竖排三点 `⋮`** 表示省略的中间各次谐波
  - 中中三框：`DC circuit analysis`（直流电路分析）、`Sine steady state circuit with frequency f`（频率 $f$ 的正弦稳态电路）、
    `Sine Steady State Circuit with Frequency Nf`（频率 $Nf$ 的正弦稳态电路）
  - 中右三框：`DC response component`（直流响应分量）、`First harmonic response component`（1 次谐波响应分量）、
    `N-th harmonic response component`（$N$ 次谐波响应分量），中间同样有**蓝色竖排三点 `⋮`**
  - 右上侧红框：`Time-domain superposition`（时域叠加）
- 公式：无显式公式（流程即算法）。**谐波分析法的步骤（我按图归纳）：**
  1. 把非正弦周期激励 $f(t)$ **分解**成傅里叶级数：直流分量 + 各次谐波（`Harmonic decomposition`）；
  2. 对**直流分量**用**直流电路分析**（`DC circuit analysis`，电容开路、电感短路），得直流响应分量；
  3. 对**第 1 次谐波**（频率 $f$）用**相量法**求解正弦稳态电路 `Sine steady state circuit with frequency f`，得 1 次谐波响应；
  4. 对**第 $N$ 次谐波**（频率 $Nf$）同样用**相量法**求解 `Sine Steady State Circuit with Frequency Nf`，得 $N$ 次谐波响应；
     （中间各次谐波同法，图中用 `⋮` 省略）
  5. 最后把各次谐波的响应在**时域叠加**（`Time-domain superposition`），得到非正弦周期交流电路的稳态响应。
  **注意：第 3、4 步必须在「相量域」内各自独立求解，不能先叠加相量再一起算**（不同频率的相量不能相加），
  这一步是流程图里用红色大箭头 `Phasor analysis` 单独强调的原因。
- 图/表（**这是全段唯一的流程图，也是最值得裁切的插图**）：
  - 版式：**上排一条主链路**（黑框 + 黑箭头）：`Frequency f …` → `Linear passive circuit` → `Steady State Response …`；
    从 `Linear passive circuit` 向下出一个**红色空心大箭头**，指向下方整块「谐波分解 → 相量分析 → 时域叠加」的处理流程。
  - **左列**：`Harmonic decomposition`（红框）向下引出三条红线，分别指向 `DC component`、`1st harmonic`、`Nth harmonic`（黑字无框）。
  - **中列**：三个**红框**（`DC circuit analysis`、`Sine steady state circuit with frequency f`、
    `Sine Steady State Circuit with Frequency Nf`），红色箭头连接。
  - **右列**：三个无框文字（`DC response component`、`First harmonic response component`、
    `N-th harmonic response component`）。
  - **右上红框** `Time-domain superposition`，从右列三条响应各引一条**红色箭头**汇入它，
    再由它向上引红色箭头指向 `Steady State Response …`。
  - **红色是主体（处理流程），黑色只有最上面一条主链路**；红框共 5 个。
  - `⋮` 省略号用**蓝色竖排三点**，共两处（左列 `1st harmonic` 与 `Nth harmonic` 之间、右列对应位置）。
  - **复现性**：**完全可以用 mermaid `flowchart` 复现**，而且能把红色/黑色层级、省略号都表达清楚，
    比裁图更清晰。**推荐 mermaid 复现**；若必须裁切，整页裁一张即可
    （原始 960×540 pt 近似 `x 30–940, y 100–520`）。
- 数值：`f`（基频）、`1st`、`Nth`、`Nf`；无具体频率数字。页码 `98`。
