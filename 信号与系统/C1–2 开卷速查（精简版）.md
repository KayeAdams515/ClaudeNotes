## 1. 信号与分类

**维度 = 自变量个数；通道 = 函数值分量数（通道不增维）**

| 信号 | 维度 | 通道 | 信号 | 维度 | 通道 |
|---|---|---|---|---|---|
| 单声道语音 | 1 | 1 | 立体声 | 1 | 2 |
| 灰度/二值图 | 2 | 1 | 彩色图 | **2** | 3 |
| 黑白视频 | 3 | 1 | 彩色视频 | 3 | 3 |
| 点云/3D 超声 $I(x,y,d)$ | 3 | 1 | 四维彩超 | 4 | 1/3 |

- **连续/离散只看自变量轴**；函数值取整数 = **量化**，不影响这个判断。采样（自变量）→ 量化（幅度，$2^n$ 级）→ 编码 = 数字化。
- 三分类：连续/离散、周期/非周期、确定/随机（随机只给分布 PDF）。能量/功率**不是**二分类。
- 两种表示：**函数表示**（可分段，便于运算）与**图形表示**（便于看变换）。

**能量与功率**

| 量 | 连续 | 离散 |
|---|---|---|
| 瞬时功率 | $p=x^2(t)$ | $p[n]=x^2[n]$ |
| 总能量 | $E=\int_{-\infty}^{\infty}x^2dt$ | $E=\sum_{-\infty}^{\infty}x^2[n]$ |
| 平均功率 | $P=\lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}x^2dt$ | $P=\lim\limits_{N\to\infty}\frac{1}{2N+1}\sum_{-N}^{N}x^2[n]$ |

- 复信号用 $\lvert x\rvert^2$；**周期信号只在一个周期上算 $P$**：$P=\frac{1}{T_0}\int_{T_0}x^2dt$。
- 分母：连续量长度 $2T$，离散数点数 $2N+1$。

| 类别 | 条件 | 典型 | 傅里叶 |
|---|---|---|---|
| 能量信号 | $E<\infty$（$P=0$） | 有限时长脉冲、$e^{-at}u(t)$ | ✅ |
| 功率信号 | $E=\infty$，$0<P<\infty$ | $\cos\omega_0t$、$u(t)$、常数 | ✅ 边界 |
| 都不是 | $E=\infty$ 且 $P=\infty$ | 双边 $e^{-2t}$、$e^{t}$ | ❌ 用 Laplace/Z |

- 三条性质：$E<\infty\Rightarrow P=0$；有限功率隐含 $P\ne0$；两类互斥。
- 快判：**有界周期→功率；有限时长有界→能量；发散→都不是**。⚠️ $e^{-t}$（双边）都不是 vs $e^{-t}u(t)$ 能量信号（$E=\frac12$）；$e^{2t}u(t)$ 仍 $E=\infty$。

## 2. 自变量变换

| 变换 | 连续 | 离散 | 口诀 |
|---|---|---|---|
| 时移 | $x(t-t_0)$ 右移/延迟；$x(t+t_0)$ 左移/超前 | $x[n-n_0]$ / $x[n+n_0]$ | 减号右移 |
| 反转 | $x(-t)$，绕 $t=0$ 竖线镜像 | $x[-n]$ | 不是绕原点 |
| 尺度 | $x(at)$：$a>1$ 压缩、$0<a<1$ 拉伸 | 内插零（第 3 章） | 括号乘几窄几倍 |

**$x(at+b)$ 两条路径（平移量不能混用）**

| 路径 | 顺序 | 平移量 | $x(6-2t)=x[-2(t-3)]$ |
|---|---|---|---|
| 一（考试用） | 先尺度→反转→平移 | $b/\lvert a\rvert$ | 压缩 2→反转→**右移 3** |
| 二（理解用） | 先平移→反转→尺度 | $b$ | **左移 6**→反转→压缩 2 |

- 判据：**看括号里的 $t$ 被换成了什么**。先写成 $x[a(t-t_0)]$ 再读位移。
- $x(4-3t)$：路径一右移 $4/3$；路径二左移 4。$x(6-2t)$ 关键点 $1.5,3,4$。
- ⚠️ $x(5-2t)$ 由 $x(-2t)$ **右移 $5/2$**（不是左移 5）。

| 写法 | 是什么 | 写法 | 是什么 |
|---|---|---|---|
| $x(t-t_0)$ | 时移 | $x(t)-t_0$ | 信号相减 |
| $x(2t)$ | 尺度 | $2x(t)$ | 乘常数 |
| $\frac{dx}{dt}$、$\int x\,dt$ | 纵轴运算 | | |

## 3. 周期性与奇偶分解

| | 连续 | 离散 |
|---|---|---|
| 定义 | $\exists T>0$，$x(t)=x(t+T)$ | $\exists N\in\mathbb{Z}^+$，$x[n]=x[n+N]$ |
| 条件 | 任意 $T>0$ | $\frac{\omega_0}{2\pi}$ **有理** |
| 求基波周期 | $T_0=2\pi/\omega_0$ | $\frac{2\pi}{\omega_0}$ 最简分数取**分子**；或 $\frac{\omega_0}{2\pi}$ 取**分母** |
| 基波频率 | $\omega_0=2\pi/T_0$ | $\omega_0=2\pi/N$（**$N$ 必为整数**） |

- 基波周期 = **最小正周期**；常数信号无最小正周期（离散记 $N=1$）。
- 速判：$\omega_0$ 带 $\pi$ 通常周期，不带 $\pi$ 通常非周期。$\cos\frac{3\pi n}{4}$：$\frac{2\pi}{\omega_0}=\frac83$ ⇒ $N=8$（不是 $\frac83$）。
- ⚠️ 基波频率**必须对应基波周期**：$\frac{3\pi}{4}$ 是 $N=8$ 的三次谐波，基波频率是 $\frac{\pi}{4}$。
- 离散频率以 $2\pi$ 为周期，只看 $[0,2\pi)$ 或 $[-\pi,\pi)$，**最高频 $\omega_0=\pi$**（$(-1)^n$）。
- 三件事别混：频率 $2\pi$ 周期（永远）/ 谐波集 $N$ 周期（基底只有 $N$ 个）/ 序列本身周期（需有理）。
- 合成：$N=\mathrm{lcm}(N_1,N_2)$；含一个非周期则整体通常非周期。乘积先积化和差。

$$\mathcal{Ev}\{x\}=\tfrac12[x(t)+x(-t)],\quad \mathcal{Od}\{x\}=\tfrac12[x(t)-x(-t)]$$

- 偶 ↔ 纵轴对称；奇 ↔ 原点对称，**奇信号 $x(0)=0$**。任何实信号唯一分解；复信号用共轭对称 $x_e=\frac12[x(t)+x^*(-t)]$。
- $u[n]$：$\mathcal{Ev}=1\,(n=0),\ \frac12\,(n\ne0)$；$\mathcal{Od}=0\,(n=0),\ \pm\frac12$。⚠️ 原点不成对，最易错。

## 4. 基本信号

### 4.1 复指数

- 欧拉：$e^{j\omega_0t}=\cos\omega_0t+j\sin\omega_0t$（单频）；$T=2\pi/\omega_0$ **无条件周期**。
- 单位：$\omega_0=2\pi f_0$，$T=1/f_0$。
- $C=\lvert C\rvert e^{j\theta}$：缩放幅度 + 旋转初相（等价平移 $-\theta/\omega_0$）。
- 一般复指数（$a=r+j\omega_0$）：$x=\lvert C\rvert e^{rt}e^{j(\omega_0t+\theta)}$ = **包络 × 振荡**；$r>0$ 发散振荡、$r<0$ 阻尼、$r=0$ 等幅。

| 离散实指数 $\alpha^n$ | 行为 |
|---|---|
| $\alpha>1$ | 单调增长 |
| $0<\alpha<1$ | 单调衰减 |
| $-1<\alpha<0$ | 正负交替、幅度衰减 |
| $\alpha<-1$ | 正负交替、幅度增长 |

- 离散复指数：$\frac{2\pi}{\omega_0}$ **有理才周期**；$x=\lvert C\rvert\lvert\alpha\rvert^n\cos(\omega_0n+\theta)+j\dots$（$\lvert\alpha\rvert=1$ 等幅、$>1$ 增长、$<1$ 衰减包络）。

- 离散：$C,\alpha$ **都用极坐标**；$\lvert\alpha\rvert$ 相对 1 ↔ 连续 $r$ 相对 0；单位圆 ↔ 虚轴；桥 $r=e^{sT}$。
- 谐波集 $\Phi_k=e^{jk\omega_0t}$ 公共周期 $T$；正交性：$\int_T e^{jk\omega_0t}e^{-jl\omega_0t}dt=T\,(k=l)$、$0\,(k\ne l)$；离散 $\sum_{\langle N\rangle}=N$ 或 $0$（$k,r$ 同一周期内）。

$$x(t)=\sum_{k=-\infty}^{\infty}a_ke^{jk\omega_0t},\quad a_k=\frac1T\int_T x(t)e^{-jk\omega_0t}dt$$
$$x[n]=\sum_{k=\langle N\rangle}a_ke^{jk\omega_0n},\quad \omega_0=\frac{2\pi}{N}$$

| | CTFS | DTFS |
|---|---|---|
| 基底维数 | 无穷维（希尔伯特空间） | **$N$ 维**（$\Phi_{k+N}=\Phi_k$） |
| $k$ 范围 | 全整数 | 只取满一个周期 |

### 4.2 冲激与阶跃

| | 离散 | 连续 |
|---|---|---|
| 冲激 | $\delta[n]=1\,(n=0)$，否则 0；**普通序列** | $\delta(t)$：$t\ne0$ 为 0，$\int\delta=1$；**广义函数** |
| 阶跃 | $u[n]=1\,(n\ge0)$ | $u(t)=1\,(t>0)$，**$u(0)$ 无定义** |
| 冲激←阶跃 | $\delta[n]=u[n]-u[n-1]$ | $\delta(t)=u'(t)$（需极限解释） |
| 阶跃←冲激 | $u[n]=\sum_{m=-\infty}^{n}\delta[m]$ | $u(t)=\int_{-\infty}^{t}\delta(\tau)d\tau$ |
| 分解 | $x[n]=\sum_k x[k]\delta[n-k]$ | $x(t)=\int x(\tau)\delta(t-\tau)d\tau$ |
| 抽样 | $\sum_n x[n]\delta[n-n_0]=x[n_0]$ | $\int x(t)\delta(t-t_0)dt=x(t_0)$ |
| 尺度 | 无（$\delta[an]=\delta[n]$） | $\delta(at)=\delta(t)/\lvert a\rvert$ |

- **乘 $\delta$ 出信号，积 $\delta$ 出数**：$x[n]\delta[n-n_0]=x[n_0]\delta[n-n_0]\ne x[n_0]$。
- $\delta(t)$：面积为本、形状无关（矩形/居中矩形/三角均可，$\lim\delta_\Delta=\delta$）；$\delta(-t)=\delta(t)$；$\delta=\delta*\delta$。
- $\delta^{(-1)}=u$；$\delta^{(k)}$ = 求 $k$ 阶导算子 ⇒ **卷奇异函数 = 施加一次微分/积分**。
- 断点求导：**位置=跳变位置，强度=跳变量（向下跳为负）**。例 $0\to1\to2\to0$ ⇒ $\delta(t)+\delta(t-1)-2\delta(t-2)$（下跳 2 步，系数 2）。
- 含冲激积分三步：化 $\delta(t-t_1)$ 并提出 $\frac{1}{\lvert a\rvert}$ → 定 $t_1=-b/a$ → 查区间（不在则 0）。
- 抽样两前提：**冲激落在积分区间内**（否则 0）；$x$ 在 $t_0$ **连续**。

| 例 | 答案 | | 例 | 答案 |
|---|---|---|---|---|
| $\int(2t^2+3t)\delta(\frac t2-2)dt$ | $88$ | | 同上区间 $[-3,3]$ | $0$ |
| $\int(t+4)\delta(-2t+4)dt$ | $3$ | | $\int t^2\delta(3t-6)dt$ | $4/3$ |

**11 条公式（乘=取值；卷=搬移）**

| 相乘类 | 卷积类 |
|---|---|
| (1) $x\delta=x(0)\delta$ | (5) $x*\delta=x$ |
| (2) $x\delta(t-t_0)=x(t_0)\delta(t-t_0)$ | (6) $x*\delta(t-t_0)=x(t-t_0)$ |
| (3) $\int x\delta(t-t_0)dt=x(t_0)$ | (7) $x(t-t_1)*\delta(t-t_2)=x(t-t_1-t_2)$ |
| (4) $\delta(at)=\delta(t)/\lvert a\rvert$ | (8) $x*\delta'=x'$ |
| (8′) $x\delta'=x(0)\delta'-x'(0)\delta$ | (9) $x*u=x^{(-1)}=\int_{-\infty}^{t}x$ |
| 补 $\int x\delta'(t-t_0)dt=-x'(t_0)$ | (10) $u*\delta'=\delta$； (11) $\int\delta'=0$ |

- ⚠️ 结果里有 $\delta$ ⇒ 相乘（取值）；没有 $\delta$ ⇒ 卷积（搬移）。
- 冲激偶 $\delta'$：一正一负、**总面积 0**；含 $\delta'$ 的系统不稳定（微分器）。

## 5. 系统与六性质

- **信号是函数，系统是方程**；标准形式：输入在右、输出在左。$x\to\boxed{L}\to y$。
- 连续 LTI ⇔ 常系数微分方程；离散 ⇔ 常系数差分方程。
- LCCDE：线性 / 常系数（⇔时不变）/ $N$ 阶 / $N$ 个初始条件 / $N\ge M$（否则含纯微分器，不可实现）。

| 互联 | 整体 $h$（LTI） | 备注 |
|---|---|---|
| 串联/级联 | $h_1*h_2$ | 可换序；一环断全链断 |
| 并联 | $h_1+h_2$ | 输出相加 |
| 串并联 | 反用上两行 | 第 2 章出题主力 |
| 反馈 | 需解方程 | 闭环、隐式；控制的基础 |

| 性质 | 定义/判据 | 典型反例 | LTI 下 → $h$ |
|---|---|---|---|
| 记忆 | 只依赖同一时刻 ⇒ 无记忆；记忆长度=最远偏移 | $x[n-1]$、积分、$x[n+1]$ | $h=k\delta$ |
| 可逆 | 一一对应；逆系统级联=恒等 | $y=0$、$x^2$、$x[n]x[n-2]$ | $h*h_1=\delta$；频域 $1/H$ |
| 因果 | 只依赖当前与过去；初始松弛 | $x[n+1]$、$x[-n]$、$x(\sin t)$ | $h=0\,(t<0)$ |
| 稳定 | BIBO：有界入→有界出 | 找有界输入使输出无界 | $\int\lvert h\rvert<\infty$（充要） |
| 时不变 | $x(t-t_0)\to y(t-t_0)$，三步法 | $tx(t)$、$x(-t)$、$x(\sin t)$、$nx[n]$ | — |
| 线性 | $ax_1+bx_2\to ay_1+by_2$，四步法 | $x^2$、$2x+3$、$\sin x$ | — |

- **时不变三步**：① $x_1\to y_1$ ② $x_2\to y_2$ ③ 令 $x_2=x_1(t-t_0)$，比 $y_2$ 与 $y_1(t-t_0)$。$y_2$ 里系统显式 $t$ **不动**；$y_1(t-t_0)$ 把**所有** $t$ 换成 $t-t_0$。
- **线性四步**：$x_1\to y_1$、$x_2\to y_2$、$x_3\to y_3$（照写）、令 $x_3=ax_1+bx_2$ 验 $y_3=ay_1+by_2$。
- Step2 代换 $x_2(\cdot)$ 的自变量（可能是 $\sin t$），Step3 代换 $y_1(\cdot)$ 的裸 $t$；$\sin t-t_0\ne\sin(t-t_0)$ ⇒ 时变。
- **在线（online）必须因果；非因果只能离线（offline）批处理**（滑动平均去噪就是离线）。
- 速判（仍需写步骤）：动**时间轴**（$x(2t)、x(-t)、x(\sin t)$）→ 时变；只动**函数值**（$\sin x、x^2$）→ 通常时不变。
- 高频对照：$\sin[x(t)]$ **非线性、时不变、因果**；$x(\sin t)$ **线性、时变、非因果**。
- 线性必要条件：**零输入⇒零输出**；有常数项 ⇒ **增量线性**（$y=3x+2$ 即带非零初态的 LTI）。
- 六性质独立，必须逐条验；否定只需一个反例（不可逆找两输入同输出；不稳定找一个有界输入）。
- LTI：$ax(t)+bx(t-t_0)\to ay(t)+by(t-t_0)$ ⇒ $y=x*h$，$h$ 完全刻画。

## 6. 卷积

$$y[n]=\sum_{k}x[k]h[n-k],\qquad y(t)=\int x(\tau)h(t-\tau)d\tau$$

- 推导三条：$\delta[n-k]\to h[n-k]$（时不变）、$x[k]\delta\to x[k]h$（齐次）、求和（可加）。
- 五步：换元 → 反转 → 平移（$h[n-k]$，右移 $n$，锚点 $k=n$）→ 相乘 → 求和/积分。
- 固定一个、滑动另一个；分段看**重叠区间**；先写骨架：

$$L_y=L_x+L_h-1,\qquad n_{y,\min}=n_{x,\min}+n_{h,\min}$$

| 卷积对 | 结果 |
|---|---|
| $u[n]*a^nu[n]$ | $\frac{1-a^{n+1}}{1-a}u[n]$（终值 $\frac{1}{1-a}$） |
| $R_N*R_N$ | 三角：$n+1$（$0\le n\le N-1$）、$2N-1-n$（$N-1<n\le2N-2$）；峰 $N$ 在 $n=N-1$ |
| $\alpha^nu[n]*\beta^nu[n]$ | $\frac{\beta^{n+1}-\alpha^{n+1}}{\beta-\alpha}u[n]$；$\alpha=\beta$：$(n+1)\alpha^nu[n]$ |
| $e^{-t}u(t)*u(t)$ | $(1-e^{-t})u(t)$ |
| $e^{-2t}u(t)*u(t-1)$ | $\frac12(1-e^{-2(t-1)})u(t-1)$ |
| $p_1*p_1$（宽 1 高 1） | $1-\lvert t\rvert$（$\lvert t\rvert\le1$），底宽 2 |

- **矩形*矩形=三角；不等宽=梯形**：总宽 $T_1+T_2$，升 $T_1$、平台 $T_2-T_1$、降 $T_1$，峰 $=T_1\times$两高度之积。
- **端点**：左端点=两左端点之和；右端点=两右端点之和。**面积**：$\int y=\int x\cdot\int h$。
- 列表法（有限长）：$\uparrow$ 标 $n=0$，横 $x$ 纵 $h$ 填乘积，**同 $k+m$ 的反对角线相加**；自检：起点相加、长度 $L_x+L_h-1$、$\sum y=\sum x\sum h$。
- ⚠️ 项数=上限−下限$+1$；$n=2N-2$ 时两矩形仍共享一点（$y=1$）；向 $-\infty$ 求等比和用 $\frac{r^m}{1-r}$；连续积分变量是 $\tau$；**跨跳变点必须拆积分**。

## 7. 卷积性质与 $h$ 的条件

| 性质 | 公式 | 框图 |
|---|---|---|
| 交换 | $x*h=h*x$ | 输入与系统对等（哪个好翻翻哪个） |
| 分配 | $x*(h_1+h_2)=x*h_1+x*h_2$ | 并联 ⇒ $h_1+h_2$ |
| 结合 | $x*(h_1*h_2)=(x*h_1)*h_2$ | 串联 ⇒ $h_1*h_2$，可换序 |

- **恒等系统 $h=\delta$（不是 1）**；串联是卷积不是乘法（频域才是乘法）；换序只对 LTI（×2 与平方不可换）。
- 时移：$x(t-t_0)*h=x*h(t-t_0)=y(t-t_0)$；推论 $x(t-t_1)*h(t-t_2)=y(t-t_1-t_2)$。
- 微分：$x'*h=x*h'=y'$；高阶可任意分配。积分：$x^{(-1)}*h=y^{(-1)}$。离散版：差分/求和。
- **求导法**（方波*斜坡等硬题）：① 方波求导 $=\delta(t)-\delta(t-T)$；② $y'=x'*h=h(t)-h(t-T)$；③ 积分回去（**积分常数由 $t\to-\infty$ 时 $y=0$ 定**）。
- **由 $x_1\to y_1$ 推 $y_2$**：不能求 $h$（卷积无逆运算）；把 $x_2$ 写成对 $x_1$ 的「时移+微积分」→ 同套操作作用到 $y_1$ → 积分回去。⚠️ 别丢隐含 $u$、别把左移记成右移。
- 阶跃响应：$s=h*u$，$h=s'$（离散 $h=\Delta s$）；实验室测 $s$ 更容易（真 $\delta$ 做不出来）。
- BIBO：$\int\lvert h\rvert<\infty$ / $\sum\lvert h\rvert<\infty$（充要）；必要性取 $x[n]=\operatorname{sgn}(h[-n])$ 反证。
- 判稳定只看**实部/模**；$u[-n+c]$ 是**左边**信号，底数 $>1$ 反而衰减；$n\cos(\frac{\pi n}{4})u[n]$ 因 $n$ 增长不稳定。

## 8. 由方程求响应

**经典法（连续）**：齐次方程 → 试 $e^{st}$ → 特征方程 → $y_h$；特解照输入形状；合成 $y=y_h+y_p$；**最后**用 $N$ 个初始条件定系数（⚠️ 先合成再定系数）。

| 输入 | 特解 |
|---|---|
| 常数 | $K$ |
| $e^{\alpha t}$（$\alpha$ 非特征根） | $Ce^{\alpha t}$，$C=1/P(\alpha)$ |
| $\cos\omega t$ 或 $\sin\omega t$ | $K_1\cos\omega t+K_2\sin\omega t$（两项都要） |
| $t^m$ | $\sum_{j=0}^{m}K_jt^j$ |
| $\alpha$ **是**特征根（撞车，$P(\alpha)=0$） | 乘 $t$；$k$ 重根乘 $t^k$ |

| 根型 | 连续 $y_h$ | 离散 $y_h$ |
|---|---|---|
| 互异实根 | $\sum K_ie^{s_it}$ | $\sum C_ir_i^n$ |
| $n$ 重根 | $(\sum K_jt^{j-1})e^{st}$ | $(\sum C_jn^{j-1})r^n$ |
| 共轭 $\sigma\pm j\omega$ / $\rho e^{\pm j\omega_0}$ | $e^{\sigma t}(K_1\cos\omega t+K_2\sin\omega t)$ | $\rho^n(C_1\cos\omega_0n+C_2\sin\omega_0n)$ |

- **全响应**：$y=y_h+y_p=y_{zi}+y_{zs}$；$y_{zs}=x*h$（初始松弛）；**只有 $y_{zs}=x*h$**。
- $y_{zi}$：解齐次方程、用**真实初始状态 $y(0^-)$**（输入接入前的储能）；$y_{zs}$：同特解、初始状态取零。
- ⚠️ 若输入含 $\delta$ 或跳变传到输出，$y(0^+)\ne y(0^-)$，须先做**跳变分析**把 $0^-$ 换成 $0^+$。
- **$y_h\ne y_{zi}$、$y_p\ne y_{zs}$**：前者系数被输入污染；四项两两不等，只有和相等。
- 增量线性：$y=3x+2$（$y(0)=2$ 就是 $y_{zi}$），名字要叫对。
- 差分方程：特征方程**最高阶配最高次幂**（$y[n]\to r^N$）；撞车判据 $P(r)=0$；撞车乘 $n$。
- ⚠️ 离散「零状态」是 $y[-1]=y[-2]=0$，**不是 $y[0]=0$**；题目给的 $y[0],y[1]$ 是**等效初始条件**（已含输入），通解只对 $n\ge0$ 成立。
- 稳定：连续 $\mathrm{Re}\{s\}<0$；离散 $\lvert r\rvert<1$（$=1$ 临界，不满足 BIBO）。

**标准结果（背下来当模板）**

| 题 | 答案 |
|---|---|
| $y''+6y'+8y=x$，$y(0)=1,y'(0)=2$，$x=e^{-t}u(t)$ | $\frac52e^{-2t}-\frac{11}{6}e^{-4t}+\frac13e^{-t}$ |
| 同上：$y_{zi}$ | $3e^{-2t}-2e^{-4t}$ |
| 同上：$h$ | $\frac12(e^{-2t}-e^{-4t})u(t)$ |
| 同上：$y_{zs}$ | $-\frac12e^{-2t}+\frac16e^{-4t}+\frac13e^{-t}$ |

| 同上：真实初值 / $y_{zi}$ / $y_{zs}$ | $(\frac12,\frac{7}{12})$ / $5\cdot2^n-6\cdot3^n$ / $-8\cdot2^n+9\cdot3^n-n2^{n+1}$ |

## 9. 方框图

| | 离散 | 连续 |
|---|---|---|
| 记忆件 | 延迟器 D | 积分器 $\int$ |
| DF I 单元数 | $N+M$ | $N+M$ |
| DF II 单元数 | $\max(N,M)$ | $\max(N,M)$ |
| 前馈系数 | $b_k$（照抄） | $b_{N-k}$（按积分重数） |
| 反馈系数 | $-a_k$（移项变号） | $-a_{N-k}$ |

- 不用微分器：$u\to\delta$ 无界；增益 $\lvert\omega\rvert$ 放大噪声；⇒ 也解释 $N\ge M$。
- DF I：$w=\sum b_kx[n-k]$ 前馈链 + $y=\frac{1}{a_0}[w-\sum a_ky[n-k]]$ 反馈链。
- DF II：**交换律换序** ⇒ 两链共用一组 D（正准型）；系数不变。
- $a_0\ne1$：两边同除，或输出前乘 **$1/a_0$（倒数）**。
- 连续：两边积分 $N$ 次把 $y^{(N)}$ 降成 $y$，再从积分器链逐级取。
- 从图写方程：前馈→右边（照抄）、反馈→左边（取相反数）、$1/a_0$ 定归一化。
- 例 $y[n]-5y[n-1]+6y[n-2]=2x[n]-3x[n-1]$：DF I 3 个 D、DF II 2 个 D；反馈线 $+5,-6$，前馈第二条 $-3$；$r=2,3$ ⇒ 不稳定。

## 10. 丢分点（考前扫一遍）

1. 彩色图 2 维 3 通道；通道不增维。
2. 量化 ≠ 采样；阶梯信号仍是连续时间。
3. 离散 $P$ 分母 $2N+1$；$E$ 有限就答能量信号，别再加「功率也有限」。
4. $e^{-t}$ 与 $e^{-t}u(t)$ 结论相反；$e^{2t}u(t)$ 仍非能量信号。
5. $x(at+b)$ 先提 $a$；先尺度则平移 $b/\lvert a\rvert$，先平移则 $b$。
6. 离散 $N$ 必须正整数；基波频率 $=2\pi/N$，不是抄系数。
7. $x(5-2t)$：右移 $2.5$。
8. $u(0)$ 无定义、$u[0]=1$；$\delta[0]=1$、$\delta(0)$ 无有限值。
9. 滑动积分写 $\int_{-\infty}^{t}\delta(\tau)d\tau$。
10. 断点求导：下跳取负、跳几步系数就是几。
11. $\delta(at)$ 的 $1/\lvert a\rvert$ 只属连续；积分区间没盖住冲激 ⇒ 0。
12. $\int x\delta'(t-t_0)dt=-x'(t_0)$，负号别漏。
13. 六性质独立；无记忆⇒因果，反之不然。
14. 时不变三步、线性四步，一步不能省；否定找反例。
15. $\sin[x(t)]$ 非线性时不变；$x(\sin t)$ 线性时变非因果（查负半轴）。
16. 线性必要条件：零输入⇒零输出。
17. 判稳定看实部/模；左边信号底数 $>1$ 也稳定。
18. 卷积锚点 $k=n$；项数 $+1$；$n=2N-2$ 不为 0。
19. 跨跳变点拆积分；连续积分变量 $d\tau$。
20. 串联是卷积不是乘法；恒等系统 $h=\delta$。
21. 求导法算完必须积分回去。
22. 推 $y_2$ 不能求 $h$；别丢 $u$、别把左移写成右移。
23. 经典法先合成 $y_h+y_p$ 再定系数。
24. $y_h\ne y_{zi}$；只有 $y_{zs}=x*h$。
25. 撞车判据：$P(\alpha)=0$ / $P(r)=0$，乘 $t$ 或 $n$。
26. 离散零状态是 $y[-1]=0$，不是 $y[0]=0$；$y[0],y[1]$ 是等效初值。
27. 特征方程最高阶配最高次幂。
28. 方框图反馈系数变号；$a_0\ne1$ 时乘 $1/a_0$；DF I $N+M$、DF II $\max(N,M)$。
29. 乘 $\delta$ 取值、卷 $\delta$ 搬移；结果有无 $\delta$ 可自查。
30. $\delta^{(-1)}=u$；卷 $\delta'$ = 微分 ⇒ 不稳定。

## 12. 连续 ↔ 离散

| 连续 | 离散 |
|---|---|
| 积分 / 微分 | 求和 / 差分 |
| $\delta(t)$ 广义函数、$u(0)$ 无定义 | $\delta[n]$ 普通序列、$u[0]=1$ |
| 卷积积分 | 卷积和 |
| 记忆件：积分器 | 记忆件：延迟器 D |
| 特征根在指数 $e^{st}$ | 特征根在底 $r^n$ |
| 重根乘 $t^k$ | 重根乘 $n^k$ |
| 衰减 $\mathrm{Re}\{s\}<0$ | 衰减 $\lvert r\rvert<1$（$r=e^{sT}$） |
| 初值 $y(0^-),y'(0^-)$ | 初值 $y[-1],y[-2]$（防等效初值） |
| 无迭代法 | 有迭代法（$y[n]=\frac{1}{a_0}\{-\sum_{k\ge1}a_ky[n-k]+\sum b_kx[n-k]\}$） |
| 只用积分器 | 只用延迟器 |

## 13. 背景类考点（一句话，考到再展开）

| 点 | 一句话 |
|---|---|
| 回声 / 记忆长度 | $y[n]=\sum_{k=0}^{K}a_kx[n-k]$，$K$ 可达 1024 抽头（≈23 ms≈8 m，音乐厅级混响） |
| CNN | 卷积层是 LTI，做的是**相关**（少一次翻转）；核尺寸取奇数；感受野：两层 $3\times3$ 等效 $5\times5$，乘法 $9+9<25$ |
| 网络顺序 | conv–conv 可合并；conv–ReLU–conv 不行（非线性不可换序） |
| 稳定性直觉 | 摩天大楼抗风 / 阻尼器；单摆稳定、**倒立摆不稳定**；汽车负反馈收敛 $f/\rho$；RNN 梯度爆炸 |
| 反馈实例 | RC 并联（电流源）：$v$ 既是电容输出又是电阻输入，求和点带减号 = 负反馈；开环 = 前向 FFN、闭环 = RNN |
| 为什么 $\delta$ 能代表系统 | 频谱无限宽，等于给每个频率都发测试信号（类比除颤仪宽频电击） |
| 迭代 vs 解析 | 无穷多个数 vs 三个参数；通向 encoder / PCA / 计算数学 |
| 冲击平衡法 | 把 $h$ 代回方程配平 $\delta$、$\delta'$；**不要求掌握**，拉氏反变换更快 |
| 实现 | `lfilter` 用转置 DF II；高阶拆二阶节级联（依据结合律） |
| 广义函数 | $\delta$ 是分布（只在积分下有意义）；形状无关、面积为本 |
