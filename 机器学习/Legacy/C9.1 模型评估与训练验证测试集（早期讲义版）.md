# C9.1 模型评估与训练验证测试集

> [!abstract] 本讲任务
> 你已经会训练回归模型，也知道过拟合可以靠正则化缓解。但新房子的预测仍然很差时，究竟该加数据、加特征，还是调参数？这一讲先解决更基础的问题：**怎样得到一个可信的“模型好不好”的判断**。
>
> 从训练与测试的分工出发，我们会发现“挑模型”本身也会学到数据，进而引出训练、验证、测试三套数据各自的职责。

## 1. 房价预测失败之后，先别急着换算法

你用面积预测房价，训练时拟合得不错，朋友拿来一套没见过的房子，预测却偏得离谱。现在有六条路：收集更多房屋记录；删掉一些特征；寻找新特征；加入 $x_1^2,x_2^2,x_1x_2$ 等多项式特征；减小正则化参数 $\lambda$；增大 $\lambda$。

这些建议甚至互相相反。**加特征与删特征都可能正确，但适用于不同的故障。** 如果随便选一条，可能忙很久才发现根本没对症。

![[C9.1-板书-房价预测的六个改进方向.png]]

我们需要**机器学习诊断 Machine Learning Diagnostic**：运行一个有针对性的检查，判断模型的哪一部分工作得不好，并据此选择改进方向。检查本身要花时间，却能省掉更昂贵的盲试。你刚才从“想一个改法”转向“先确认哪里出了问题”，就是在建立诊断流程。

这一讲先把测量工具做好，[[C9.2 偏差方差诊断与正则化选择（早期讲义版）]] 再解释如何定位故障，[[C9.3 学习曲线与改进方向（早期讲义版）]] 最后回收这六个选项。

## 2. 为什么不能用训练成绩当作最终成绩

### 2.1 穿过已有点，不等于会预测新点

用四次多项式

$$h_\theta(x)=\theta_0+\theta_1x+\theta_2x^2+\theta_3x^3+\theta_4x^4$$

可以让曲线很贴近少量训练点，甚至连训练点之间的偶然起伏也拟合进去。问题是：新房子并不保证沿着这些起伏出现。**泛化 Generalization** 指的就是模型对未参与训练的新样本的预测能力。

一个特征时，我们还能画曲线找异常。若有约一百个特征——面积、卧室数、楼层数、房龄、邻里平均收入、厨房大小等——很难靠看图判断高维曲面是否过拟合。因而需要独立数据上的数值指标。

![[C9.1-板书-过拟合与多特征评估.png]]

> [!question] 停一下，先自己想想
> 如果一个人反复练习同一套题，直到答案全对，能用这套题的成绩证明他会做没见过的题吗？模型把训练误差压低，和这件事有什么相似之处？

相似之处在于**这份数据已经参与了答案的选择**。参数 $\theta_0,\ldots,\theta_4$ 就是为降低这些点上的误差而挑出来的，所以训练误差通常偏乐观。它仍然有价值，可以检查模型有没有学会训练数据，却不能单独估计泛化能力。

![[C9.1-板书-训练误差的乐观偏向.png]]

### 2.2 第一版方案：训练集与测试集

把数据分成两份：**训练集 Training Set** 用来学习参数，**测试集 Test Set** 留着检查未见样本上的表现。一个示例比例是训练 70%、测试 30%。这只是示例，不是必须遵守的定律。

十条房屋记录为：

| 面积 Size | 价格 Price |
|---|---|
| 2104 | 400 |
| 1600 | 330 |
| 2400 | 369 |
| 1416 | 232 |
| 3000 | 540 |
| 1985 | 300 |
| 1534 | 315 |
| 1427 | 199 |
| 1380 | 212 |
| 1494 | 243 |

表中的十条可示意分成七条训练、三条测试。训练样本记为 $(x^{(i)},y^{(i)})$，训练数量记为 $m$；测试样本记为 $(x_{test}^{(i)},y_{test}^{(i)})$，测试数量记为 $m_{test}$。**两个集合的上标 $i$ 分别编号，不表示它们是一一配对的同一个样本。**

![[C9.1-板书-训练与测试的七三划分.png]]

**【拓展】** 对普通独立同分布样本，可以在划分前随机打乱；分类时可按类别分层抽样。同一人的多张照片、同一房子的重复记录不能随意分散到两边，否则会发生**数据泄漏 Data Leakage**。如果任务是用过去预测未来，则应按时间划分，不能把未来随机混进训练集。这里的目标始终是让测试方式接近真正使用模型时的情形。

## 3. 参数冻结以后，怎样算测试误差

### 3.1 线性回归：在测试集上算平方误差

先只用训练集优化 $J(\theta)$，得到 $\hat\theta$。接着保持 $\hat\theta$ 不动，把测试样本逐个送进去：

$$J_{test}(\hat\theta)=\frac{1}{2m_{test}}\sum_{i=1}^{m_{test}}\left(h_{\hat\theta}(x_{test}^{(i)})-y_{test}^{(i)}\right)^2.$$

逐项读：括号里是预测值减真实值；平方避免正负抵消；求和收集所有测试样本；除以 $m_{test}$ 使不同规模的测试集可比较；额外的 $1/2$ 沿用回归代价的记号约定。

![[C9.1-板书-测试平方误差.png]]

> [!example] 手算一次评估
> 假设三个测试样本的残差为 $1,-2,3$，则
> $$J_{test}=\frac{1^2+(-2)^2+3^2}{2\times3}=\frac{14}{6}=\frac73\approx2.3333.$$
> 如果指标名称是均方误差 MSE，则不带 $1/2$，结果是 $14/3\approx4.6667$。比较两个模型时必须使用同一口径。

训练可以有正则化，但这里评估的是**预测误差**，不再把参数惩罚项加进去。为什么这么做，下一讲选择 $\lambda$ 时会进一步说明。

### 3.2 逻辑回归：概率好不好与分类对不对，是两种问题

逻辑回归输出 $p_i=h_{\hat\theta}(x_{test}^{(i)})$，表示正类概率。可以用与训练损失相同类型的**交叉熵 Cross-Entropy** 来评估概率预测：

$$J_{test}(\hat\theta)=-\frac{1}{m_{test}}\sum_{i=1}^{m_{test}}\left[y_{test}^{(i)}\log p_i+(1-y_{test}^{(i)})\log(1-p_i)\right].$$

当真实标签为 1，只剩 $-\log p_i$；当标签为 0，只剩 $-\log(1-p_i)$。所以它奖励给真实类别较大的概率，并强烈惩罚“非常自信地答错”。$\log$ 在这里是自然对数。

> [!warning] 原课件 p8 的公式缺项
> 第二项印成了 $(1-y)\log h_\theta(x)$，正确的是 $(1-y)\log(1-h_\theta(x))$，并应把两项都放进求和的方括号内。否则 $y=0$ 时也会鼓励 $h$ 接近 1，和分类目标矛盾。

如果只问类别是否判断正确，就先选定阈值，例如 $\hat y_i=1$ 当 $p_i\ge0.5$，否则为 0，再计算**误分类率 Misclassification Error**：

$$\operatorname{err}(p,y)=\begin{cases}1,&\mathbf1[p\ge0.5]\ne y,\\0,&\mathbf1[p\ge0.5]=y,\end{cases}\qquad E_{test}=\frac1{m_{test}}\sum_i\operatorname{err}(p_i,y_{test}^{(i)}).$$

这里的 1 表示错一次，0 表示没错；最后取平均，就是错分比例。p8 只列出了该指标名称，没有给出完整表达式，这里按定义补全。

> [!example] 两种指标回答不同问题
> 四个标签为 $(1,0,1,0)$，模型概率为 $(0.8,0.4,0.7,0.1)$。阈值 0.5 下四个全对，所以误分类率为 0；交叉熵为
> $$-\tfrac14[\log0.8+\log0.6+\log0.7+\log0.9]\approx0.2990.$$
> 后者没有变成 0，因为模型并未给真实类别概率 1。若把第一个概率从 0.8 降到 0.51，类别仍然判对，但概率预测的损失会变大。

如果正负类数量严重不平衡，误分类率也可能误导，应接回 [[C6.2 偏斜类的评估：精确率、召回率与 F1]]；评估流程与指标选择是两件都要做好、不能互相替代的事。

## 4. 为什么挑模型还需要第三份数据

### 4.1 测试集上的赢家，也可能是运气好

我们训练十种模型：一次、二次、三次，一直到十次多项式。第 $d$ 个模型的参数记为 $\hat\theta^{(d)}$；这里上标 $d$ 标识**模型编号**，不是某个训练样本。

一个看起来合理的做法是：分别计算十个 $J_{test}(\hat\theta^{(d)})$，选最小的模型，例如五次多项式，然后把它的测试误差当最终成绩。

问题在于，虽然各个 $\theta$ 没有通过测试集梯度来学习，**阶数 $d$ 却通过测试集选了出来**。测试集已经参与决策，赢家容易碰巧适合它的偶然特点。这是另一种过拟合，得到的误差通常是泛化误差的乐观估计。

![[C9.1-板书-用测试集选阶数的问题.png]]

> [!important] 测试集有没有参与训练，要看信息是否影响了选择
> 不仅更新权重算“学习”：选阶数、挑 $\lambda$、挑特征、选阈值、决定哪一轮停止，都可能把评估数据的信息带进最终模型。只要反复根据测试成绩改方案，它就失去了独立的最终检验作用。

### 4.2 训练、验证、测试各守一个岗位

再分出**验证集 Validation Set**。本课也称 **Cross Validation Set**，缩写 CV；这里指一份留出的验证数据，**不等于已经做了 K 折交叉验证**。

一个示例比例是 60% / 20% / 20%：十条记录中六条训练、两条验证、两条测试。数量分别为 $m,m_{cv},m_{test}$。

![[C9.1-板书-训练验证测试三集划分.png]]

三种回归误差采用完全相同的计算口径：

$$\begin{aligned}
J_{train}(\theta)&=\frac1{2m}\sum_i(h_\theta(x^{(i)})-y^{(i)})^2,\\
J_{cv}(\theta)&=\frac1{2m_{cv}}\sum_i(h_\theta(x_{cv}^{(i)})-y_{cv}^{(i)})^2,\\
J_{test}(\theta)&=\frac1{2m_{test}}\sum_i(h_\theta(x_{test}^{(i)})-y_{test}^{(i)})^2.
\end{aligned}$$

同一组参数分别接受三套题目的检查；**计算 CV 或测试误差时不重新拟合参数**。

![[C9.1-板书-三种评估误差.png]]

### 4.3 完整走一遍模型选择

1. 用训练集分别训练 $d=1,\ldots,10$ 的模型，得到 $\hat\theta^{(1)},\ldots,\hat\theta^{(10)}$。
2. 在同一验证集上计算十个误差，选 $d^*=\arg\min_dJ_{cv}(\hat\theta^{(d)})$。
3. 假如选中四次模型，就固定这个选择，再在测试集上报告 $J_{test}(\hat\theta^{(4)})$。

五次与四次分别是前一个错误流程、后一个正确流程里的示意选择，并非通过前面十条房价记录算出的拟合结果。

![[C9.1-板书-验证选模型测试报成绩.png]]

停一下，我们刚才做了什么：不是让某一份数据永远不能看，而是把**学参数、挑方案、报成绩**分开，避免同一份数据同时扮演选拔者和裁判。

**【拓展】** 特征缩放的均值、标准差也应只用训练集拟合，再原样应用到 CV / Test。确定全部方案后，可以另行决定是否合并训练和验证数据重训；那是新的最终模型，仍需用此前未参与选择的测试集评估，不能把重训前后的成绩混为一谈。

## 5. 小结

> [!important] 这一讲的三句话
> 1. 训练误差回答“已有数据学得怎样”，独立数据上的误差才用于检查泛化能力。
> 2. 验证集选择模型与超参数，测试集报告最终表现；在测试集上选赢家会产生乐观偏差。
> 3. 回归平方误差、分类交叉熵与误分类率衡量不同的表现，但都必须遵守数据分工与统一评估口径。

### 速查表

| 问题 | 做法 |
|---|---|
| 学 $\theta$ | 用训练集最小化训练目标，可含正则项 |
| 选 $d,\lambda$ 等 | 比较验证误差 |
| 估计最终泛化表现 | 固定选择后计算测试误差 |
| 回归评估 | $\frac1{2\lvert S\rvert}\sum_{i\in S}(h_i-y_i)^2$，不含正则项 |
| 分类概率评估 | $-\frac1{\lvert S\rvert}\sum_{i\in S}[y_i\log p_i+(1-y_i)\log(1-p_i)]$ |
| 误分类率 | 错分数量 / 样本数量 |
| 示例划分 | 70/30；要选模型时 60/20/20，比例非定律 |

> 现在我们知道误差该在哪里测量了。但验证误差很高，究竟是模型太简单，还是把训练集记得太死？下一讲把训练误差也摆到旁边，从两者的高度和差距作诊断。
