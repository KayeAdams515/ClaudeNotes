# 机器学习课程 MOC

本 vault 收录本课程的逐节讲义笔记。目标是**读完笔记等于听过这节课**：课件上一行结论的地方，笔记里展开成课堂上会讲的那一段。

## 课程信息

> [!important] 成绩构成 Grading
> - 课堂表现 Class performance：**10%**（会不定期点名/查出勤）
> - 平时项目作业 Regular project assignments：**30%**（约两个月后开始编程课，考核**课堂内编程 in-class coding**；另有 1–2 次书面作业）
> - 期末考试 Exam：**60%**（课堂内考试）
>
> 另有**期末项目 Final Project**：给定一份数据和一个问题，用学过的算法求解并提交报告。数据常用**股票数据**（美股／港股／A 股），目标是检验你的策略能否跑赢市场。

> [!note] 参考书 Textbooks
> 1. *Pattern Recognition and Machine Learning*, C. Bishop —— 千页以上，可当字典查，体系最完整
> 2. 《机器学习方法》，周志华，清华大学出版社
> 3. 《统计学习方法》，李航，清华大学出版社
> 4. *Machine Learning*, Tom Mitchell —— CMU 机器学习系首任系主任所著，偏"这个领域是怎么一步步发展来的"的脉络书；本课程决策树部分的记号与例子基本沿用此书

> [!warning] 授课与考试提醒
> - 本学期起要求**英文授课**，多数内容用英文讲，少量用中文补充。
> - **熵 / 条件熵 / 信息增益的手算是明确的考试考点**，每次考试都会考。给一张属性—标签表格，要能算出 $H(Y)$、$H(Y|X)$、$IG(Y|X)$。
> - 课件一般提前约一天发出。
> - 期末考试形式为课堂考试；转写稿中关于是否可带书本／笔记的表述识别不清，以任课教师课堂通知为准。

## 公式速查（第 2 章）

| 名称 | 公式 |
|---|---|
| 线性回归假设 | $h_\theta(x)=\theta^Tx=\theta_0x_0+\theta_1x_1+\cdots+\theta_nx_n$，$x_0=1$ |
| 平方误差代价 | $J(\theta)=\frac{1}{2m}\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})^2$ |
| 梯度下降 | $\theta_j:=\theta_j-\alpha\frac{1}{m}\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}$（同步更新） |
| 正规方程 | $\theta=(X^TX)^{-1}X^Ty$ |
| 均值归一化 | $x_i\leftarrow\frac{x_i-\mu_i}{s_i}$（不对 $x_0$ 做） |
| sigmoid | $g(z)=\frac{1}{1+e^{-z}}$，$g'(z)=g(z)(1-g(z))$ |
| 逻辑回归假设 | $h_\theta(x)=\frac{1}{1+e^{-\theta^Tx}}=P(y=1\mid x;\theta)$ |
| 对数损失 | $J(\theta)=-\frac{1}{m}\sum_i[y^{(i)}\log h_\theta(x^{(i)})+(1-y^{(i)})\log(1-h_\theta(x^{(i)}))]$ |
| 决策边界 | $\theta^Tx=0$ |
