## p53

- 页标题：**网孔电流法的前置概念**（页内标签仍高亮「基本概念」）
- 中文/英文正文要点：
  - ◆ **Why using a mesh is appropriate?** ——为什么用网孔合适？
  - ◆ **Network graph theory:**（网络图论）三条：
    - **1. all the internal meshes of a planar circuit are independent loops** ——平面电路的**全部内部网孔**都是**独立回路**。
    - **2. the number of internal meshes of a planar circuit is exactly (B-N+1).** ——平面电路内部网孔的个数**恰好是** $(B-N+1)$。
    - **3. KCL equation No.: B-N+1.** ——KCL 方程个数也是 $B-N+1$。
  - 图区右下方有两张小图（黑白扫描风）：左图是一个含源电路（标节点 `1 / 2 / 3 / 4`，上方横向 R、中间两条电感接节点 2、左侧竖向 R + 电压源、中间竖向电容、右侧竖向 R），右图是它的**拓扑图**（节点 $n_1,n_2,n_3,n_4$，支路 $b_1\dots b_6$）。
  - 页面中部偏左有一行**醒目的蓝色加粗提问（课堂提问条）**：文本层原文为 **`B=? N=? Equation No.=0?`**；读图时末字符被底部红色页脚条**部分压住**，形状像 `0` 或 `?`，按语义应为 **`Equation No.=?`**（问 B、N、方程数各是多少）
- 公式（LaTeX，逐个写全）：
  - 内部网孔数 $=$ 独立回路数 $=B-N+1$
  - KCL 独立方程数 $=N-1=B-N+1$（课件写的是 `KCL equation No.: B-N+1`，见疑点）
  - 右图：$n_1\sim n_4$ 共 $N=4$ 个节点，$b_1\sim b_6$ 共 $B=6$ 条支路 → $B-N+1=6-4+1=3$
- 电路图：
  - 左图（原电路）：节点 `1 2 3 4`；`1–2` 之间：上方一条电阻（横向）与中间一条电感（横向）并联；`2–3` 之间：一条电感（横向）；`1–4` 之间：电阻 + 电压源（`+` 上 `−` 下）；`2–4` 之间：电容；`3–4` 之间：电阻。**无具体数值**。
  - 右图（拓扑图）：$n_1$ 在左、$n_3$ 在右、$n_2$ 在中上、$n_4$ 在下；$b_1$ 是 $n_1\!-\!n_2\!-\!n_3$ 的上弧，$b_2$ 是 $n_1\!-\!n_2$ 直边，$b_3$ 是 $n_2\!-\!n_3$ 直边，$b_4$ 是 $n_1\!-\!n_4$ 直边，$b_5$ 是 $n_2\!-\!n_4$ 竖边，$b_6$ 是 $n_3\!-\!n_4$ 直边。
  - 左图可以用 mermaid / 手绘复现，右图（拓扑图）能用 mermaid `graph` 或 graphviz 复现。**值得裁切**（前置概念的关键图，尤其拓扑图）。两图是位图（扫描件），裁切比自绘更保真。
- 数值：节点编号 `1 2 3 4`；$n_1,n_2,n_3,n_4$；$b_1\cdots b_6$；符号 $B$、$N$；右下页码 `53`。
- 疑点：
  - **印刷/表述矛盾（重要）**：第 3 条写「KCL equation No.: $B-N+1$」。按电路理论，**独立 KCL 方程数为 $N-1$**（对连通电路），而 $B-N+1$ 是独立**回路（KVL）**方程数。对同一电路两者数值**相等**是因为 $(N-1)+(B-N+1)=B$ 这个恒等式（独立 KCL 数 + 独立 KVL 数 = 支路数），但把 KCL 方程数写成 $B-N+1$ 是**用错式子**——正确写法应是「$N-1=B-N+1$ 个独立 KCL 方程」。这条在讲义里必须纠正并解释为什么数值相同。
  - 第 3 条与第 2 条其实是同一件事的两种说法（网孔数 = 独立回路数 = 独立 KCL 数），课件并排列出容易让人误以为是两个独立结论。
  - 页面下方那行 `B=? N=? Equation No.=?` 是课堂提问（蓝色加粗），PDF 里被底部红色页脚条**部分遮挡**（读图时看到的是 `Equation No.=0?`，文本层才是 `=?`）→ 属**排版遮挡**问题，不是笔误。
  - 左图与右图是同一电路的两个层次（原理图 / 拓扑图），但左图的元件与右图的支路**没有一一对应标注**，需要读者自己数：$B=6$、$N=4$、$B-N+1=3$。

## p68

  - **复算（sympy 符号展开）**：
    - 把控制方程 $i_3=i_1-i_2$ 代入第 2 式：$-R_3i_1+(R_2+R_3)i_2=-r(i_1-i_2)$
      $\Rightarrow -R_3i_1+(R_2+R_3)i_2=-ri_1+ri_2$
      $\Rightarrow (r-R_3)i_1+(R_2+R_3-r)i_2=0$ ✓ **与课件整理结果完全一致，无复算不符。**

  - **复算（sympy）**：$4i_1=16\Rightarrow i_1=4$；$-2\times4+8i_2=0\Rightarrow i_2=1$ ✓；
    $\alpha i_3=\alpha(i_1-i_2)=1\times(4-1)=3\mathrm{A}$ ✓。
    代回原式 $6\times4-2\times1-2\times3=24-2-6=16$ ✓；$-2\times4+6\times1-2\times3=-8+6-6=-8$，右端 $-\mu u_1=-1\times(2\times4)=-8$ ✓。

## p71

- 页标题：**Summary for Mesh current method**（页头黄字，蓝底；本段最后一页，「小结」标签）
- 中文/英文正文要点（5 条，**第 5 条为红色**）：
  1. **1、Set mesh current for each inner mesh（For convinience, set the mesh current directions the same）.** ——为每个**内部网孔**设定网孔电流（**为了方便，网孔电流方向取成一致**）。（原文 `convinience` 拼写有误，应为 `convenience`）
  2. **2、List KVL mesh equation for every inner mesh, $j=1,2,\dots,B-N+1$:** ——对每个内部网孔列 KVL 网孔方程。
  3. **3、Solve the mesh equation above simultaneously to find the mesh current** $I_1,I_2,\dots,I_{B-N+1}$ ——联立求解网孔方程，得到网孔电流。
  4. **4、According to the connection position of each branch, use the mesh current to calculate the required branch current; Determine the branch voltage according to the characteristics of the branch** ——根据各支路的连接位置，用网孔电流计算所需支路电流；再按支路特性（VCR）确定支路电压。
  5. **5、If the unaccompanied current source (无伴电流源) belongs to only one mesh, the mesh does not need to write equations; In fact, the mesh current is selected as the intermediate variable because the inner mesh is a group of observable independent circuits. If an independent circuit can be found, it can break through the limit of the planar circuit - the loop current method (回路电流法，不讲).** ——**若（无伴）电流源只属于某一个网孔，则该网孔不必列方程**；事实上，选网孔电流作中间变量是因为内部网孔就是一组「可观测的独立回路」；**如果能找到（别的）独立回路，就可以突破平面电路的限制——那就是回路电流法（本课不讲）**。
- 公式（LaTeX，逐个写全）：
  - 第 2 条的一般结构（与 p56/p58 完全相同）：
    $$R_{j1}I_1+R_{j2}I_2+\cdots+R_{jj}I_j+\cdots+R_{j(B-N+1)}I_{B-N+1}=U_{jS}$$
  - 第 3 条的解向量：$I_1,I_2,\dots,I_{B-N+1}$
- 电路图：无
- 数值：$j=1,2,\dots,B-N+1$；右下页码 `71`。
- 疑点：
  - **与 p58 的「分析步骤」不一致**：p58 有 5 步且第 1 步是「含源支路做电源等效变换」，p71 的第 1 步直接从「设网孔电流」开始，**把电源变换那一步取消了**，改为在第 5 条专门讲无伴电流源。**两页的 5 条不是同一套流程**，讲义要合并成一条完整流程（建议：设电流 → 处理电源（有伴变换/无伴设 $u$ 或挪外层/受控源设控制方程）→ 列方程 → 求解 → 求支路量）。
  - **第 5 条的表述与 p65 有细微差别**：p65 说的是「无伴电流源**出现在电路外围边界上**时，该网孔电流等于电流源电流」，p71 说的是「无伴电流源**只属于一个网孔**时，该网孔不列方程」。**「在外围边界」与「只属于一个网孔」并不等价**（一个内层的电流源也可能只属于一个网孔）→ 两处条件口径不一致，是本段最后一处需要澄清的地方。
