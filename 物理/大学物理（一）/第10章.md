# 第十章 旋转 [Chapter 10 Rotation]

## 10-1 旋转变量 [The Rotational Variables]

- **刚体 [Rigid bodies]**：在本章中，我们只考虑**刚体 [rigid body]** 绕**固定轴 [fixed axis]** 的旋转。刚体是指在旋转过程中，其所有部分锁定在一起，形状不发生任何改变的物体。旋转发生在一个不改变位置的轴上（即旋转轴）。
    
- 在纯旋转中，物体的**每个点 [every point]** 都以旋转轴上的点为圆心做圆周运动，并且每个点在特定的时间间隔内转过**相同的角度 [same angle]**。
    
    ![[Pasted image 20260408150932.png|432]]
    
- **角位置 [Angular position]**：$\theta = \frac{s}{r}$（$s$ 为圆弧长度，$r$ 为圆的半径）。
    
- $\theta$ 的测量单位是**弧度 [radians, rad]**。角位置是一个**无量纲量 [dimensionless quantity]**（两个长度的比值）。角位置在每次绕旋转轴完整旋转一周后**不会 [not]** 重置为零。
- 对于同一参考线上的点，它们的线速度不同，但是在同一过程中转过的角度是相同的。于是很有必要引入角速度。物理上规定逆时针为正。
    
- 角度换算关系：$\theta = \frac{2\pi r}{r} = 2\pi \text{ radians} = 360^{\circ} = 1 \text{ revolution}$。即 $1 \text{ rev} = 360^{\circ} = 2\pi \text{ rad}$。
    
    ![[Pasted image 20260408151439.png|488]]
    ![[Pasted image 20260408151457.png|244]]

### 角位移、角速度与角加速度 [Angular displacement, velocity and acceleration]

- **角位移 [Angular displacement]**：刚体的每个点都具有相同的角位移。
    
    $$\Delta\theta = \theta_f - \theta_i$$
    
- **逆时针旋转 [Counterclockwise rotation]** 的角位移为**正 [positive]**（$\Delta\theta > 0$）；**顺时针旋转 [Clockwise rotation]** 的角位移为**负 [negative]**（$\Delta\theta < 0$）。
    
    ![[Pasted image 20260408152309.png|444]]
    
- **角速度 [Angular velocity]**：刚体的每个点都具有相同的角速度。
    
- 平均角速度：$\omega_{avg} = \frac{\theta_f - \theta_i}{t_f - t_i} = \frac{\Delta\theta}{\Delta t}$
    
- （瞬时）角速度：$\omega = \lim_{\Delta t \to 0} \frac{\Delta\theta}{\Delta t} = \frac{d\theta}{dt}$
    
- 角速度的常用单位是弧度每秒（$\text{rad/s}$）。**角速率 [angular speed]** 是角速度的大小 $|\omega|$。逆时针旋转的物体角速度为正，顺时针旋转的物体角速度为负。
    
- **角加速度 [Angular acceleration]**：刚体的每个点都具有相同的角加速度。单位为 $\text{rad/s}^2$。
    
- 平均角加速度：$\alpha_{avg} = \frac{\omega_f - \omega_i}{t_f - t_i} = \frac{\Delta\omega}{\Delta t}$
    
- （瞬时）角加速度：$\alpha = \lim_{\Delta t \to 0} \frac{\Delta\omega}{\Delta t} = \frac{d\omega}{dt}$
    
- **角加速度的符号判定 [Sign of angular acceleration]**：当物体加速时，$\alpha$ 与 $\omega$ 符号相同；当物体减速时，$\alpha$ 与 $\omega$ 符号相反。

## 10-3 恒定角加速度的旋转 [Rotation with Constant Angular Acceleration]

当角加速度 $\alpha$ 为常数时，我们可以类比一维直线运动（$a$ 为常数）推导出旋转运动的公式：

- 对应关系：位置 $x \to \theta$，速度 $v \to \omega$，加速度 $a \to \alpha$。
    
- 基本方程 1：$\omega = \omega_0 + \alpha t$
    
- 基本方程 2：$\theta - \theta_0 = \omega_0 t + \frac{1}{2}\alpha t^2$
    
- 导出方程：
    
    $$\omega^2 = \omega_0^2 + 2\alpha(\theta - \theta_0)$$
    
    $$\theta - \theta_0 = \frac{1}{2}(\omega_0 + \omega)t$$
    
    $$\theta - \theta_0 = \omega t - \frac{1}{2}\alpha t^2$$
    

**例题 2**：一个圆盘以恒定的角加速度 $\alpha = 0.35 \text{ rad/s}^2$ 旋转。在 $t = 0$ 时，角速度 $\omega_0 = -4.6 \text{ rad/s}$，参考线的角位置 $\theta_0 = 0$。在 $t = 0$ 之后什么时间，参考线的角位置 $\theta = 5.0 \text{ rev}$？

- **解答**：首先进行单位换算，$\theta = (5.0 \text{ rev})(2\pi \text{ rad/rev}) = 10\pi \text{ rad}$。使用位移公式：
    
    $$\theta - \theta_0 = \omega_0 t + \frac{1}{2}\alpha t^2$$
    
    $$10\pi \text{ rad} - 0 = (-4.6 \text{ rad/s})t + \frac{1}{2}(0.35 \text{ rad/s}^2)t^2$$
    
- 利用求根公式解得：$t = 32s$ 或 $t = -5.6s$（舍去负值）。因此时间为 $32s$。

## 10-4 关联线变量与角变量 [Relating the Linear and Angular Variables]
![[Pasted image 20260410085957.png|345]]
![[Pasted image 20260410090029.png|453]]

旋转物体上的任意一点都在以旋转轴为中心的圆上运动。粒子距离旋转轴**越远 [farther]**，其所在圆的周长**越大 [greater]**，因此其线速率 $v$ 必须**越快 [faster]**。刚体上所有的点都有着相同的角速率。

- **位置与速度 [The position and speed]**：
    
- 圆弧长度：$s = \theta r$（$\theta$ 必须用弧度表示）
    
- **线速度 [Linear speed]**（线速度大小）始终与圆周路径相切：
    $$v=\frac{ds}{dt}=\frac{d\theta}{dt}r=\omega r$$
    $$v = \omega r$$
    
- **旋转周期 [Time of one revolution]**：如果角速率恒定，那么每个点以及刚体旋转一周的周期为：
    
    $$T = \frac{2\pi r}{v} = \frac{2\pi}{\omega}$$
    
- **加速度 [The acceleration]**：旋转物体上一点的线速度大小和方向都可以改变。
    
- **切向加速度 [Tangential component]**：由线速度大小的变化引起，与圆弧路径相切。$\alpha$ 必须用弧度表示。
$$v=\omega r$$
	$$\frac{dv}{dt}=\frac{dw}{dt}r$$
    $$a_t = \alpha r$$
    
- **径向加速度 [Radial component]**（向心加速度）：由线速度方向的变化引起，指向圆心。$\omega$ 必须用弧度表示。
    
    $$a_r = \frac{v^2}{r} = \omega^2 r$$
    ![[Pasted image 20260410090756.png|284]]
    
- **总线加速度大小 [Magnitude of linear acceleration]**：
    
    $$a = \sqrt{a_r^2 + a_t^2}$$
    

**例题 3**：一辆汽车在水平的圆形轨道上从静止开始运动。汽车的速率以 $g$ 的比率增加。当汽车的总线加速度等于 $4g$ 时，它的角位置变化了多少？
![[Pasted image 20260410090836.png|236]]

- **解答**：速率增加的比率即为切向加速度，故 $a_t = g$。
    
    $$a_r = \omega^2 r = (\omega_0^2 + 2\alpha\Delta\theta)r = 2\alpha r \Delta\theta = 2a_t \Delta\theta = 2g\Delta\theta$$
    
- 已知总加速度 $a = \sqrt{a_r^2 + a_t^2} = 4g$，代入得到：
    
    $$4g = \sqrt{(2g\Delta\theta)^2 + g^2} \implies 16 = 4(\Delta\theta)^2 + 1$$
    
- 解得 $\Delta\theta = \frac{\sqrt{15}}{2} \approx 1.94 \text{ rad} = 111^{\circ}$。

## 10-5 旋转动能 [Kinetic Energy of Rotation]

- 对于以相同角速度旋转的 $n$ 个粒子，总动能为各个粒子动能之和。
    
    $$K = \frac{1}{2}(m_1r_1^2 + m_2r_2^2 + \dots + m_nr_n^2)\omega^2 = \frac{1}{2}(\sum_{i=1}^n m_ir_i^2)\omega^2$$
    
- 定义**转动惯量 [Rotational inertia]** 对于一个由许多质点组成的刚体，绕某一固定轴旋转时，转动惯量为： $$I = \sum_{i=1}^n m_ir_i^2$$
- 其中：

- $m_i$​：第 i 个质点的质量
- $r_i$​：该质点到转轴的垂直距离

- 它不仅与质量有关，还与质量如何绕旋转轴分布有关。质量分布离轴越远，转动惯量越大。 它告诉我们旋转物体的质量是如何围绕其旋转轴分布的。对于特定对象的特定旋转轴，它是恒定的。
    
- **旋转动能公式**（$\omega$ 必须用弧度表示）：
$$K=\frac{1}{2}Mv_{com}^2$$
    $$K = \frac{1}{2}I\omega^2$$
    
    ![[Pasted image 20260410091646.png|627]]
    ![[Pasted image 20260410092227.png]]
**物理意义**：
-  **转动惯量越大**，越难改变其转动状态（需要更大的力矩才能获得相同的角加速度）。
    
- 与质量分布密切相关：**质量离转轴越远，转动惯量越大**。例如，同样质量的圆环和圆盘，圆环的质量集中在边缘，其转动惯量大于圆盘。

## 10-6 计算转动惯量 [Calculating the Rotational Inertia]

- **连续质量分布的公式 [Formulas]**：当 $\Delta m_i \to 0$ 时，求和变为积分。
$$dI=d(mr^2)$$
针对m微分，因为m好求
$$dI=r^2dm$$
积分：$$I = \int r^2 dm$$
    
- **常见刚体的转动惯量**：
    
    - 环形圆柱体（或圆环）绕中心轴：$I = \frac{1}{2}M(R_1^2 + R_2^2)$
        
    - 箍（薄圆环）绕中心轴：$I = MR^2$
        
    - 实心圆柱体（或圆盘）绕中心轴：$I = \frac{1}{2}MR^2$
        
    - 实心圆柱体（或圆盘）绕中心直径：$I = \frac{1}{4}MR^2 + \frac{1}{12}ML^2$
        
    - 细杆绕垂直于长度的中心轴：$I = \frac{1}{12}ML^2$
        
    - 平板绕垂直中心轴：$I = \frac{1}{12}M(a^2 + b^2)$
        
    - 实心球绕任意直径：$I = \frac{2}{5}MR^2$
        
    - 薄球壳绕任意直径：$I = \frac{2}{3}MR^2$
        
    - 箍绕任意直径：$I = \frac{1}{2}MR^2$
        
        `[此处有图片：各类常见几何体转动惯量示意图]`
## 推导几何体转动惯量的通用步骤

转动惯量的定义式是 $I = \int r^2 \, dm$，其中 $r$ 是质量微元 $dm$ 到转轴的垂直距离。推导任何几何体的转动惯量，都遵循以下标准流程：

---

### 第一步：确定转轴与坐标系
- 明确转轴的位置和方向（是否过质心？是否对称轴？）
- 根据对称性选择坐标系：
  - 细杆 → 一维直线坐标 $x$
  - 圆盘/圆柱 → 极坐标 $(r,\theta)$ 或柱坐标
  - 球体 → 球坐标 $(r,\theta,\phi)$

---

### 第二步：写出质量微元 $dm$ 的表达式
利用密度将 $dm$ 与几何微元联系起来：
- 线密度 $\lambda = \frac{m}{L}$（均匀细杆） → $dm = \lambda \, dx$
- 面密度 $\sigma = \frac{m}{A}$（均匀薄板） → $dm = \sigma \, dA$
- 体密度 $\rho = \frac{m}{V}$（均匀实心体） → $dm = \rho \, dV$

其中 $dA, dV$ 由坐标系决定：
- 圆环面积微元：$dA = 2\pi r \, dr$
- 圆盘面积微元：同上
- 柱壳体积微元：$dV = 2\pi r L \, dr$
- 球坐标体积微元：$dV = r^2 \sin\theta \, dr\,d\theta\,d\phi$

---

### 第三步：表达距离 $r$（被积函数中的 $r^2$）
找出质量微元到转轴的**垂直距离**，用坐标变量表示。
- 例如：圆盘绕中心轴 → 距离就是极径 $r$（从轴到微元的水平距离）
- 例如：细杆绕中心垂直轴 → 距离就是 $|x|$（坐标绝对值）

---

### 第四步：写出 $dI = r^2 \, dm$ 并化简
将 $dm$ 和 $r^2$ 代入，得到只含一个积分变量的表达式（对称性会使某些角度变量提前积出常数）。

---

### 第五步：确定积分限并积分
- 积分变量遍历整个物体
- 利用对称性简化计算（如偶倍奇零）

---

### 第六步：代入总质量 $m$ 化简结果
将密度用总质量和几何尺寸表示，消去密度，得到只含 $m$ 和长度/半径的简洁公式。

---

## 示例：均匀细杆绕一端垂直轴

| 步骤  | 操作                                                          |
| --- | ----------------------------------------------------------- |
| 1   | 转轴过端点，垂直于杆。取 $x$ 轴沿杆，原点在端点，范围 $[0,L]$。                      |
| 2   | 线密度 $\lambda = m/L$，$dm = \lambda \, dx$                    |
| 3   | 微元到转轴的距离 $r = x$                                            |
| 4   | $dI = x^2 \cdot \lambda \, dx$                              |
| 5   | $I = \int_0^L \lambda x^2 dx = \lambda \cdot \frac{L^3}{3}$ |
| 6   | 代入 $\lambda = m/L$，得 $I = \frac{1}{3} m L^2$                |

---

## 总结流程图

$$
\boxed{\text{转轴与坐标}} \xrightarrow{\text{确定}} \boxed{dm = \rho \cdot (\text{几何微元})} \xrightarrow{\text{表达}} \boxed{dI = r^2 dm}
$$
$$
\downarrow
$$
$$
\boxed{I = \int dI} \xrightarrow{\text{化简}} \boxed{I = \text{常数} \times m \times (\text{特征长度})^2}
$$

只要按这六步走，任何规则形状的转动惯量都可以推导出来。
        
- **平行轴定理 [Parallel-axis theorem]**：绕平行于过质心轴的任意轴的转动惯量 $I$，等于过质心轴的转动惯量 $I_{com}$ 加上物体质量 $M$ 与两轴之间垂直距离 $h$ 平方的乘积。
    
    $$I = I_{com} + Mh^2$$
    
    ![[Pasted image 20260410095935.png]]
    

**例题 4**：求一根细杆绕通过**左端点 [left end]** 并垂直于杆的旋转轴的转动惯量。

- **解答**：使用平行轴定理，$h = L/2$。
    
    $$I = I_{com} + Mh^2 = \frac{1}{12}ML^2 + M(\frac{L}{2})^2 = \frac{1}{3}ML^2$$
    
- 也可以使用转动惯量的定义积分求解，设线密度 $\lambda = M/L$，则 $dm = (M/L)dx$：
    
    $$I = \int_0^L x^2 (\frac{M}{L}dx) = \frac{M}{L}[\frac{x^3}{3}]_0^L = \frac{1}{3}ML^2$$

## 10-7 力矩 [Torque]

- **旋转的能力 [Ability to rotate]**：力使物体旋转的能力不仅取决于其切向分量的大小，还取决于力施加点离旋转中心 $O$ 的距离。
    
- **力矩 [Torque, $\tau$]** 衡量了力使物体旋转的能力。逆时针旋转的力矩为**正 [positive]**，顺时针为**负 [negative]**。
    
    $$\tau = rF_t = rF\sin\phi$$
    
- 力的**作用线 [Line of action]** 是穿过力矢量的延长线。**力臂 [moment arm, $r_{\perp} $]** 是旋转轴到力作用线之间的垂直距离。所以力矩也可以写为 $\tau = r_{\perp}F$。
    
- **矢量定义 [Definition]**：力矩是一个**矢量 [vector quantity]**。
    
    $$\vec{\tau} = \vec{r} \times \vec{F}$$
    
- 力矩的**方向 [Direction]** 根据**右手定则 [right-hand rule]** 确定，垂直于 $\vec{r}$ 和 $\vec{F}$ 构成的平面。
    
    ![[Pasted image 20260415140113.png]]
    

![[Pasted image 20260415140724.png]]
**例题 5**：已知 $F_1 = F_2 = F_3 = 2.0 N$，$\theta = 30^{\circ}$，$r = 3.0 m$。分别求每个力绕原点 O 产生的力矩。
![[Pasted image 20260415141049.png]]
![[Pasted image 20260415141059.png]]
- **解答**：
    
    - $\vec{\tau}_1 = rF_1\sin(150^{\circ}) \text{ (方向向里)} = -3.0 N\cdot m \hat{j}$
        
    - $\vec{\tau}_2 = rF_2\sin(120^{\circ}) \text{ (方向向外)} = 5.2 N\cdot m \hat{j}$
        
    - $\vec{\tau}_3 = rF_3\sin(90^{\circ}) \text{ (垂直于r)} = 6.0 N\cdot m$。由于粒子在 xz 平面内，方向为 $\vec{r} \times \vec{F}_3 = 3.0 N\cdot m \hat{i} - 5.2 N\cdot m \hat{k}$。

## 10-8 旋转的牛顿第二定律 [Newton's Second Law for Rotation]

- **公式 [Formula]**：类比纯平动 $\vec{F}_{net} = M\vec{a}_{com}$，纯旋转的牛顿第二定律为：
    
    $$\tau_{net} = I\alpha$$
    
- （注意：$\alpha$ 必须用弧度表示）力矩是产生角加速度的原因。
    
- **推导 [Derivation]**：对于单个粒子，$F_t = ma_t$。力矩 $\tau = F_t r = (ma_t)r = m(\alpha r)r = mr^2\alpha = I\alpha$。对于由多个粒子组成的刚体，通过求和可得净力矩等于转动惯量乘以角加速度。
平动加速度由合外力决定，此时视为整个系统的外力都画在一个点上，如果合外力为0，质心不平动，但是可能转动，这时候再根据力矩来求转动加速度。
    

**例题 6**：圆盘质量 $M = 2.5 kg$，半径 $R = 20 cm$。求下落物块（质量 $m = 1.2 kg$）的加速度、圆盘的角加速度以及绳子中的张力。

- **解答**：
    
    - 对物块应用牛顿第二定律：$T - mg = ma \implies -T + mg = -ma$（设向下为负）
        
    - 对圆盘应用旋转牛顿第二定律：$\tau_{net} = I\alpha \implies -TR = (\frac{1}{2}MR^2)\alpha$
        
    - 由于绳子不打滑，线加速度与角加速度关系为 $a = \alpha R$。联立解得：
        
        $$a = -\frac{2m}{2m + M}g = -4.8 \text{ m/s}^2$$
        
        $$\alpha = \frac{a}{R} = -24 \text{ rad/s}^2$$
        
        $$T = \frac{1}{2}M|a| = 6.0 N$$
        

**例题 7**：圆盘以初始角速度 $\omega_0$ 在桌面上旋转，圆盘与桌面间的摩擦系数为 $\mu$。求圆盘因摩擦而完全停止所需的时间。

- **解答**：取一个圆环质量元 $dm = \sigma dA = \sigma (2\pi r dr)$。作用在其上的微元摩擦力矩 $d\tau = r \cdot df = r \cdot \mu g dm$。
    
- 圆盘上的总力矩：
    
    $$\tau = \int d\tau = \int_0^R r \cdot \mu g \cdot \sigma \cdot 2\pi r dr = \frac{2}{3}\mu mgR$$
    
- 应用旋转的牛顿第二定律 $\tau = I\frac{d\omega}{dt}$：
    
    $$-\frac{2}{3}\mu mgR = (\frac{1}{2}mR^2)\frac{d\omega}{dt}$$
    
- 分离变量并积分 $\int_0^t dt = -\frac{3R}{4\mu g} \int_{\omega_0}^0 d\omega$，解得时间 $t = \frac{3R}{4\mu g}\omega_0$。

## 10-9 功与旋转动能 [Work and Rotational Kinetic Energy]

- **功-动能定理 [Work-kinetic energy theorem]**：类比一维平动的 $W = \Delta K = \frac{1}{2}mv_f^2 - \frac{1}{2}mv_i^2$，绕固定轴纯旋转的功-动能定理为：
    
    $$W = \Delta K = \frac{1}{2}I\omega_f^2 - \frac{1}{2}I\omega_i^2$$
    
- **做功与功率**：
    
    - 旋转做功积分公式：$W = \int_{\theta_i}^{\theta_f} \tau d\theta$
        
    - 恒定力矩做功：$W = \tau(\theta_f - \theta_i)$
        
    - 功率（做功的速率）：$P = \frac{dW}{dt} = \tau \omega$
        
- **功-动能定理推导**：$dW = F_t ds = F_t r d\theta = \tau d\theta$。积分后即可得到 $W = \int \tau d\theta$。这适用于由多个粒子组装而成的任何刚体。

**例题 8**：承接例题 6。圆盘 $M = 2.5 kg$，$R = 20 cm$。角加速度 $\alpha = -24 \text{ rad/s}^2$，绳子张力 $T = 6.0N$。如果圆盘从 $t = 0$ 处静止开始，它在 $t = 2.5 s$ 时的旋转动能是多少？

- **解答**：
    
    - 方法一（直接算）：$\omega = \omega_0 + \alpha t = 0 + \alpha t$。$K = \frac{1}{2}I\omega^2 = \frac{1}{2}(\frac{1}{2}MR^2)(\alpha t)^2 = 90 J$。
        
    - 方法二（功-动能定理）：$K_f = W + K_i = W + 0$。由于力矩恒定 $\tau = -TR$，$W = \tau(\theta_f - \theta_i) = -TR(\frac{1}{2}\alpha t^2) = 90 J$。
        

**例题 9**：用质量 $m$ 和半径 $R$ 表示图中物体的转动惯量是多少？（一根细杆加一个圆环）

- **解答**：总转动惯量 $I = I_{hoop} + I_{rod}$。
    
    - $I_{hoop} = \frac{1}{2}mR^2$（关于平面内的任意直径）
        
    - 对于杆，使用平行轴定理：$I_{rod} = I_{com} + mh^2 = \frac{1}{12}m(2R)^2 + m(2R)^2 = \frac{13}{3}mR^2$
        
    - 故 $I = \frac{1}{2}mR^2 + \frac{13}{3}mR^2 = \frac{29}{6}mR^2$。
        

**例题 10**：从静止开始，物体（上方细杆连下方圆环）绕旋转轴从初始**直立 [upright]** 方向转动。当它变为**倒立 [inverted]** 状态时，它绕旋转轴的**角速率 [angular speed]** $\omega$ 是多少？

- **解答**：对于物体-地球系统，机械能守恒，$0 = \Delta K + \Delta U$。
    
    - 动能变化：$\Delta K = \frac{1}{2}I\omega^2 - 0 = \frac{1}{2}(\frac{29}{6}mR^2)\omega^2$
        
    - 势能变化分析质心高度。初始质心高度 $y_{com, i} = \frac{m(R+L/2)}{2m} = R$；倒立时质心高度 $y_{com, f} = -R$。
        
    - $\Delta U = (2m)g \Delta y_{com} = (2m)g(-2R)$
        
    - 代入守恒方程：$0 = \frac{29}{12}mR^2\omega^2 - 4mgR \implies \omega = \sqrt{\frac{48g}{29R}}$。代入 $R=0.15m$，解得 $\omega = 10 \text{ rad/s}$。
