## 一、顺序存储的地址公式

课件的存储示意（物理地址 ↔ 元素）：

| Physical Address 物理地址 | Elements 元素 |
| --- | --- |
| $L_0$ | $e_1$ |
| $L_0+m$ | $e_2$ |
| …… | …… |
| $L_0+(i-1)m$ | $e_i$ |
| …… | …… |
| $L_0+(n-1)m$ | $e_n$ |

> [!important] 地址公式
> $$Loc(e_i) = L_0 + (i-1)\times m$$
> 其中 $L_0$ 是首元素地址，$m$ 是**单个元素占用的存储单元数**，$i$ 是序号（**从 1 开始**）。

> [!warning] 与第 1 章公式的差异（必须分清）
> [[C1.4 物理结构与存储分配]] 写的是 $Loc(i)=L_0+i\times u$（下标**从 0** 起）；这里写 $L_0+(i-1)m$（序号**从 1** 起）。**两式等价，只是起点约定不同。**
> 考试给出的往往是"第 $i$ 个元素"，请先确认题目中第一个元素的编号是 0 还是 1，代错公式会整题错。

> [!note] 公式带来的唯一优点，也是全部优点
> 只要一次乘法加一次加法就能定位任意元素 —— **随机存取 (random access)，$O(1)$**。顺序表的所有优势都由这一条派生；它的所有劣势（插入删除要搬移）也都由"必须保持连续"这个前提付出。

## 二、类定义

```cpp
template <typename T>
class SqList
{
public:
    SqList(int);          //initialization
    ~SqList();            //destroy
    bool empty();         //whether empty
    T get(int);           //retrieve one element
    int getLength();      //get the length
    int getCapacity();    //get the capacity
    int find(T);          //find one element
    bool insert(T, int);  //insert one element
    void erase(int);      //delete one element
private:
    T* elem;              //array head address
    int capacity;         //capacity of the SqList
    int length;           //length of the SqList
};
```

> [!important] 三个私有成员的分工
> - `elem`：指向动态数组首地址（就是公式里的 $L_0$）
> - `capacity`：**最多能装几个**
> - `length`：**当前装了几个**
>
> `length ≤ capacity` 是这个类的**不变式 (invariant)**，所有函数都必须维持它。

## 三、初始化与简单函数

```cpp
template <typename T>
SqList::SqList(int capacity)
{
    this->capacity = capacity;                    //set the capacity
    this->elem = new T[capacity];                 //allocate memory
    if (!this->elem) exit(OVERFLOW);              //if failed, exit
    this->length = 0;                             //set length to 0
}
```

> [!note] 三行代码里的三个考点
> 1. **容量由构造函数参数决定** —— 顺序表必须"先说要多大"，这就是 [[C2.2 案例：字母表·花名册·多项式]] 里说的 "Allocation is rigid"。
> 2. **检查分配是否失败**（`if (!this->elem) exit(OVERFLOW)`）—— 这是 [[C1.5 算法与渐进分析]] 四项指标里的**健壮性 Robustness** 的落实。（现代 C++ 中 `new` 失败会抛 `std::bad_alloc` 而非返回 NULL，此处是 C 风格写法。）
> 3. **`length = 0` 而不是 capacity** —— 新表是空的，容量只是"预定的座位数"。

```cpp
// Destroy 销毁
SqList::~SqList() {
    if (this->elem)
        delete[] this->elem;
}

// Clear 清空
void SqList::clear() {
    this->length = 0;
}

// Is empty? 判空
bool SqList::empty() {
    return this->length == 0;
}

// Get length 求长度
int SqList::getLength() {
    return this->length;
}
```

> [!warning] 三个细节
> - 析构里先判 `if (this->elem)` 是防止重复释放；且必须用 **`delete[]`** 而非 `delete`（见 [[C1.0 课程信息与C++预备]]）。
> - `clear()` **只把长度归零，不释放内存**，容量保持不变，旧数据仍在内存里。
> - `empty()`、`getLength()` 都是 $O(1)$，因为 length 被显式维护着。

## 四、Retrieve：按下标取元素

```cpp
template <typename T>
T SqList::get(int index) {
    //check the feasibility of the index
    if (index < 0 || index >= this->length) {
        exit(ERROR);     //define this by yourself
    }
    return this->elem[index];
}
```

> [!important] 复杂度：$O(1)$
> 直接按公式定位，与 $n$ 无关。这是顺序表相对链表的**核心优势**。

> [!warning] 边界条件为什么是 `index >= length` 而不是 `>= capacity`
> 因为下标 `length` 到 `capacity-1` 的格子虽然**已分配但没装数据**，读出来是垃圾值。
> **合法下标区间是 $[0,\ length-1]$。** 这一条在 insert 里会变成另一副样子（见下），是本节最容易错的地方。

## 五、Find：顺序查找

**成功的例子**（在 `25 34 57 16 48 09` 中找 16，i 从 0 逐个右移，第 4 次命中）：

![[C2-顺序查找-成功.png]]

**失败的例子**（在 `25 34 57 16 48` 中找 50，走到末尾仍未找到，返回 fail）：

![[C2-顺序查找-失败.png]]

```cpp
template <typename T>
int SqList::find(T x) {
    for (int i = 0; i < this->length; i++) {
        if (this->elem[i] == x) {
            return i;
        }
    }
    return -1;
}
```

> [!important] 课件的提问 "Time Complexity？？？" 的答案
> - **最好情况**：第一个就命中，比较 1 次，$O(1)$。
> - **最坏情况**：最后一个才命中，或根本不存在，比较 $n$ 次，$O(n)$。
> - **平均情况**（假设查找每个位置的概率相等且一定能找到）：
> $$\text{平均比较次数}=\frac{1}{n}\sum_{i=1}^{n} i = \frac{1}{n}\cdot\frac{n(n+1)}{2}=\frac{n+1}{2}$$
> - 因此 **$O(n)$**。

> [!note] 为什么用 $O$ 而不用 $\Theta$
> 因为循环里有 `return`（提前退出），下界不确定 —— 这正是 [[C1.6 代码复杂度的计算方法]] 里说的"带 break/return 的循环只能给上界 $O$"。而查最大值那种必须走完全程的才是 $\Theta(n)$。
>
> **约定**：找不到时返回 **-1**（因为合法下标非负，-1 是天然的"无效值"哨兵）。

## 六、Insert：在第 $i$ 个元素之前插入

![[C2-顺序表插入-图示.png]]

课件的演示：数组 `25 12 47 89 36 14`（length=6，capacity=9），要在下标 3（值 89）之前插入 99。做法是**从后往前**把 14、36、89 依次右移一格，腾出下标 3，再放入 99。

> [!important] 移动次数（课件原文）
> - Insert before the **4th** element，move **6 - 3** times（在第 4 个元素前插入，移动 3 次）
> - Insert before the **$i$-th** element，move **$n - i$** times

```cpp
template <typename T>
bool SqList::insert(T x, int index) {
    if (index < 0 || index > this->length)      //index is illegal
        return false;
    if (this->length == this->capacity)         //full
        return false;
    for (int i = this->length; i > index; i--) {   //move elements
        this->elem[i] = this->elem[i - 1];
    }
    this->elem[index] = x;                      //insert the element
    this->length++;                             //increase 1
    return true;
}
```

> [!warning] 四个必考细节
> 1. **合法性判断是 `index > length` 而不是 `>=`** —— 因为允许在**末尾之后**插入（即 `index == length` 表示追加到尾部）。这与 `get()` 的 `index >= length` 恰好差一，是"差一错误 (off-by-one)"的经典考点。
> 2. **必须从后往前搬**（`i` 从 `length` 递减）。如果从前往后写 `elem[i+1]=elem[i]`，会一路把同一个值复制满整个数组——**这是初学者第一号 bug**。
> 3. **判满用 `length == capacity`**。课件的实现是直接 `return false`（不扩容）；工业实现（如 `vector`）会在这里触发扩容，即 [[C1.6 代码复杂度的计算方法]] 里那段 `update_capacity`，代价 $\Theta(n)$。
> 4. **别忘 `length++`**。

> [!important] 平均移动次数 AMN（Average Moving Number）
> 插入位置有 $n+1$ 种可能（可以插在 $n$ 个元素之前，也可以插在末尾之后），每种等概率：
> $$\mathrm{AMN}=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{1}{n+1}(n+\dots+1+0)=\frac{1}{n+1}\cdot\frac{n(n+1)}{2}=\frac{n}{2}$$

> [!note] 这个求和逐项拆开（课件跳过的一步）
> 当 $i=1$（插在最前）要移 $n$ 个；$i=2$ 移 $n-1$ 个；…；$i=n$ 移 1 个；$i=n+1$（插在末尾之后）移 **0** 个。
> 所以求和就是 $n+(n-1)+\dots+1+0=\dfrac{n(n+1)}{2}$，除以 $n+1$ 种情形得 $\dfrac n2$。
> **分母是 $n+1$ 不是 $n$** —— 因为末尾追加也是一种合法位置。删除时分母就变成 $n$（见下），这一对差别是最爱考的点。
>
> 课件的红字总结：
> - Insert element at the **tail**, no move is needed (**fast**)
> - Insert element at the **head or middle**, move a lot (**slow**)
> - So, for **average**? → $n/2$

## 七、Erase：删除第 $i$ 个元素

![[C2-顺序表删除-图示.png]]

课件的演示：删除下标 3 的元素 89，把后面的 36、14 依次**左移**一格，length 减 1。

> [!important] 移动次数（课件原文）
> - Erase the **3rd** element，move **6 - 3 - 1** times（删第 3 个元素，移动 2 次）
> - Erase the **$i$-th** element，move **$n - i - 1$** times

```cpp
template <typename T>
void SqList::erase(int index) {
    if (index < 0 || index >= this->length)     //index is illegal
        exit(ERROR);
    for (int i = index + 1; i < length; i++) {
        this->elem[i - 1] = this->elem[i];      //move elements
    }
    this->length--;                             //decrease 1
}
```

> [!warning] 与 insert 的三处镜像差异
> | | Insert | Erase |
> | --- | --- | --- |
> | 合法下标 | `index > length` 非法（可等于 length） | `index >= length` 非法 |
> | 搬移方向 | **从后往前**，元素**右移** | **从前往后**，元素**左移** |
> | 长度变化 | `length++` | `length--` |
> | 失败处理 | `return false` | `exit(ERROR)`（课件写法不一致，实际应统一） |

> [!important] 平均移动次数
> 删除位置有 $n$ 种可能（只能删已存在的元素），每种等概率：
> $$\mathrm{AMN}=\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{1}{n}\cdot\frac{(n-1)n}{2}=\frac{n-1}{2}$$

> [!note] 为什么删除的分母是 $n$、插入是 $n+1$
> - 插入：位置可以是"第 1 个之前、第 2 个之前、…、第 n 个之前、最后一个之后"，共 **$n+1$** 个空隙。
> - 删除：只能删除**已存在的** $n$ 个元素之一，共 **$n$** 种。
>
> 结果分别是 $\dfrac n2$ 和 $\dfrac{n-1}{2}$，都是 $\Theta(n)$，但**别把两个公式记混**——这是本章最经典的填空题。
>
> 求和验算：$\sum_{i=1}^{n}(n-i)=(n-1)+(n-2)+\dots+1+0=\dfrac{(n-1)n}{2}$。

课件的红字总结：
- Erase element at the **tail**, no move is needed (**fast**)
- Erase element at the **head**, move a lot (**slow**)
- So for **average**? → $(n-1)/2$

## 八、复杂度结论

> [!important] 课件原句
> Clearly, Sequential List **'find', 'insert', and 'erase' have time complexity $O(n)$ and space complexity $O(1)$**.

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| get / retrieve（按下标） | $O(1)$ | 地址公式直接算 |
| find（按值） | $O(n)$ | 平均比较 $(n+1)/2$ 次 |
| insert | $O(n)$ | 平均移动 $n/2$ 次 |
| erase | $O(n)$ | 平均移动 $(n-1)/2$ 次 |
| 空间（辅助） | $O(1)$ | 只用了几个临时变量 |

> [!warning] "空间复杂度 $O(1)$"指的是什么
> 指的是**除了存放数据本身之外**的额外空间（只有 `i` 这类循环变量）。存数据的 $n$ 个格子不计入，这是"辅助空间 (auxiliary space)"的标准约定。
> 同理 [[C1.6 代码复杂度的计算方法]] 里说堆排序空间 $\Theta(1)$、归并排序 $\Theta(n)$，比的也是辅助空间。

## 九、顺序表的优缺点

> [!important] Merit 优点
> - **High Storage Density 存储密度高** —— no extra storage is needed to represent the linear relationship（不需要额外空间来表示线性关系，因为关系由"位置相邻"隐含表达）
> - **Random access 随机存取**（arbitrary access）

> [!important] Defect 缺点
> - **'Insert' and 'erase' need to move elements.**（增删要搬移元素）
> - **Extra space is needed for future insertion.**（要为将来的插入预留空间）
> - **Static storage, hard to expand.**（静态存储，难以扩展）

> [!note] 存储密度的定义（课件没给，但会考）
> $$\text{存储密度} = \frac{\text{数据本身占用的空间}}{\text{结点实际占用的总空间}}$$
> 顺序表 = **1**（100%，全是数据）；单链表 = $\dfrac{\text{sizeof(T)}}{\text{sizeof(T)}+\text{sizeof(ptr)}}$。
> 例：存 `int`（4 字节）在 64 位系统上，指针 8 字节，链表存储密度只有 $4/12\approx33\%$ —— **链表为了表达"关系"付出了 2/3 的空间**。这就是 [[C2.7 两种实现的比较]] 表里"Storage Density: High, only data"的含义。

## 本节自测 Self-Test

> [!question] Q1：$Loc(e_i)=L_0+(i-1)m$ 中的 $m$ 是什么？公式说明顺序表的什么特性？
> **A**：单个元素的大小；说明顺序表支持 $O(1)$ 随机存取。

> [!question] Q2：insert 的合法下标范围是什么？为什么和 get 不同？
> **A**：$[0, length]$；因为允许在末尾之后追加，而 get 只能取已有元素，范围是 $[0, length-1]$。

> [!question] Q3：插入时为什么必须从后往前搬移？从前往后会怎样？
> **A**：从前往后会用前一个元素覆盖后一个，最终把同一个值复制满整段。

> [!question] Q4：插入与删除的平均移动次数分别是多少？为什么分母不同？
> **A**：插入 $n/2$（$n+1$ 个可插位置），删除 $(n-1)/2$（只有 $n$ 个可删元素）。

> [!question] Q5：在长度为 6 的表中，在第 4 个元素前插入要移动几次？删除第 3 个元素要移动几次？
> **A**：插入移动 $6-3=3$ 次；删除移动 $6-3-1=2$ 次。

> [!question] Q6：顺序表的存储密度是多少？和链表比如何？
> **A**：顺序表为 1（100%）；链表因需存指针而小于 1，存 int 时约 1/3。

> [!question] Q7：`clear()` 之后 `capacity` 变了吗？数据还在内存里吗？
> **A**：capacity 不变；数据仍留在内存中，只是 length=0 使其不可访问。
