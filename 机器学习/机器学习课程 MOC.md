## 公式速查（第 2 章）

| 名称 | 公式 |
|---|---|
| 线性回归假设 | $h_\theta(x)=\theta^Tx=\theta_0x_0+\theta_1x_1+\cdots+\theta_nx_n$，$x_0=1$ |
| 平方误差代价 | $J(\theta)=\frac{1}{2m}\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})^2$ |
| 梯度下降 | $\theta_j:=\theta_j-\alpha\frac{1}{m}\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}$（同步更新） |
| 正规方程 | $\theta=(X^TX)^{-1}X^Ty$ |
| 均值归一化 | $x_i\leftarrow\frac{x_i-\mu_i}{s_i}$（不对 $x_0$ 做） |
| sigmoid | $g(z)=\frac{1}{1+e^{-z}}$，$g'(z)=g(z)(1-g(z))$ |
| 逻辑回归假设 | $h_\theta(x)=\frac{1}{1+e^{-\theta^Tx}}=P(y=1\mid x;\theta)$ |
| 对数损失 | $J(\theta)=-\frac{1}{m}\sum_i[y^{(i)}\log h_\theta(x^{(i)})+(1-y^{(i)})\log(1-h_\theta(x^{(i)}))]$ |
| 决策边界 | $\theta^Tx=0$ |
| 优化器接口 | 给定 $\theta$，返回 $J(\theta)$ 与 $\frac{\partial}{\partial\theta_j}J(\theta)$；算法有 GD / CG / BFGS / L-BFGS |
| One-vs-all | 训练 $h^{(i)}_\theta(x)=P(y=i\mid x;\theta)$，预测 $\hat y=\arg\max_i h^{(i)}_\theta(x)$ |
| 正则化线性回归 | $J(\theta)=\frac{1}{2m}[\sum_i(h_\theta(x^{(i)})-y^{(i)})^2+\lambda\sum_{j=1}^n\theta_j^2]$ |
| 正则化逻辑回归 | 对数损失 $+\frac{\lambda}{2m}\sum_{j=1}^n\theta_j^2$ |
| 正则化更新式（$j\ge1$） | $\theta_j:=\theta_j(1-\alpha\frac{\lambda}{m})-\alpha\frac{1}{m}\sum_i(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}$ |
| 正则化正规方程 | $\theta=(X^TX+\lambda\,\mathrm{diag}(0,1,1,\ldots,1))^{-1}X^Ty$ |

## 公式速查（第 3 章）

| 名称 | 公式 |
|---|---|
| 公理 | $0\le P(A)\le1$；$P(\text{True})=1$；$P(\text{False})=0$；$P(A\vee B)=P(A)+P(B)-P(A\wedge B)$ |
| 补事件 | $P(A)+P(\sim A)=1$ |
| 边缘化 | $P(A)=P(A\wedge B)+P(A\wedge\sim B)$ |
| 条件概率 | $P(A\mid B)=\frac{P(A\wedge B)}{P(B)}$ |
| 链式法则 | $P(A\wedge B)=P(A\mid B)P(B)=P(B\mid A)P(A)$ |
| 贝叶斯定理 | $P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}$ |
| 展开分母 | $P(B)=P(B\mid A)P(A)+P(B\mid\sim A)P(\sim A)$ |
| 独立 | $P(A\mid B)=P(A)\iff P(A\wedge B)=P(A)P(B)$ |
| 条件独立 | $P(A\wedge B\mid C)=P(A\mid C)P(B\mid C)$ |
| 联合分布查询 | $P(E)=\sum_{\text{符合}E\text{的行}}P(\text{row})$ |
| 联合分布推断 | $P(E_1\mid E_2)=\frac{\sum_{\text{符合}E_1\wedge E_2}}{\sum_{\text{符合}E_2}}$ |
| 期望 | $E[X]=\sum_x xP(X=x)$；$E[f(X)]=\sum_x f(x)P(X=x)$ |
| 方差 | $\mathrm{Var}(X)=E[(X-E[X])^2]=E[X^2]-E[X]^2$ |
| 标准差 | $\sigma_X=\sqrt{\mathrm{Var}(X)}$ |
| 协方差 | $\mathrm{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])]=E[XY]-E[X]E[Y]$；$\mathrm{Cov}(X,X)=\mathrm{Var}(X)$ |
| 相关系数 | $\rho_{XY}=\frac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1]$；$|\rho|=1\iff Y=aX+b$ |
| 重要反例 | $X\sim U\{-1,0,1\}$，$Y=X^2$：$\rho=0$ 但不独立 |
