### 电路分析方法（第3章）
| 方法/定理 | 公式 | 要点 |
|---|---|---|
| 直流稳态 | C 视为开路、L 视为短路 | 仅稳态成立；暂态失效（第5章） |
| 串联/并联 | $R_{eq}=\sum R_k$；$G_{eq}=\sum G_k$ | 分压用 R、分流用 G |
| 源变换 | $u_S = R\, i_S$ | 电阻随源搬家；**等效只对外** |
| 入端等效电阻 | $R_{eq}=U/I$ | 无**独立**源（受控源保留，可为负） |
| 一步法求等效电源参数 | 外加 $U$ 求 $I$：$U=U_{OC}+R_0I$ | **含受控源时首选** |
| 测量法 | $R_0=\dfrac{U_1-U_2}{I_2-I_1}$ | 内部未知时的工程做法 |
| 通用支路方程 | $u=u_S+R(i-i_S)$ | $R=0$ 无伴压源；$R=\infty$ 无伴流源 |
| Y→Δ / Δ→Y | $R_\Delta=3R_Y$（对称）；$G_\Delta=\dfrac{Y\text{相邻乘积}}{\sum G_Y}$ | 桥式网络解桥 |
| 全电路方程 | B·VCR + (N−1)·KCL + (B−N+1)·KVL | 2B 个方程，理论完备 |
| 支路电流法 | 变量 $=B$ 个支路电流：$(N-1)$ 个 KCL $+(B-N+1)$ 个 KVL | 第 5 步**用功率守恒自检** |
| **网孔电流法** | $R_{jj}I_j+\sum_{n\ne j}R_{jn}I_n=U_{jS}$ | **仅平面电路**；自电阻正、互电阻负；**KCL 自动满足**；含受控源时 $R_{jk}\ne R_{kj}$ |
| 网孔法电源项口诀 | 电源 $+\to-$ 与网孔电流同向 → **取负**，反向 → **取正** | 前提：所有网孔电流**同向** |
| 无伴电流源（内层/最外层） | 内层**设 $u$ + 补电流源方程**；最外层**该网孔电流 = 电流源电流** | 判据是「只属于一个网孔」 |
| 结点电压法 | $G_{jj}U_j+\sum_{n\ne j}G_{jn}U_n=I_{jS}$ | 自电导正、互电导负、右端流入电流；**KVL 自动满足**；适用任意电路 |
| 叠加定理 | $U=\sum a_nU_{Sn}+\sum r_mI_{Sm}$ | **功率不满足叠加** |
| 替代定理 | 已知 $u_0,i_0$ → 同值电压源/电流源 | 线/非线性均可 |
| 戴维南/诺顿 | $u=U_{OC}-R_0i$；$U_{OC}=R_0I_{SC}$ | 参数三法：二步/一步/测量 |
| 最大功率传输 | $R_L=R_0$，$P_{max}=\dfrac{U_{OC}^2}{4R_0}$ | 效率仅 50%；匹配时 $U_L=U_{OC}/2$（自检） |

## 复习路线建议

**第一遍（理解主线）**：C1.1 → C1.2 → C1.5
把"为什么可以用路的方法"和"路的两条铁律"打通，这是全课程的骨架。

**第二遍（建立工具箱）**：C1.4 → C1.3
先熟悉理想元件的伏安关系，再理解两种线性化方法。

**第三遍（器件建模）**：C2.1 → C2.2 → C2.3
按"实物 → 非理想因素 → 集总模型"的固定套路对照着看，三节结构完全平行。

**第四遍（电路分析方法）**：C3.1 → C3.2 → C3.3 → C3.4
C3.1 是地图；C3.2（等效）适合"只问一条支路"；C3.3 是系统解法主力——**按"全电路方程 → 支路电流法 → 网孔电流法 → 结点电压法"的顺序读**，前一个是后一个的动机：支路电流法暴露了"独立回路难找"，网孔法把找回路变成数格子（代价是只能用于平面电路），结点法再把这个限制也去掉。C3.4（叠加/替代/戴维南/最大功率）是考试高频。**第 4 章会把整套方法原样搬到相量域**，第 3 章务必扎实。

> [!note] 关于 C3.3 的篇幅
> C3.3 现在是全课程最长的一篇（对应新版课件 53 页、正文约 1400 行），因为它一个人装下了**四个系统方法**。读起来觉得重的话，可以按上面的顺序**分四次读**，每次读一个方法加上它的例题。

**第五遍（交流稳态）**：C4.1 → C4.2 → C4.3
一条线走下来：**造工具（正弦量→相量）→ 换元件（R/L/C→阻抗）→ 搬方法（第 3 章全套）**。C4.1 的第 6 节（相量怎么被逼出来）和 C4.2 的第 2 节（求导 = 乘 $\mathrm j\omega$）是全章的技术心脏，两处都不能跳。

**第六遍（交流稳态的工程落点）**：C4.4 → C4.6
C4.4 是"算出来的相量怎么变成钱"（$P$/$Q$/$S$、补偿电容、最大功率传输），C4.6 是"频率从常数变成自变量"（网络函数、谐振、通频带）。两篇都是考试与应用的双高频，而且 C4.4 的补偿电容相量图与 C4.6 的并联谐振**是同一个物理**。

**第七遍（非正弦）**：C4.5
放在 C4.4/C4.6 之后读更顺：它用到的"逐频率分别算"依赖 C4.3 的方法，用到的"功率逐次谐波相加"依赖 C4.4 的正交概念，最后又直接引出 C4.6 的谐振。

**易混淆点清单：**
- 参考方向 vs 真实方向；相关 vs 非相关参考方向 → [[C1.2 电路的基本概念]]- 分段线性化（大信号）vs 微分线性化（小信号）→ [[C1.3 电路模型]]
- 独立源 vs 受控源（叠加定理中只置零独立源）→ [[C1.4 理想电路元件]]
- 电压源怕短路 vs 电流源怕开路 → [[C1.4 理想电路元件]]
- 集总 vs 分布（判据是电长度）→ [[C2.1 元件互连与传输线模型]]
- **BJT 饱和区 vs FET 饱和区（含义相反！）** → [[C2.3 双端口器件的电路模型]]
- **等效 vs 替代**（等效对任意外电路成立；替代只在当前电路的工作点成立）→ [[C3.4 线性电路定理]]
- **电压/电流可叠加，功率不可叠加**（二次量有交叉项）→ [[C3.4 线性电路定理]]
- 有伴 vs 无伴电压源（结点法处理方式完全不同）→ [[C3.3 电阻网络的系统分析]]
- $i_D$（总量）/ $I_D$（直流）/ $i_d$（交流）三种下标写法 → [[C1.3 电路模型]]
- **网孔电流法 vs 结点电压法**：前者列 KVL、KCL 自动满足、**只能用于平面电路**；后者列 KCL、KVL 自动满足、**任意电路都行**。两者都适用时**谁方程少用谁**（$B-N+1$ vs $N-1$）→ [[C3.3 电阻网络的系统分析]] §3.18
- **平面电路 ≠ 三维空间不交叉**（判据是"能不能画在一张平面上而不交叉"，芯片层叠结构就是非平面）→ [[C3.3 电阻网络的系统分析]] §3.2
- **网孔 ⊂ 回路**：网孔一定是回路，回路不一定是网孔（"你圈的那一圈不是网孔" ≠ "没有网孔"）→ [[C3.3 电阻网络的系统分析]] §3.3
- **无伴电流源的两种处境**：在内层要"设 $u$"、在最外层直接等于网孔电流；判据其实是"**只属于一个网孔**"→ [[C3.3 电阻网络的系统分析]] §3.14
- **含受控源后"自参数为正、互参数对称"全部失效**（网孔法 $R_{jk}\ne R_{kj}$、结点法 $G_{jk}\ne G_{kj}$；自电阻/自电导可能为负）→ [[C3.3 电阻网络的系统分析]] §3.16
- **"二端网络"（one-port，一对端钮）vs "二端口网络"（two-port，两对端钮）**——课件里的 `two-port` 是"二端"的直译，别与第 4 章的两端口混淆 → [[C3.2 电阻网络等效化简]] §9.2
- **幅值相量 vs 有效值相量**（差 $\sqrt2$ 倍，全程只能选一种）→ [[C4.1 正弦量与相量]]
- **$\sin$ 参考 vs $\cos$ 参考**（换约定会让所有相位整体转 $90^\circ$）→ [[C4.1 正弦量与相量]]
- **感抗/容抗 $X$ 都是正数，$-j$ 的符号归阻抗管** → [[C4.2 元件相量模型与阻抗导纳]]
- **判"感性/容性"要用阻抗角 $\varphi_z$**，用导纳角会得到相反结论 → [[C4.2 元件相量模型与阻抗导纳]]
- **复功率必须取电流共轭**（不共轭，角度会从"差"变成"和"）→ [[C4.4 正弦稳态功率与功率因数]]
- **两个 $Q$**：无功功率（var）vs 品质因数（无量纲）→ [[C4.4 正弦稳态功率与功率因数]]、[[C4.6 网络函数与谐振]]
- **$S$ 不守恒**（$S_\Sigma=\sqrt{P_\Sigma^2+Q_\Sigma^2}\ne\sum S_k$）→ [[C4.4 正弦稳态功率与功率因数]]
- **两个 $P_{\max}$**：容量上限 $UI$ vs 共轭匹配 $U_S^2/(4R_S)$ → [[C4.4 正弦稳态功率与功率因数]]
- **最大功率传输 ≠ 高效率**（共轭匹配效率仅 50%，电力系统绝不追求匹配）→ [[C4.4 正弦稳态功率与功率因数]]
- **有效值用平方和、平均功率用直接和**（一个靠勾股、一个靠正交性）→ [[C4.5 非正弦周期电路的谐波分析]]
- **不同频率的相量不能相加**（只能在时域叠加）→ [[C4.5 非正弦周期电路的谐波分析]]
- **$U_L$、$U_C$ 的峰值不在谐振频率处**（$U_{Lm}=U_{Cm}=\frac{QU}{\sqrt{1-1/(4Q^2)}}>QU$）→ [[C4.6 网络函数与谐振]]
- **串联放大电压、并联放大电流**；$Q_\text{串}$ 里是 $L/C$、$Q_\text{并}$ 里是 $C/L$ → [[C4.6 网络函数与谐振]]
