## 先固定约定

| 项目 | 双向链表 DLList<T> | 循环链表 Ring |
| --- | --- | --- |
| 是否带头结点 | 不带 | 不带 |
| 空表 | head、tail 为空，length 为 0 | 同左 |
| 非空链接 | head->prior 为空，tail->next 为空 | tail->next == head |
| 单结点 | prior、next 都为空 | next 指向自己 |
| 位置或编号 | 插删下标从 0 开始 | 结点保存调用者传入的数据，没有强制编号规则 |
| 非法操作 | insert 返回 false；erase 直接 return | 空表 popFront 返回 false；rotate 的步数非正时不动 |
| 所有权 | 类释放自己的结点，不允许复制整个容器 | 同左 |

本模块不实现 get，观察器返回 const 结点指针，允许测试观察但不能修改结点。两个方向的链接必须相互吻合。按下标找到结点允许 O(n)，拿到结点之后的接链、断链是 O(1)。头尾插入均要求 O(1)。

## D2：插入

合法下标是 [0,length]。分别考虑空表、头插、尾插、中间插；空表通常合并到头插分支。尾插使用 tail，不再从头遍历。

先画 a <-> b，再画插入新结点 s 后的 a <-> s <-> b。需要更新的不只是 next，还有 prior。先让新结点保存左右邻居，再让邻居改口。

测试同时从头向后、从尾向前检查，不能只让正向看起来正确。本关还检查清空后复用、析构是否真正释放结点。计数元素是测试辅助，不需要你修改或学习其实现。

## D3：删除

文件：`dllist.h`，TODO 7。命令：`make test-3`。

合法下标是 [0,length-1]。先找到待删结点，更新左右邻居；缺少左邻居就是删头，缺少右邻居就是删尾。删唯一结点时两端都归空。接好之后再 delete，长度只减一次。

测试包括非法删除、头中尾删除、删光再插入，以及 200 次混合操作，每一步都检查双向链接和顺序。按下标定位本身可能 O(n)，不要把“已知结点的断链 O(1)”误写成整个 erase(index) 一定 O(1)。

## C1：循环链表（选做，本轮跳过）

按课堂重点，本轮不要求实现 `ring.h`；已有文件和测试保留作选做，不计入默认通关。只需理解：非空环的 `tail->next == head`，遍历不能靠遇到空指针结束。

以下为保留的选做说明：文件 `ring.h`，TODO 1–4，命令 `make test-4` 或 `make test-ring`。

基础构造、析构和观察接口已经给出，你实现：

- pushBack(x)：尾插，O(1)，空表新结点指向自己。
- popFront()：删除当前头，O(1)，空表返回 false，唯一结点单独处理。
- rotate(steps)：头尾一起向后走，不创建结点，不修改 next，不交换数据。比如 1→2→3，前进一格后从头看到 2→3→1。空表或 steps<=0 不动；大步数可对长度取模。
- clear()：释放整个环。可以反复 popFront，也可以先断环再逐个释放。

这关沿用你刚练过的循环结构，不重复约瑟夫题。不要直接用 while(p != nullptr) 遍历未断开的环。
