## 1. 逐页结论

## p72
- 页标题：Node voltage method（结点电压分析法）
- 该页讲了什么：结点电压作为**中间变量**（"intermediate variables（中间变量）"标红）；元件的对外特性把电压与电流联系起来，因此可以用支路电压表示支路电流；每条支路都接在两个确定的结点之间，所以任一支路电压都可表示为结点电位之差；于是取结点电压为基本变量列方程，称为结点电压法。下方流程图：`Set the reference node → Node voltage（all other node's voltage to the referenced node）→ Branch voltage → Branch current`。
- 旧笔记里有没有？→ **有**（C3.3 §3.1）
- 差异：内容一一对应；v2 把「中间变量」提升为红字关键词（旧笔记在 §2.1 讲了"中间变量"，§3.1 未重复）。英文把「每个元件的特性 VCR 将支路电压和电流联系起来」简写成 "external characteristic links its voltage to its current"，语义等价。
- 疑点：无。

## p73
- 页标题：Node voltage method（结点电压分析法）
- 该页讲了什么：设 d 为参考结点；列三个独立结点 KCL：$\text{a}:I_{ad}+I_{ab}+I_{ac}=0$、$\text{b}:I_{db}+I_{ab}-I_{bc}=0$、$\text{c}:I_{ac}+I_{bc}+I_{dc}=0$；再用支路特性方程与 KVL 把电流写成结点电压。
- 旧笔记里有没有？→ **有**（C3.3 §3.3 第一、二步）
- v2 原文（6 个 VCR 式，逐字）：
  $$I_{ad}=\frac{U_a-U_{S1}-0}{R_1}\quad I_{ab}=\frac{U_a-U_b}{R_6}\quad I_{ac}=\frac{U_a-U_c-U_{S2}}{R_2}$$
  $$I_{bc}=\frac{U_b-U_c}{R_4}\quad I_{db}=\frac{0-U_b-U_{S3}}{R_3}\quad I_{dc}=\frac{0-U_c-U_{S5}}{R_5}$$
  差异：v2 把旧版的 $I_{db}=(-U_b-U_{S3})/R_3$、$I_{dc}=(-U_c-U_{S5})/R_5$ 写成显含参考点电位 0 的形式，与旧版数学等价。
- 疑点：**v2 新增视觉标注**——结点 a、d、b、c 均用**红色虚线圈**圈出（旧 p52 无任何圈注，已渲染核对）。这是 v2 为强调"哪些点是结点、哪个是参考点"新加的，属于"新版有、旧笔记对应的旧图没有"的视觉信息。

## p110
- 页标题：Maximum power transmission theorem（最大功率传输定理）
- 该页讲了什么：推导。负载从网络获得的功率 $P=UI=\dfrac{R_L}{(R_0+R_L)^2}\cdot U_S^2$；当 $R_0$ 确定时 $P$ 与 $R_L$ 呈**二次函数关系**，存在极值：
  $$\frac{\mathrm dP}{\mathrm dR_L}=U_S^2\left[\frac{(R_0+R_L)^2-2(R_0+R_L)R_L}{(R_0+R_L)^4}\right]=U_S^2\frac{R_0-R_L}{(R_0+R_L)^3}=0$$
  得唯一极值点 $R_L=R_0$；并验证是极大点
  $$\left.\frac{\mathrm d^2P}{\mathrm dR_L^2}\right|_{R_L=R_0}=-\frac{U_S^2}{8R_0^3}<0,\qquad P_{\max}=\frac14\cdot\frac{U_S^2}{R_0}$$
- 旧笔记里有没有？→ **有**（C3.4 §4.2，含 dP/dR_L 与二阶导验证，逐式一致）
- 复算（sympy）：$\mathrm dP/\mathrm dR_L=U_S^2(R_0-R_L)/(R_0+R_L)^3$ ✓；二阶导 $=-U_S^2/(8R_0^3)$ ✓；$P_{\max}=U_S^2/(4R_0)$ ✓。
- 疑点：无。

import numpy as np, sympy as sp
# p79 E.G1
G=np.array([[1.2,-1,0,-0.1],[-1,2.5,-0.5,0],[0,-0.5,1.25,-0.25],[-0.1,0,-0.25,0.6]])

u=np.linalg.solve([[2,-4,2],[-1,3,-1],[1,-.5,-.5]],[6,0,0])  # [4. 3. 5.] -> p=5*2*3=30
# p106 二步法
UOC=2*(5/9*9)-4*(4/9*9); R0=3*6/9; I=(UOC-10)/(R0+2)       # -6, 2, -4
# p113 最大功率（独立结点法，3 未知量 V1=顶轨, Vm=中结点, Va=a）
A=np.array([[.2,-.1,0],[-.1,.2,-.1],[0,-.1,.3]]); b=np.array([1,2,17])
Va=np.linalg.solve(A,b)[2]                                    # 80.0  (U_OC)
Va2=np.linalg.solve(A,[0,0,1])[2]                             # 4.285714 = 30/7 (R0)
Pmax=Va**2/(4*30/7)                                           # 373.33 W
# p110 符号验证
RL,R0s,US=sp.symbols('R_L R_0 U_S',positive=True)
P=RL/(R0s+RL)**2*US**2
sp.factor(sp.diff(P,RL))                                      # US^2*(R0-RL)/(R0+RL)^3
sp.simplify(sp.diff(P,RL,2).subs(RL,R0s))                     # -US^2/(8*R0^3)
sp.simplify(P.subs(RL,R0s))                                   # US^2/(4*R0)
