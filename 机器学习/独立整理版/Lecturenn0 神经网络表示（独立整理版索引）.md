# Lecturenn0 神经网络表示（独立整理版索引）

这一组讲义围绕一个问题展开：**怎样把简单的逻辑单元连起来，形成能够使用新特征的模型？** 上篇先解释为什么需要它、基本单元怎样计算；下篇亲手计算网络，并用XNOR检验表达能力。

切分点位于“单元模型已建立、尚未组合为网络”处。生物学背景完整保留在上篇辅助阅读区；主线中的数值例与推导紧贴各自要解决的问题。

## 优先掌握的知识

| 必须会做的事 | 判断依据或公式 | 在哪里讲透 |
| --- | --- | --- |
| 分清非线性输出与非线性边界 | 单调sigmoid按0.5阈值分类，等价于加权和不小于0 | 上篇第二节 |
| 数出二次特征，而非把重复乘积也算进去 | $n+\binom n2=n(n+1)/2$，只计恰好二次部分 | 上篇第二节 |
| 计算一个逻辑单元 | $z=\theta_0+\sum_k\theta_kx_k$，$a=g(z)$；偏置值固定、偏置权重可学 | 上篇第三节 |
| 看网络结构就能写对矩阵尺寸 | $\Theta^{(j)}\in\mathbb R^{s_{j+1}\times(s_j+1)}$，$s_j$ 不含偏置 | 下篇第二节 |
| 独立完成一遍前向传播 | 加权和 → 逐元素激活 → 非输出层补偏置 | 下篇第三节 |
| 解释隐藏层为何有用 | XNOR原始四点线性不可分，隐藏特征使目标可由一条直线区分 | 下篇第四至六节 |
| 解释多输出与标签 | 当前四类约定下 $y$ 为四维独热向量，预测为四个连续激活 | 下篇第七节 |

三层网络的参数记号、偏置与前向传播，是进入Lecturenn1学习部分的前提。不要把“给定权重能算出结果”当作已经解决“怎样学习权重”。
