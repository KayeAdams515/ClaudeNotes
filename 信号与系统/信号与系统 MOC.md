### 卷积（Ch.2）

| 名称 | 连续 | 离散 |
|---|---|---|
| 信号分解 | $x(t)=\int x(\tau)\delta(t-\tau)d\tau$ | $x[n]=\sum_kx[k]\delta[n-k]$ |
| 卷积 | $y(t)=\int x(\tau)h(t-\tau)d\tau$ | $y[n]=\sum_kx[k]h[n-k]$ |
| 方波自卷积 | 三角：底宽 $2T$、峰值 $T$ | 三角：底宽 $2N-1$、峰值 $N$ |

| 面积/总和 | $\int y=\int x\cdot\int h$ | $\sum y=\sum x\cdot\sum h$ |

### 常用卷积结果

| 卷积 | 结果 |
|---|---|
| $u[n]*a^nu[n]$ | $\dfrac{1-a^{n+1}}{1-a}u[n]$ |
| $\alpha^nu[n]*\beta^nu[n]$ | $\dfrac{\beta^{n+1}-\alpha^{n+1}}{\beta-\alpha}u[n]$；$\alpha=\beta$ 时 $(n+1)\alpha^nu[n]$ |
| $e^{-at}u(t)*u(t)$ | $\dfrac{1-e^{-at}}{a}u(t)$ |
| $x*\delta(t-t_0)$ | $x(t-t_0)$ |
| $x*\delta'(t)$ | $x'(t)$ |
| $x*u(t)$ | $\int_{-\infty}^tx(\tau)d\tau$ |

### 傅里叶级数（Ch.3）

| 项目 | 连续 CTFS | 离散 DTFS |
|---|---|---|
| 基频 | $\omega_0=2\pi/T$ | $\omega_0=2\pi/N$ |
| 综合 | $x(t)=\sum_{k=-\infty}^{\infty}a_ke^{jk\omega_0t}$ | $x[n]=\sum_{k=\langle N\rangle}a_ke^{jk\omega_0n}$ |
| 分析 | $a_k=\frac1T\int_Tx(t)e^{-jk\omega_0t}dt$ | $a_k=\frac1N\sum_{n=\langle N\rangle}x[n]e^{-jk\omega_0n}$ |
| 系数周期性 | 无 | $a_{k+N}=a_k$ |
| 方波 | $\frac{2T_1}{T}\mathrm{Sa}(k\omega_0T_1)$ | $\frac1N\frac{\sin[2\pi k(N_1+1/2)/N]}{\sin(\pi k/N)}$，$k=0$ 时 $\frac{2N_1+1}N$ |
| 正交性 | $\int_Te^{jk\omega_0t}e^{-jl\omega_0t}dt=T\delta_{kl}$（内积用负共轭） | $\sum_{n=\langle N\rangle}e^{jk\omega_0n}e^{-jr\omega_0n}=N\delta_{kr}$ |
| 直流 / 均值 | $a_0=\frac1T\int_Tx(t)dt$ | $a_0=\frac1N\sum_{n=\langle N\rangle}x[n]$ |
| 主瓣边界（方波） | $\mathrm{Sa}$ 第一个零点 $k\omega_0T_1=\pi$ ⇔ $\omega=\pi/T_1$（只由脉宽决定） | 同（离散端用 $\sin/\sin$，峰在 $k=0$） |
| 冲激串 | $\sum\delta(t-kT)\leftrightarrow\frac1T$ | — |

### 第 11 节课的课堂结论（课件上没有、靠语音稿补入）

| 结论 | 内容 |
|---|---|
| **为什么能当基底** | 复内积用**负共轭**、在一个整周期上积分 ⇒ 谐波集两两正交 ⇒ 可以张成一个空间；基底有**无穷多个**，所以是**无穷维的希尔伯特空间**，不是欧氏空间 |
| **$a_k$ 的物理含义** | $a_k$ 是信号在第 $k$ 根基（频率 $k\omega_0$）上的**坐标 / 权重**；$a_k$ 越大，说明这个频率的成分越强 |
| **推导里被强调的两步** | 乘 $e^{-jl\omega_0t}$ 之后可以**乘进求和号里**（分配律）；再把**积分与求和交换顺序**（积分是线性的） |
| **积分区间怎么挑** | $\int_T$ 是任意一个整周期，**挑好算的那段**：对称区间 $[-\frac{T_0}2,\frac{T_0}2]$ 与对称方波最配，而且非零段只有 $[-T_1,T_1]$，区间可以一路缩短 |
| **Sa 的主瓣与旁瓣** | $\mathrm{Sa}(x)=\frac{\sin x}x$：零点在 $x=k\pi$，$x=0$ 取 1（洛必达）；$[-\pi,\pi]$ 是**主瓣**，往外是**旁瓣** |
| **主瓣宽度只由脉宽定** | 第一个零点 $k\omega_0T_1=\pi$ ⇔ $\omega=\frac{\pi}{T_1}$：固定 $T_0$ 时脉冲越窄主瓣越宽（里面谱线条数变多）；固定 $T_1$ 时周期越长谱线越密而主瓣纹丝不动 |
| **一张图还是两张图** | $a_k$ 一般是复数，实信号的谱也可能是复数谱 ⇒ 常规要画**幅度谱 + 相位谱**；只有"实且偶"这类信号才一张图搞定 |
| **DTFS 为什么只有 $N$ 维** | 离散端 $e^{j2\pi n}=1$，$k$ 与 $k+N$ 落在单位圆**同一点**；连续端 $e^{j2\pi t/T}$ 随 $t$ 一直在变、永不恒等于 1，所以连续的每个 $k$ 都是新频率 |
| **对偶记法** | 积分换求和、$\frac1T$ 换 $\frac1N$；分析式基函数的负号来自**负共轭**；真正本质的区别是 $k$ 的范围（无穷维 vs $N$ 维） |
| **考核提示（课堂原话）** | CTFS 第一个公式要记住；周期方波"占空比 × Sa"要背；归一化 $\mathrm{sinc}$ 不要求背 |

### 第 8–10 节课的课堂结论（课件上没有、靠语音稿补入）

| 结论 | 内容 |
|---|---|
| **微分不变性** | $x^{(n)}(t)*h(t)=x(t)*h^{(n)}(t)=y^{(n)}(t)$；离散对应一阶差分。求导是"换到导数空间去解题" |
| **积分不变性** | $x^{(-1)}*h=x*h^{(-1)}=y^{(-1)}$；离散对应累加和（running sum） |
| **无记忆 LTI** | $h=k\delta$ ⇒ $y=kx$；等价地"冲激是卷积单位元" $x*\delta=x$ |
| **BIBO 充要** | 连续 $\int\lvert h\rvert<\infty$，离散 $\sum\lvert h\rvert<\infty$。充分性用三角不等式放大；必要性用 $x[n]=\mathrm{sgn}(h[-n])$ 反证 |
| **阶跃响应** | $s=h*u$，$h=s'$（离散 $h[n]=s[n]-s[n-1]$）。工程上测 $s$ 容易、测 $h$ 难，所以"测 $s$ 再求导" |
| **特解撞特征根** | 与齐次解同形时必须乘一个因子：连续乘 $t$、离散乘 $n$（否则系数会被合并掉、$c$ 解不出来） |
| **离散等效初始条件** | 通解只对 $n\ge0$ 成立；题给的 $y[0],y[1]$ 往往已含输入作用，真正的初状态是输入作用前的 $y[-1],y[-2]$，须用方程推到正时间再用 |
| **增量线性** | 非零初状态会让系统只在"增量"意义下线性（$y=2x+3$ 不是 LTI）；零输入响应就是那个"增量" |
| **$\delta'$ 相乘性质** | $x(t)\delta'(t)=x(0)\delta'(t)-x'(0)\delta(t)$（卷积类 $x*\delta'=x'$ 不要与它混） |
| **方框图存储量** | Direct Form I：$N+M$ 个延迟器；Direct Form II：$\max(N,M)$ 个（靠交换律共用延迟链）；连续时间一律用积分器，不用微分器 |
| **特征函数** | $e^{st}\to H(s)e^{st}$，$z^n\to H(z)z^n$；$h$ 能代表系统的理由：冲激含全频段、各频率被等权激发，一次就把 $H$ 全测出来 |
| **离散频率的周期** | $H(e^{j\omega})$ 以 $2\pi$ 为周期；最高频是 $\omega=\pi$（即 $(-1)^n$）；`fft` 给 $[0,2\pi)$，`fftshift` 给 $[-\pi,\pi)$ |

### DFT 与频谱分析（实验二）

**三个长度各管什么**（这三行混用是实验里最常见的错误）：

| 名字 | 符号 | 由谁定 | 决定 |
|---|---|---|---|
| 数据长度 | $M$ | 实际取了多少样本 | 真分辨率 $\Delta\Omega\approx2\pi/M$（或 $\Delta f\approx1/T_p$） |
| FFT 点数 | $N$ | `fft(x,N)` | 栅栏间隔 $2\pi/N$；补零只改这一行 |
| 记录时长 | $T_p=M T_s$ | 时间轴长度 | $\Delta f=1/T_p$ |

**五条换算**：

| 关系 | 式子 | 说明 |
|---|---|---|
| DFT ↔ DTFS 系数 | $X[m]=N a_m$ | `fft` 给总和，$a_k$ 是平均，要除 $N$ |
| 幅值换算 | $X(j\omega)\approx T_s X[m]$ | 求和变积分，乘 $T_s$；忘乘就差 $f_s$ 倍 |
| 频率换算 | $\omega_m=2\pi m/(NT_s)$ | 归一化频率 $\Omega=2\pi m/N$ 除以 $T_s$ |
| 采样定理 | $f_s>2f_m$，$\omega_s>2\omega_m$ | 等号不安全，工程取 $2.5\sim5$ 倍 |
| 频域取样定理 | $N\ge M$ | 否则时域环绕混叠 |

**窗的两个指标**（主瓣以 $2\pi/N$ 计）：

| 窗 | 主瓣 | 峰值旁瓣 |
|---|---|---|
| 矩形 | 2 | $-13.3$ dB |
| 三角 / 汉宁 | 4 | $-26.5$ / $-31.5$ dB |
| 哈明 | 4.2 | $-42.7$ dB |
| 布莱克曼 | 6 | $-58.1$ dB |
| 凯塞 | 随 $\beta$ 变 | $\beta$ 越大越低（$-14.7$ 至 $-82$ dB 已实测） |

**分辨率判据**：能分开的最小间隔 $\Delta f_{\min}\approx\dfrac{2\sim4}{T_p}$（矩形约 $2/T_p$，哈明/凯塞约 $4/T_p$）；**补零不改变这个数**。

## 面向 AI 的重点 Learning Focus for AI

> [!important] 必须吃透 Master These
> 离散卷积 Discrete Convolution｜DFT/FFT｜采样定理与抗混叠 Sampling Theorem (anti-aliasing)｜LTI 系统

> [!tip] 理解为主 Conceptual Grasp
> Z 变换 Z-Transform｜拉普拉斯变换 Laplace Transform（重直觉，跳过繁重手算）

> [!tip] 第 2 章与 AI 的具体接口
> - **卷积长度公式** $L_y=L_x+L_h-1$ = `np.convolve(..., 'full')` 的输出长度，也是 CNN 输出尺寸/padding 计算的来源；
> - **矩形 * 矩形 = 三角、反复卷积趋于钟形** = 多次滑动平均 ≈ 高斯模糊，堆叠小卷积核的等效感受野；
> - **级联可换序只对 LTI 成立** = conv-conv 可合并、conv-ReLU-conv 不可——激活函数存在的理由；
> - **直接形式 II** = `scipy.signal.lfilter` 的内部结构（转置直接 II 型），`sos` 二阶节级联依据结合律；
> - **BIBO 稳定 ⇔ $\sum\lvert h\rvert<\infty$** = IIR 滤波器设计的第一道门槛。

> [!tip] 第 3 章与 AI 的具体接口
> - **DTFS = DFT / FFT**：`np.fft.fft(x)/N` 就是 $a_k$；`fftshift` 把 $[0,2\pi)$ 挪到 $[-\pi,\pi)$，画频谱前必做；
> - **$b_k=a_kH$ = 卷积定理**：大卷积核用 FFT 算更快（`scipy.signal.fftconvolve`）；
> - **帕塞瓦尔**：能量 / 功率在时域和频域守恒，是频域损失函数、谱分析能量占比的依据；
> - **吉布斯现象**：频域硬截断带来振铃（JPEG、MRI 伪影），加窗 / 平滑截断是对策；
> - **微分 = 高通**：图像梯度、边缘检测算子（Sobel 等）都在放大高频。

> [!tip] 第 5 章与 AI 的具体接口
> - **DTFT 是 FFT 那条曲线的极限**：`np.fft.fft(x)/N` 给出的是 $X(e^{j\omega})$ 在 $\frac{2\pi}{N}k$ 各点的采样，点数变多只是把同一条曲线画细；
> - **$\lvert H(e^{j\omega})\rvert$ 就是滤波器的"形状"**：`scipy.signal.freqz` 画的就是它，IIR 设计的首要门槛是极点必须留在单位圆内；
> - **相乘性质 = 加窗与 STFT**：给信号乘窗就是在频域做周期卷积，频谱泄漏与主瓣宽度都从这条性质来；
> - **$(-1)^n$ 反转频谱**：实现上就是"隔一个变一次号"，把低通变高通；
> - **帕塞瓦尔**：谱能量占比（语音端点检测、频带能量特征）的依据。

> [!tip] 实验（MATLAB）与 AI 的具体接口
> - **点运算的方向正好相反**：MATLAB 里"逐元素"要加点（`.*`），NumPy 里"矩阵乘"才要特殊记号（`@`）。从 MATLAB 往 Python 搬代码时 **`.*`→`*`、`*`→`@` 各改一次**，漏一个都是静默错误（尺寸合法时不报错，只是算出来是另一回事）。
> - **`conv` 与 `np.convolve(...,'full')` 长度完全一致**（$N+M-1$），而且**都不返回时间轴**——这正是 CNN 里"输出尺寸 = 输入 + 核 − 1"（`valid` 卷积）那条公式的来源。
> - **`xcorr` = `np.correlate(...,'full')`，而 CNN 的卷积层做的其实是相关**（核不翻转）：第 2 章讲过的"CNN = 相关"在实验台上就是这两行代码的区别。
> - **`sinc` 在 MATLAB 与 NumPy 里定义完全相同**（$\sin\pi x/\pi x$），与教材的 $\mathrm{Sa}$ 差一个 $\pi$——跨语言搬运在这一处不会出错，出错永远在"教材公式 ↔ 代码"那一跳。
> - **"造不出严格的 $\delta(t)$、只能造成面积 1 的窄脉冲"** = 数值计算里"用有限精度网格近似广义函数"的第一课；后面做频域采样、谱估计时同一件事会再出现一次。
