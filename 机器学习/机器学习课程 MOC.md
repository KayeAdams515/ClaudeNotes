# 机器学习课程 MOC

本 vault 收录本课程的逐节讲义笔记。目标是**读完笔记等于听过这节课**：课件上一行结论的地方，笔记里展开成课堂上会讲的那一段。

## 课程信息

> [!important] 成绩构成 Grading
> - 课堂表现 Class performance：**10%**（会不定期点名/查出勤）
> - 平时项目作业 Regular project assignments：**30%**（约两个月后开始编程课，考核**课堂内编程 in-class coding**；另有 1–2 次书面作业）
> - 期末考试 Exam：**60%**（课堂内考试）
>
> 另有**期末项目 Final Project**：给定一份数据和一个问题，用学过的算法求解并提交报告。数据常用**股票数据**（美股／港股／A 股），目标是检验你的策略能否跑赢市场。

> [!note] 关于“监督 / 无监督”的分界
> 第 1–3 章都在监督学习的框架里（数据是 $(x,y)$）。**第 4 章和第 5 章跨到了无监督一侧**（数据只有 $x$）：聚类问“这堆数据分成几堆”，异常检测问“这一个新样本正不正常”。第 5 章会把第 3 章的概率工具全部用起来。

| sigmoid 临界点 | $g(0)=0.5$；$g(4.6)=0.99$，$g(-4.6)=0.01$ |
| AND / OR / NOT | $g(-30+20x_1+20x_2)$ / $g(-10+20x_1+20x_2)$ / $g(10-20x_1)$ |
| XNOR | $(x_1\text{ AND }x_2)\text{ OR }((\text{NOT}x_1)\text{ AND }(\text{NOT}x_2))$ |
| 隐藏层的作用 | 把输入映射到**新坐标**，使原本线性不可分的排布在新坐标里线性可分 |
| 多分类 | 输出层 $K$ 个单元，$h_\Theta(x)\in\mathbf{R}^K$，标签为独热向量 |

## 公式速查（第 14 章 神经网络学习）

| 名称 | 公式 / 判断 |
|---|---|
| 代价函数 | $J(\Theta)=-\frac1m\sum_i\sum_k[y_k\log h_k+(1-y_k)\log(1-h_k)]+\frac{\lambda}{2m}\sum_l\sum_i\sum_j(\Theta^{(l)}_{ji})^2$ |
| 退化检验 | $K=1$ 时等于逻辑回归的交叉熵 |
| 误差项定义 | $\delta^{(l)}_j=\frac{\partial}{\partial z^{(l)}_j}\text{cost}(i)$ |
| 输出层误差 | $\delta^{(L)}=a^{(L)}-y$ |
| 回传 | $\delta^{(l)}=(\Theta^{(l)})^T\delta^{(l+1)}.*g'(z^{(l)})$ |
| sigmoid 导数 | $g'(z)=g(z)(1-g(z))=a(1-a)$ |
| 累积与梯度 | $\Delta^{(l)}+=\delta^{(l+1)}(a^{(l)})^T$；$D=\frac1m\Delta+\frac{\lambda}{m}\Theta\ (j\ne0)$、$D=\frac1m\Delta\ (j=0)$ |
| 数值微分代价 | 一个参数 $2$ 次前向；$n$ 个参数 $2n$ 次 |
| 反向传播代价 | $1$ 次前向 $+$ $1$ 次回传 |
| 数值梯度 | $\text{gradApprox}=\frac{J(\theta+\epsilon)-J(\theta-\epsilon)}{2\epsilon}$，$\epsilon=10^{-4}$ |
| 差分误差阶 | 两侧 $O(\epsilon^2)$；单侧 $O(\epsilon)$ |
| 梯度检验判据 | 量级相当；相对误差 $<10^{-7}$ 好、$>10^{-3}$ 几乎必有错 |
| 初始化 | $\Theta^{(l)}_{ij}\in[-\epsilon,\epsilon]$ 随机；**不能全零**（对称不破缺） |
| 结构默认值 | 输入 = 特征维；输出 = 类别数；1 个隐藏层；多层则等宽 |
| $J(\Theta)$ 的性质 | 非凸；局部最优在实践中通常不是主要障碍 |
